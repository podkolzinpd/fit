# Промпт для ИИ-агента

Скопируйте этот текст в начало задачи:

> Ты работаешь в Fit V2. Сначала полностью прочитай `AGENTS.md`, `ARCHITECTURE.md` и релевантный раздел `FEATURE_PARITY.md`. Соблюдай направление UI → repository → query → Supabase. Не обращайся к Supabase из компонентов. Не используй бизнес-триггеры, ручной SQL в Dashboard, `select('*')`, `any` или небезопасные casts. Составные записи реализуй одной явной RPC-транзакцией. Любое изменение БД начинай с migration и DB/RLS тестов. Сохраняй внешний вид и пользовательский результат V1, но не копируй legacy data-access код. Перед завершением запусти все проверки из `AGENTS.md` и перечисли, что было проверено.
