# Сторонние медиа

## Vital Animations Free Pack

- Источник: [Vital Animations Free Pack](https://vitalanimations.com/free-pack)
- Условия: [Vital Animations License](https://vitalanimations.com/license)
- Получено: 2026-09-01
- Использование: локальные оптимизированные видео внутри интерфейса Fit; исходный
  архив и самостоятельный набор файлов не распространяются.

Используется полный бесплатный набор `Free50`: 50 роликов с последовательными
ID `0051`–`0100`. Машиночитаемая таблица `ID → исходное название → ref карточки
FIT → имя локального файла` хранится в `src/shared/vital-free-pack.ts`; тест
проверяет полноту диапазона, уникальность соответствий и наличие каждого файла.

Для 29 точных совпадений переиспользуются существующие упражнения каталога. Для
21 движения или конкретного тренажёра, которых раньше не было, добавлены новые
системные карточки. В частности, `0082` — степмилл с движущимися ступенями, а
`0083` — компактный степпер с педалями: это разные тренажёры, а не дубли.

Видео перекодированы в H.264, 540 × 540, 30 кадров/с, без звука. Подмена
приблизительно похожими упражнениями запрещена: новые соответствия добавляются
только после проверки движения и оборудования. Для каждой новой карточки из
ролика сохранены два локальных JPG-кадра — статичный fallback и облегчённая
техника при выключенной анимации.
