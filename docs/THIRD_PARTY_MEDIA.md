# Сторонние медиа

## Free Exercise DB

- Источник: [Free Exercise DB](https://github.com/yuhonas/free-exercise-db)
- Лицензия: Unlicense / public domain
- Использование: два локальных JPG-кадра техники для системных упражнений.

Для `Close-Grip_Front_Lat_Pulldown` два исходных кадра хранятся отдельно в
`public/exercises/reference/`. Они закреплены только за вариантом узкого хвата;
обычная и широкая тяга продолжают использовать проверенный ролик Vital. Это
исключает прежнюю подмену узкого хвата широким при сохранении исторического
`exercise ref`.

В дополнение к прежнему импорту из 451 упражнения добавлен отдельный
воспроизводимый набор из 120 карточек. Явный список исходных ID и русских
названий хранится в `scripts/import-exercise-expansion.mjs`; он не изменяет
старые идентификаторы и не добавляет смысловые дубли карточек Vital.

## Vital Animations Free Pack

- Источник: [Vital Animations Free Pack](https://vitalanimations.com/free-pack)
- Условия: [Vital Animations License](https://vitalanimations.com/license)
- Локальный документ покупки: EULA 2026.1 от 18 июля 2026 года.
- Получено: 2026-09-01
- Использование: локальные оптимизированные видео внутри интерфейса Fit; исходный
  архив и самостоятельный набор файлов не распространяются.

Используется полный бесплатный набор `Free50`: 50 роликов с последовательными
ID `0051`–`0100`. Машиночитаемая таблица `ID → исходное название → ref карточки
FIT → имя локального файла` хранится в `src/shared/vital-free-pack.ts`; тест
проверяет полноту диапазона, уникальность соответствий и наличие каждого файла.

Для 29 точных совпадений переиспользуются существующие упражнения каталога. Для
21 движения или конкретного тренажёра, которых раньше не было, добавлены новые
системные карточки. В частности, `0082` — степмилл с движущимися ступенями, а
`0083` — компактный степпер с педалями: это разные тренажёры, а не дубли.

Видео перекодированы в H.264, 540 × 540, 30 кадров/с, без звука. Подмена
приблизительно похожими упражнениями запрещена: новые соответствия добавляются
только после проверки движения и оборудования. Для каждой новой карточки из
ролика сохранены два локальных JPG-кадра — статичный fallback и облегчённая
техника при выключенной анимации.

## Vital Animations Gym Pro

- Источник: [Vital Animations Gym Pro](https://vitalanimations.com/exercises/gym-exercises)
- Условия: [Vital Animations License](https://vitalanimations.com/license)
- Получено: 2026-09-07
- Использование: локальные оптимизированные видео внутри интерфейса Fit; исходный
  архив и самостоятельный набор файлов не публикуются.

Из приобретённого архива отобраны 317 самостоятельно проверенных animation
family. Пять известных true duplicate схлопываются существующими правилами
каталога, поэтому в основном выборе это 312 самостоятельных карточек.
Шестнадцать карточек публичного предварительного каталога исключены: нужного
движения в приобретённом архиве нет либо файл показывает другое оборудование
или технику. Приблизительные подмены запрещены.

Файл `scripts/data/vital-gym-pro-catalog.json` фиксирует соответствие публичной
карточки, приобретённого файла, русского названия, алиасов и старых FIT ref.
Команда `node scripts/import-vital-gym-pro.mjs --source <распакованный архив>`
проверяет список и воспроизводимо создаёт 540 × 540 H.264 без звука, начальный
и промежуточный JPG-кадры и типизированный каталог. Исходный ZIP не входит в Git.

Поскольку репозиторий публичный, открытые MP4/JPG также исключены из Git.
Команда `node scripts/package-vital-gym-pro-media.mjs --key-file <key>` хранит
их как AES-256-GCM authenticated bundle. Ручной workflow `Deploy Vital exercise
media` раскрывает bundle только во временном GitHub runner, проверяет все 951
файл и загружает их в закрытый Supabase Storage bucket. Приложение выдаёт
часовые signed URL только вошедшим пользователям; Vercel и публичный GitHub не
получают исходные медиа или ключ.
