## Известные уточнения и конфликты

- Fixed2 обозначает исходную согласованную пару тренеров. Контакты остаются в
  разрешённом приватном контексте, технические guards — в коде. Общие правила
  документации не расширяют пилот и не отменяют другие независимые client gates.
- 54/48 px — согласованные поля оригинального/компактного тренерского Live,
  а не высота всех кнопок продукта.
- Старые планы v79/composition запрещали добавлять паузу тренеру в том этапе.
  Позднее решение YAFIT-668 отменило этот запрет: PR1849 вернул паузу с учётом
  отдыха/длительности, PR1851 добавил явный coach pilot/all/off.
  [Текущий план](design/COACH_LIVE_FINISH_AND_ROLLOUT_20261028.md) заменяет
  прежний fixed2-запрет только для согласованного coach rollout после проверки.
- Планы superset/Live не разрешают дублировать заметки, имена и действия в каждом
  круге. Последнее замечание о компактности сохраняется в [реестре ошибок](REGRESSION_LESSONS.md).
- Сохранённая история не доказывает доступность реального OAuth/физического
  устройства. Непроверенные состояния не превращаются в проверенные при переносе.

## Сохранённые поперечные решения Fit

Это продуктовые ограничения из прежнего AGENTS, не второй общий процесс:

- Client Home остаётся voice-first: диктовка и ввод текстом — основные действия.
- UI-задача не меняет LLM, SpeechKit, matching, fallback, сохранение, таймеры
  и завершение без отдельного продуктового решения. Завершённая тренировка
  состоялась и при неполном плане; неделя начинается в понедельник, дата — LocalDate.
- Progress: проценты до целых, остальные показатели максимум до одного знака.
  Пользовательские тексты — понятные русские.
- Desktop trainer/P2 не расширяется автоматически; проверка совместимости
  не означает разрешение нового редизайна. Роли, ownership, темы и плотности
  сохраняют собственные области действия.
- Не добавлять панели, кнопки, метрики и повторы ради композиции; доступность
  механики проверяется действием, не числом постоянно видимых контролов.
- Не удалять legacy migrations, шрифты/fallback и rollback по возрасту:
  потребители и отдельное решение о выводе проверяются в соответствующей области.
- Production — Cloud.ru, внешний вход — Yandex ID; Vercel только redirect,
  Supabase только ограниченный legacy. Локально — Podman, новые миграции —
  services/api/db/migrations. Детали и запреты данных — ENGINEERING_RULES/playbook.

## Память и поиск по другим областям

Для расписания, чатов, питания, профиля, авторизации и других экранов начать с
нужного раздела PRODUCT_WIKI, затем найти действующий план/тикет и фактический код.
Этот индекс не заявляет, что перечислил все продуктовые решения.
[Архивный индекс](archive/workflow-20261027/INDEX.md) сохраняет ссылки из всего
прежнего snapshot, включая незакрытые и неуточнённые ограничения.
Поиск rg по области/тикету и docs/design обязателен перед изменением, не весь архив.
Если решение не отменено явно, не выбрасывать его по дате.

Корпоративные KB сейчас не являются надёжной точкой входа Fit: при ошибке поиска
продолжать с этим репозиторием. Никаких требований настроить/прочитать чужую fleet
базу перед каждой Fit-задачей. Общий core и реестр чужих баз не изменяются.

## Быстрая запись и история

[YAFIT-675 / план](design/QUICK_WORKOUT_AND_BOOKING_PLAN_20261029.md): пять PR,
независимый default-off пилот ровно двух учёток. Не наследует coach rollout all;
обе роли для подстановки, запись на время только у тренера. Scroll/swipe/inertia
имеют приоритет перед тапом, повтор истории заполняет существующую запись.

30.10.2026: владелец разрешил общий выпуск quick-entry и названий всем ролям.
[Актуальный план YAFIT-692](design/WORKOUT_NAMES_AND_PUBLIC_QUICK_ENTRY_20261030.md)
заменяет fixed2-границу YAFIT-675 только для этого пакета; прочие пилоты прежние.
Runtime all включается отдельным выпуском, текущий статус — в тикете.

## Проведение и несостоявшиеся занятия

[ФИТ19 / единое завершение Live](design/COACH_LIVE_SINGLE_EXIT_20261101.md):
в тренерском Lime одна верхняя галочка, три точных названия без подписей;
удаление только пустой записи, прежние команды/финансы/синхронизация.
Логотип, Original/Compact и клиентская механика сохраняются.

[YAFIT-698](design/COACH_QUICK_COMPLETION_20261031.md) уточняет YAFIT-697:
тренер проводит свой план/Live с упражнениями или без, без фиктивных фактов;
отмена доступна своему начатому Live, сохраняет данные, без расхода; крестик в
календаре. Пустые посещения остаются в общей истории, но не в источниках плана.
Original54/Compact48 и клиентская механика прежние; статус выпуска — в тикете.

[YAFIT-700](design/COACH_WORKOUT_STATUS_DISPLAY_20261101.md): у тренера любой
done отображается «Проведена» одинаково, незаписанный результат — «—».
Это только отображение; клиентские правила и механики YAFIT-698 сохраняются.
