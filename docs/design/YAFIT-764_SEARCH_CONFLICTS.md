# YAFIT-764 — конфликтные поисковые фразы

Автоматический отчёт `exerciseSearchConflicts` на каталоге из 663 упражнений
зафиксировал четыре исторические фразы, которые указывают больше чем на один
системный `ref`.
Они не дают молчаливую автоподстановку: новый контракт возвращает уровень
`ambiguous`, а человек подтверждает нужный вариант.

| Нормализованная фраза | Конфликтующие ref | Решение |
| --- | --- | --- |
| жим гантели стоя | `fedb-standing-dumbbell-press`, `vital-standing-dumbbell-press` | Дубликат уже скрыт из нового выбора, старый ref сохранён |
| подъем блина перед собой | `fedb-front-plate-raise`, `vital-plate-front-raise` | Старый FEDB-вариант скрыт из нового выбора, оба ref сохранены |
| становая на прямых ногах в Смите | `fedb-smith-machine-stiff-legged-deadlift`, `vital-smith-stiff-leg-deadlift` | Старый FEDB-вариант скрыт из нового выбора, оба ref сохранены |
| тяга штанги в наклоне | `barbell-row`, `fedb-bent-over-barbell-row` | Дубликат уже скрыт из нового выбора, старый ref сохранён |

Семантические коллизии исправлены без изменения ref: дорожка отделена от
общего бега и ходьбы, горизонтальная тяга — от тяги штанги, а рывковая и
«автомобильная» становая получили точные русские названия. Новое движение
«Журавлик в Смите» добавлено отдельной карточкой.

Пользовательские упражнения в этот отчёт попадают только во время поиска в
актуальном каталоге тренера. Их записи, идентификаторы и история не изменяются.

## Производительность

Регрессия выполняет 50 поисков по полному каталогу и требует уложиться в 1500 мс
даже при параллельном coverage на CI. Нормализованный индекс карточки кэшируется,
поэтому сотни дополнительных поисковых форм не пересчитываются на каждый символ.
Поиск не увеличивает сетевые запросы: нормализация и ранжирование выполняются
локально.

## LLM

Полный словарь алиасов остаётся локальным и не сериализуется в запрос модели.
Модель получает тот же компактный системный каталог, а локальный результат
после ответа повторно проверяется по уровню совпадения и оборудованию.
