# YAFIT-517 — общий индикатор непрочитанных сообщений

## Пользовательский результат

На главной тренера и спортсмена постоянно видна компактная кнопка
«Сообщения» с общей суммой непрочитанных. Она открывает список диалогов, а
push — конкретный диалог. Системное разрешение на push не влияет на внутренний
счётчик.

## Acceptance-чеклист

1. На главной тренера и спортсмена в правом верхнем углу постоянно
   отображается кнопка сообщений с областью нажатия не меньше 44×44 px.
2. При непрочитанных кнопка показывает их общую сумму; без непрочитанных число
   скрыто; значения больше 99 показаны как «99+».
3. Нажатие с главной открывает общий список диалогов; возврат возвращает на
   главную без наложения таббара.
4. В списке диалогов видны имя и аватар собеседника, последнее сообщение,
   время, непрочитанные и существующие состояния отправки, ошибки и отключения.
5. Открытие списка диалогов не снимает непрочитанные. Прочитанность фиксируется
   после успешного открытия соответствующего диалога и показа первого
   непрочитанного.
6. Счётчики синхронно обновляются после получения и чтения сообщения, возврата
   из фона, перехода по push, восстановления сети и существующего
   периодического обновления.
7. Push из фона открывает нужный диалог; при открытом нужном диалоге новое
   сообщение не создаёт ложный непрочитанный счётчик.
8. Если системные уведомления запрещены, внутренние счётчики и список сообщений
   продолжают работать.
9. Переписка не передаётся ИИ; существующие функции чата, схема данных и права
   доступа не меняются.
10. Проверены отдельно роли тренера и спортсмена, светлая и тёмная темы,
    390/430/1440 px, «99+», длинные имена, loading/empty/error/offline и возврат
    назад.

## Границы

- Без большой уведомительной плашки на главной.
- Без нового realtime-канала.
- Без изменений LLM, SpeechKit, схемы сообщений и push-пайплайна.
- Используется существующий единый запрос списка диалогов и общий cache.
