## Приёмка задачи 1

- Первая запись, изменение и PR: `workout-results.test.ts`, SQL 0046/0047; предшествующая история обязательна. Объём и fixed-weight reps имеют отдельные ключи.
- Две конкретные тренировки, включая один день: unit; ссылки и даты component. Повторный вход/порядок массива не меняют выбор.
