# Ачивки «Регулярность»: согласованные формулировки — 2026-10-05

## Неизменяемый список текстов

Названия, ID, пороги и правила начисления сохраняются. В подробностях каждой
ачивки раздела «Регулярность» используется следующий текст:

| Ачивка | Текст |
| --- | --- |
| Четыре недели | 4 недели подряд по 1 тренировке |
| Восемь недель | 8 недель подряд по 1 тренировке |
| Двенадцать недель | 12 недель подряд по 1 тренировке |
| 52 активные недели | По 1 тренировке в 52 разные недели. Не обязательно подряд |
| Снова в деле | Тренировка после перерыва не менее 21 дня |
| Нашёл ритм | 4 недели подряд по 2 тренировки |
| Держу ритм | 8 недель подряд по 2 тренировки |
| Ритм на квартал | 12 недель подряд по 2 тренировки |
| Трижды в неделю | 4 недели подряд по 3 тренировки |
| В своём темпе | В любые 6 из 8 недель — по 2 тренировки |
| Месяц в движении | 8 тренировок за календарный месяц |
| Сильный месяц | 12 тренировок за календарный месяц |
| Три месяца в деле | 3 месяца подряд по 4 тренировки в месяц |
| Полгода в деле | 6 месяцев подряд по 4 тренировки в месяц |
| Вернулся в ритм | После перерыва не менее 21 дня — ещё 2 тренировки в течение 14 дней |

Одна общая подпись раздела: «Тренировки засчитываются в разные дни.» Это
поясняет действующее правило: несколько завершённых тренировок за один день
считаются одним тренировочным днём. Награды «Месяц в движении» и «Сильный месяц»
в подробностях отдельно сообщают: «Можно получать каждый месяц.»

У числового прогресса регулярности указывается единица измерения: недели, дни
или месяцы. Пример: «Прогресс: 5 из 8 недель». Полученные награды сохраняют дату,
а повторяемые месячные — число получений и прогресс текущего месяца.

## Граница и приёмка

- Только тексты, пояснение и единицы прогресса в существующих Badge,
  AchievementDetail и коллекции `/me/achievements`; новые экраны, картинки,
  цвета, CTA и бизнес-правила не добавляются.
- Проверить точность всех 15 формулировок; две тренировки в один день не
  засчитываются как два дня; пропущенная неделя обрывает неполученную серию;
  месячные награды повторяются, прежние остаются полученными.
- Проверить 390/430 px, светлую/тёмную темы, длинный текст без горизонтального
  скролла, доступную подпись, загрузку/ошибку/повтор и закрытие подробностей.

Текущий маршрут `/me/achievements` — визуальный референс. Единственное основное
действие — открыть подробности награды. Переиспользуются `Page`, `Badge`,
`AchievementDetail` и существующие семантические токены текста.
