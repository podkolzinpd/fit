# Реализация UX/UI-аудита основного тренировочного пути

> Это сводка «план → факт», а не повторный аудит и не новый backlog.
> Основание: UX/UI-аудит от 2026-08-06 на commit `90982d3`.
> Проверенная граница: `main` на 2026-08-07, commit `fb7f385`.

## Итог

Обязательный scope основного пути закрыт: `Today / composer → review →
назначение → план → live → история`. Реализация сделана серией небольших PR,
без изменения LLM/SpeechKit. Отдельно подтверждены реальный WebKit и таймер
отдыха на 390 px.

## Что сделано после основного scope, но не является его приоритетом

- PR [#315] добавил отзыв тренера к завершённой тренировке. Это полезное
  развитие результата занятия, но не пункт исходного UX/UI-аудита.
- PR [#318] показывает «Частично» и «Пропущена». Это необязательная полировка
  из более позднего бэклога и не должна менять порядок следующих задач.

## Что сознательно не делалось

Эти пункты были явно исключены из scope основного редизайна, поэтому не
считаются незавершёнными дефектами этого плана:

- публичная стартовая страница и маркетинговый лендинг;
- полноценная desktop-компоновка;
- новые тренировочные форматы, аналитика и показатели списка клиентов;
- редизайн профиля и карточки спортсмена;
- оптимизация каталога без подтверждённой проблемы производительности.

## Проверки и оговорка по визуальным артефактам

- Поведенческие e2e и WebKit-проверки добавлены вместе с соответствующими PR.
- PR [#316] зафиксировал реальные live-состояния с ненулевым отдыхом, которые
  в исходном аудите были помечены как `NOT VERIFIED`.
- Исходный аудит содержит baseline-скриншоты. Отдельный versioned-пакет из
  двенадцати финальных скриншотов не хранится в репозитории; это пробел в
  артефактах приёмки, но не известный пользовательский дефект.

## Следующий продуктовый приоритет

Дальше применять порядок из `docs/design/BACKLOG-OVERVIEW.md`, а не брать
случайную низкоприоритетную полировку: сначала состав тела и тренд-график,
затем детализация мышечных групп. Для задач, требующих продуктового решения,
сначала получить это решение.
