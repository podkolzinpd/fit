# YAFIT-512 — компактный голосовой и текстовый ввод на главной клиента

Пользовательский результат: на главной клиента кнопки микрофона и текстового
ввода выглядят и работают как единый компактный блок по образцу главной
тренера.

## Acceptance-чеклист

1. [x] На главной клиента кнопки микрофона и текстового ввода объединены в две
   небольшие соседние плашки, визуально согласованные с главной тренера.
2. [x] При записи и обработке голоса сохраняются текущие состояния и сообщения
   об ошибках; текстовая кнопка доступна только в безопасном состоянии.
3. [x] Текстовая кнопка открывает прежний текстовый редактор и корректно
   обрабатывает восстановленный черновик.
4. [x] Главная тренера не меняется; клиентский экран проверен с тренировками и
   без них на мобильной ширине 390 px.
5. [x] Изменение покрыто целевыми тестами и полной проверкой проекта.

## Матрица проверки

| Пункт | Видимый результат | Проверка | Статус |
| --- | --- | --- | --- |
| 1 | Две кнопки находятся в одном правом блоке голосовой карточки | WebKit 390 px; baselines Client Home 390/430 px, light/dark | Готово |
| 2 | Во время записи остаются штатные «Готово» и «Отменить», при обработке текстовая кнопка скрыта | Сохранённый контракт `VoiceInputButton`; WebKit client flow | Готово |
| 3 | Кнопка с клавиатурой открывает текстовый редактор и очищает восстановленный черновик по прежним правилам | WebKit client flow и Chromium trainer quick start | Готово |
| 4 | Trainer Home без изменений; Client Home проверен для существующего и нового профиля | Client Home 390/430 px и first-run baseline; trainer quick start | Готово |

Локальные darwin-baselines Trainer Home на актуальном `main` уже расходятся с
порядком PWA-карточки после #900. Код и снимки тренерской главной в YAFIT-512 не
менялись; её рабочий быстрый старт отдельно подтверждён поведенческим тестом.
