# YAFIT-572 — последняя тренировка на главной спортсмена

Утверждено владельцем продукта 30 сентября 2026 года. Реализовать и выпустить отдельно от остальных пунктов [YAFIT-567](https://st.yandex-team.ru/YAFIT-567).

## Граница задачи

Меняется только личный результат внутри существующей карточки «Последняя тренировка» на `/me`. Карта «Нагрузка по телу» остаётся в этой же карточке без изменений. Голосовой и текстовый старт, план, неделя, ответ тренера, Progress, экран завершения, тренерский интерфейс, расчёты и правила личного рекорда вне scope.

Референс — действующий Client Home и его baseline `personal-result-home-*-visual-client-390.png`. Переиспользуются `PersonalWorkoutResult`, `PeriodLoadMap`, существующие нейтральная `card`, `eyebrow`, `link` и типографические токены. Единственное primary-действие экрана по-прежнему голосовой ввод; «Открыть тренировку» остаётся вторичным переходом.

## Утверждённый acceptance-чеклист

1. **Первая завершённая тренировка.** Показать дату, «Первая тренировка записана», количество упражнений с подтверждёнными подходами и количество подтверждённых подходов, затем «Открыть тренировку». Не выбирать одно упражнение и не называть первый результат личным рекордом.
2. **Последующая завершённая тренировка без рекорда.** При снижении, равенстве и росте, не являющемся рекордом, показывать только дату, те же фактические счётчики и ссылку. Не писать «Тренировка записана», «Результат снизился» или «Результат вырос», не выводить разовую дельту и не выбирать упражнение. Если подтверждённых фактов нет, оставить дату и ссылку без нулевых или выдуманных показателей.
3. **Подтверждённый личный рекорд.** Показать дату, «Личный рекорд», упражнение, конкретный рекордный показатель и ссылку. Первое выполнение упражнения остаётся отправной точкой; рекорд возможен только после более позднего сопоставимого подтверждённого выполнения того же упражнения с лучшим показателем. Существующий расчёт не менять.
4. **Несколько рекордов в одной тренировке.** Показать первый по порядку упражнений в тренировке и коротко «Ещё N рекордов»; не ранжировать упражнения по оценочной важности. Количество брать только из подтверждённых рекордных фактов.
5. **Сохранить остальные состояния и элементы.** Loading, empty, error/retry, навигация, voice-first primary и карта месячной нагрузки не меняются. Блок недели, цель/ответ тренера и тренерский интерфейс не меняются. Проверить частичную тренировку, отсутствие факта, длинное название, 390/430 px, светлую и тёмную темы, WebKit и production после зелёного CI.

## Условные состояния

| Состояние | Поведение внутри блока |
| --- | --- |
| История загружается | Существующий статус загрузки; прежние цифры не выдаются за новые. |
| Ошибка загрузки | Существующая ошибка с «Повторить»; рекорд и счётчики не показываются из устаревших данных. |
| Завершённой тренировки нет | Существующее пустое состояние; карта без завершённой тренировки не добавляется. |
| Есть завершённая тренировка без подтверждённых подходов | Дата и ссылка без счётчиков и оценки. |
| Есть частично выполненная тренировка | Счётчики только по подтверждённым подходам; сам статус `done` не отменяется. |
| Первый факт упражнения в более поздней тренировке | Не рекорд; карточка использует обычный нейтральный вариант. |
| Другие роли | Компонентный режим вне `home` сохраняет прежнее представление; тренерские экраны не меняются. |
