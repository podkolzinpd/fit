# Live: ввод, клавиатура и подключение существующего переноса

Пользователь подтвердил выполнение 16.10.2026. План ниже — acceptance-контракт;
пункты не удалять и не менять по смыслу без согласования. Реализация — три PR.
Проверка существующего обязательна заново перед каждым PR.

## PR 1. Быстрый ввод и редактирование подходов

- Быстрая замена веса и повторов.
- Переход между полями и следующим подходом без закрытия клавиатуры.
- Выполненные подходы доступны для прямой правки: галочка остаётся, поля не блокируются.
- Переиспользуем существующие автосохранение, черновики и обработку ошибок.
- Правка выполненного подхода не перезапускает отдых.

## PR 2. Стабильная клавиатура и прокрутка

- Устраняем подтверждённые скачки при открытии и закрытии клавиатуры.
- Сохраняем фокус, введённые значения и положение экрана.
- Используем существующий механизм управления экраном, исправляя его взаимодействие с полями.

## PR 3. Подключение готового перетаскивания

- Подключаем существующие компоненты переноса к клиентскому Live.
- Переиспользуем маркер вставки, прокрутку у края, отмену жеста и перенос суперсетов целиком.
- Используем готовое безопасное сохранение порядка.
- Сохраняем клиентскую айдентику — весь тренерский пилот ради перетаскивания не включаем.
- Проверяем сохранность результатов, черновиков и порядка после перезагрузки.

Каждый PR проверяем отдельно. По уточнению владельца16.10 обязательная проверка
существующего — сверка кода и уже работающих механизмов ДО разработки. Проверка
на физическом iPhone не является условием выпуска этих доработок и не требует
дополнительного разрешения. Она не выполнена и не выдаётся за выполненную.
Тестовые данные только синтетические; реальные пользовательские записи не изменять.

## Аудит тестовых случаев PR 1

Добавлены ровно два поведенческих случая: клиент и тренер имеют разные галочки
и компоновку завершения. Каждый проверяет замену числа, переход полей,
подтверждение, прямую правку, reload и сетевой retry без второго подтверждения
или сброса отдыха. Новых визуальных декартовых матриц нет. Прежние 626 случаев
сохранены, полный union теперь628 на движок; critical+finance94→96. Проверка
уникальности, равенства union шардов и обязательных конфигураций сохранена.
Защитный reviewedInventoryDigest не обновлялся: изменение spec продолжает
включать полный CI. В существующих visual cases заменён только селектор
числового поля и проверка ручной разблокировки на проверку прямого сохранения.

Проверка физического iPhone НЕ ВЫПОЛНЕНА: devicectl не обнаружил подключённых
устройств. WebKit, Chromium и будущий simulator не заменяют физический телефон.
