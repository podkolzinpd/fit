# Компактный список клиентов и гостевое приглашение

Канонический план и журнал [YAFIT-699](https://st.yandex-team.ru/YAFIT-699).
Владелец подтвердил два PR и полный самостоятельный выпуск после согласования
интерактивных эскизов из аудита31.10.2026. Состояния и данные эскиза условные;
полные макеты и YS Geo остаются локальными, не публикуются в Git.

## PR1 — компактный список клиентов

- CUI101: поиск виден при любом непустом списке, использует существующий q и
  текущие данные. Пустой результат позволяет очистить запрос без создания дубля.
- CUI102: одно «Добавить»: шапка непустого списка либо пустое состояние.
  Открывает выбор существующего создания карточки/приглашения; декоративного
  плюса нет. Права, idempotency приглашения и необязательность параметров прежние.
- CUI103: инициалы, полное имя, один полезный текущий статус, прежний чат.
  Компактная Lime-строка ориентировочно68px, длинное имя увеличивает высоту.
  Данные возраста/роста/массы остаются в профиле; finance overview переиспользуется
  без запросов на каждую строку и без новых вычислений денег.
- CUI104: прежние карточка, чат, форма профиля и частный alias тренера.
  Новый фото-контракт, изменения личности или прав не вводятся.
- CUI105: архив/восстановление/отмена, запрос поиска и позиция списка при возврате
  сохраняются; вертикальная прокрутка не становится архивированием.
Проверки: пустой/один/большой список, длинное имя, поиск/no-results/clear,
существующие создание/чат/архив/undo/возврат; обе темы/мобильные ширины/клавиатура.

## PR2 — приглашение в действующей айдентике

- IUI201: принятые палитра, YS Geo, логотип и controls для гостевого приглашения;
  только этот маршрут, без расширения других public gates/ролей/пилотов.
- IUI202: отправитель/роль/срок до входа; существующие вход/регистрация и возврат;
  текущий аккаунт и явное подключение после входа.
- IUI203: pending/защита от повторов, успех в существующий кабинет; прежние токен,
  OAuth continuation и claim. Оформление не создаёт другую карточку/аккаунт.
- IUI204: expired/revoked/claimed/network/неверная роль/другой действующий тренер/
  storage-unavailable. Retry только там, где уместен; чужая связь не отключается.
- IUI205: реальная серверная регрессия связывания созданной вручную карточки,
  сохранность истории/расписания/абонемента, actor/RLS и replay. Если найден
  дефект данных — отдельное явное решение, не скрытая миграция или обход прав.
Проверки: guest→auth/register→return→claim→home, terminal/error/retry и роли;
существующий серверный claim на локальном PG17, неизменность связанных данных.

## Выпуск и границы

Каждый PR проходит применимые проверки/current-headCI. Оба выполняются целиком,
не заканчиваются одним PR. Штатная очередь: ФИТ14 приоритет, затем активные PR
по созданию; неактивные — по ранее подтверждённому владельцем правилу. Чужие
ветки/гейты не изменять. Публикации сериализованы, без наложения с ФИТ20.
Финал: зелёный exact-main, штатные API/frontend/подписанный Android OTA,
независимые health/assets/release checks и опубликованные сценарии с условными
данными. Физические телефоны/реальный OAuth отмечаются отдельно от эмуляции.
Отдельный PR только для приёмки не создаётся. Фото, новая навигация, два Live,
голос/текст/SpeechKit/LLM/matching/настройки моделей, таймеры/черновики и реальные
данные/деньги не меняются. Существующие клиентские изменения сохраняются.
