# Восстановление неполного профиля тренера

Тикет: YAFIT-516. Статус: локальная реализация готова, ожидает PR и CI.

## Пользовательский результат

Тренер с уже существующим профилем может добавить первого клиента, даже если
служебная запись тренера по какой-либо причине отсутствовала до входа.

## Зафиксированный план

1. Добавить тест на «профиль тренера есть, служебной записи тренера нет».
2. При входе автоматически и безопасно восстанавливать такую запись.
3. Добавить понятную диагностику, если создание клиента всё же отклонено.
4. Прогнать проверки регистрации и создания первого клиента.
5. Создать PR, дождаться очереди CI, смержить и проверить выкладку. Существующий активный PR #922 не буду ломать или обходить — учту его перед слиянием.

## Acceptance cases

- Существующий корректный профиль тренера не переинициализируется.
- Профиль с ролью тренера без строки в `trainers` восстанавливается через
  существующую идемпотентную RPC до показа рабочего интерфейса.
- Клиентский аккаунт не получает строку тренера.
- Серверная ошибка `trainer_not_initialized` не раскрывается пользователю как
  техническая деталь.
- Состояния формы первого клиента остаются прежними: validation, pending,
  success и error; повторная отправка во время pending заблокирована.

## Границы

- Не меняем композицию главной тренера, создание клиента и схему БД.
- Не исправляем другие возможные причины конкретной жалобы без подтверждения.
- Используем существующие `initialize_account`, форму первого клиента и
  стандартное отображение ошибки.
