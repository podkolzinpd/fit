# Клиентский доступ к ассистенту — утверждённый план

Статус: зафиксирован владельцем продукта 2026-09-17. Объём нельзя расширять без отдельного решения.

1. Добавить в клиентское нижнее меню кнопку **«Ассистент»**.

   Расположение:  
   **Кабинет → Тренировки → Ассистент → Прогресс → Профиль**

2. По кнопке открывать тот же экран ассистента, который уже используется тренером:

   - та же история;
   - то же поле ввода;
   - те же кнопки микрофона и отправки;
   - те же карточки ответов и подтверждений;
   - без нового дизайна и отдельных компонентов.

3. Разрешить клиенту открывать существующий маршрут ассистента. Сейчас он закрыт проверкой роли тренера.

4. Минимально адаптировать контекст:

   - ассистент автоматически работает с текущим клиентом;
   - не предлагает выбрать или создать другого клиента;
   - убрать только явно тренерские формулировки и команды;
   - всю остальную логику оставить общей.

5. На сервере сделать только необходимое изменение: клиент может создавать и читать собственные диалоги и выполнять действия только со своими данными. Это обязательно, потому что сейчас сервер также ограничивает ассистента ролью тренера.

6. Проверить:

   - открытие по кнопке;
   - текстовый и голосовой ввод;
   - сохранение истории;
   - работу с собственной тренировкой;
   - отсутствие доступа к чужим данным;
   - отображение пяти кнопок на узком экране.

7. После проверок выкатить обычным порядком.

Не трогаем главную, прогресс, существующие тренировочные сценарии, юридические документы, архитектуру ассистента и не создаём отдельный клиентский вариант.
