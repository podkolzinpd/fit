# YAFIT-496 — фактический вес в следующих подходах

Tracker: https://st.yandex-team.ru/YAFIT-496

## Пользовательский результат

Во время активной тренировки Fit подхватывает последний подтверждённый
фактический вес для следующих однотипных подходов, не меняя сам план программы.

## Утверждённый план и acceptance

1. План `20 / 20 / 20`: факт первого подхода `25` подставляет `25` в два
   следующих нетронутых подхода.
2. План `10 / 20 / 20 / 30`: факт второго подхода `22` подставляет `22` только
   в третий подход; первый и четвёртый сохраняют `10` и `30`.
3. Фактический вес, уже введённый вручную в следующий подход, имеет приоритет и
   не перезаписывается.
4. Значение не переносится между разными упражнениями.
5. Один и тот же Live-контракт работает для самостоятельной тренировки и
   тренировки, назначенной тренером.
6. Поведение покрыто чистыми unit-тестами и мобильным WebKit-сценарием; перед
   выпуском выполняются `npm run check`, CI и production smoke-test.

## Реализация

- Использовать существующие `WorkoutSet`, `LiveSetFields`, локальный draft и
  Live-экран без нового контрола или изменения визуальной иерархии.
- Для нетронутого силового подхода искать ближайший предыдущий подтверждённый
  подход внутри непрерывной группы с тем же плановым весом.
- Фактический или локально введённый вес текущего подхода всегда важнее
  автоматически предложенного значения.
- Автоподстановка является фактом только после обычного подтверждения подхода;
  плановые поля программы не изменяются.

## Вне scope

- изменение программы и адаптация будущих тренировок;
- перенос повторов, RPE, времени или дистанции;
- новый интерфейс, подсказка или coachmark;
- изменение backend-схемы и RPC.
