# YAFIT-389 — безопасное переподключение самостоятельного клиента

## Контракт

- Канонической остаётся самостоятельная карточка авторизованного клиента.
- Карточка нового тренера атомарно объединяется с ней через уже проверенный
  `claim_client_invitation`: тренировки, цели, замеры и авторство сохраняются.
- Новый тренер получает доступ только после успешного завершения всей операции.
- Старый тренер должен быть явно отключён заранее. При активной связи операция
  возвращает `trainer_disconnect_required` и не меняет ни один объект.
- Повтор уже успешно использованного тем же клиентом кода идемпотентен.
- Чужой, просроченный, отозванный или повреждённый код не раскрывает данные.

## Граница задачи

Задача добавляет только серверную операцию `reconnect_client_trainer(text)` и
SQL/RLS-приёмку. Экран ввода кода, тексты состояний и сценарий явного перехода
к отключению текущего тренера выполняются отдельной задачей.

## Проверяемые гарантии

1. Самостоятельная история клиента не теряется.
2. План нового тренера переносится в каноническую карточку с авторством.
3. Одновременно существует не более одной активной связи с тренером.
4. Прежняя отключённая связь остаётся в истории.
5. При конфликте нет частичного merge, claim или выдачи доступа.
