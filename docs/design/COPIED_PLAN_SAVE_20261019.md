# Сохранение копии плана — 19.10.2026

Запрос: проверить по коду и исправить ошибки сохранения скопированного плана
после замены упражнений, в том числе случай без замены. На скриншоте — общий
текст «Yandex Cloud временно недоступен». Это не подтверждение аварии облака.

## Acceptance (нумерацию и смысл сохранять)

1. Воспроизвести замену в новом плане, скопированном из завершённой тренировки;
   при том же типе ввода сохранить значения либо подставить историю выбранного
   упражнения. Не переносить/менять факты исходной тренировки.
2. Проверить копию без замены и с заменой: валидный запрос, самостоятельные
   идентификаторы блоков, без source-ID и expectedVersion оригинала; серверная
   атомарная запись, readback и повтор без дубля. Сохранить права и conflict checks.
3. При 5xx оставить форму/ввод/черновик и действие повторного сохранения;
   показать существующую безопасную диагностику без персональных данных.
   Не утверждать, что Cloud.ru/Yandex Cloud недоступен по любому ответу 5xx.
4. Выполнить целевые браузерные и DB-проверки, общий check; PR и штатный выпуск
   только после обязательных проверок и очереди. В отчёте отдельно назвать
   исправленные дефекты и неподтверждённую причину пользовательского инцидента.

Не входит: новые флаги/пилоты, редизайн, LLM/голос, изменение пользовательских
данных production, ослабление валидации/прав, фоновые повторы мутаций.

## Доказательства

До реализации: WebKit baseline замены/удаления 1/1, PostgreSQL17 3/3.
Новый WebKit regression воспроизвёл потерю 27.5 кг × 10 после замены в копии
завершённого источника (получено пустое поле). Правка ограничивает clearFact
наличием редактируемого workoutId. Также воспроизведена потеря точного кода
диагностики: generic body затирал безопасный SQLSTATE из заголовка; приоритет
исправлен в существующем helper, пользовательская классификация не меняется.

PostgreSQL17: 4/4 целевых теста (обе копии/readback/replay/original unchanged,
агрегат/conflict/RLS, title/receipt). Unit: 213/213 в пяти затронутых наборах.
Добавлен один браузерный сценарий (WebKit+Chromium), два DB-варианта; длинные
существующие сценарии и матрицы не дублируются. Общий inventory digest/gates
не меняются: CI сохраняет полный fail-closed набор.

Запись в YAFIT остановлена проверкой безопасности среды: передача внутреннего
плана во внешний сервис требует отдельного подтверждения; обход не используется.
PR/CI/выпуск и оставшиеся проверки заполняются по факту. Причина конкретного
серверного 5xx не установлена и не объявляется устранённой этими правками.
