# YAFIT-600 — профиль спортсмена: спортивные интересы

Итоговый план — для приложения спортсмена, без даты рождения и без запуска публичных профилей.

1. Переименовать экран «Редактировать клиента» в «Редактировать профиль». Заголовок тренерской формы не менять.
2. Оставить существующие данные для тренировок как есть: имя, пол, возраст числом, рост и цель. Числовой возраст в черновике ассистента тренера тоже не трогать.
3. Добавить необязательный раздел «Чем занимаюсь» с поиском и выбором любого количества пунктов:
   - зал и фитнес: силовые, функциональный тренинг, кроссфит, калистеника, йога, пилатес, растяжка, танцы;
   - выносливость: бег, трейлраннинг, ходьба, велоспорт, плавание, гребля, триатлон;
   - игровые: футбол, баскетбол, волейбол, теннис, настольный теннис, бадминтон;
   - единоборства: бокс, борьба, смешанные единоборства;
   - на природе и зимой: походы, скалолазание, лыжи, сноуборд, коньки;
   - «Другое». Список можно будет расширять позже.
4. Добавить необязательное короткое поле «О себе в спорте» — до 160 символов. Выбранные занятия и текст показывать в собственном профиле; длинный перечень сворачивать.
5. Сделать новые сведения приватными: сохранять и показывать их владельцу, не публиковать для друзей и не подмешивать в тренировочную карточку тренера. Существующие профили должны работать с пустыми новыми полями.
6. Проверить сохранение и повторное открытие, отсутствие лимита выбора, мобильную вёрстку с клавиатурой, права доступа и то, что тренерские сценарии не изменились.

Профили друзей, публикацию этих полей и переход с числового возраста на дату рождения оставляем отдельными задачами после решения вопросов с персональными данными.

## Границы и приёмка

- Основной поток: product. База: Yandex PostgreSQL/API; новых Supabase миграций нет.
- Один основной action на форме: «Сохранить». Новые поля необязательные.
- Профиль с заполненными полями, без них, loading, error/retry, pending и успешное сохранение проверяются отдельно.
- Тренерские формы и голосовой черновик остаются без нового раздела и без изменения возраста.
- Для приватных данных проверяются владелец, другой спортсмен и тренер, включая прямой запрос к API.
