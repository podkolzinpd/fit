# Live: точные нажатия и чистая таблица подходов

Статус: утверждено к реализации и автономному выпуску 2026-09-14.
Тикет: YAFIT-918 (`podkolzinpd/fit#918`).

## Утверждённый план

1. Исправить ошибочное нажатие:

   - развести зоны кнопок соседних подходов;
   - исключить перекрытие нижней строки сообщением «Сохранено»;
   - сделать статус сохранения некликабельным.

2. Перестроить подходы в единые полноширинные строки:

   - одинаковая геометрия до и после сохранения;
   - общий фон строки вместо отдельных плиток полей;
   - внутренние разделители между номером, весом, повторами и статусом;
   - 6–8 px между соседними строками для надёжного нажатия.

3. Развести состояния визуально:

   - текущий подход — чёрная кнопка;
   - выполненный — зелёная строка и отметка;
   - редактирование выполненного — контурная кнопка сохранения;
   - никаких скачков размеров при переходе между состояниями.

4. Убрать лишние линии:

   - верхнюю границу таблицы;
   - разделители между подходами;
   - лишнюю линию перед заметкой.

5. Уплотнить служебные блоки:

   - не показывать «Нет предыдущего результата»;
   - пустую заметку держать свёрнутой;
   - существующую заметку показывать одной строкой превью;
   - технику без анимации показывать компактно, без старой фотографии и большой пустой медиазоны.

6. Убрать дублирование отдыха:

   - оставить короткую строку `Отдых 1:30`;
   - по нажатию выбор времени раскрывается в этой же строке;
   - надпись «Отдых в этой тренировке» удалить;
   - более длинный текст не добавлять.

7. Нижнюю кнопку оставить безопасной:

   - пока подходы не завершены — спокойная вторичная;
   - после последнего подхода — заметная основная;
   - закрепление и безопасный нижний отступ сохраняются.

8. Проверить на реальном мобильном сценарии:

   - последовательные нажатия верхней и нижней кнопок;
   - нажатие во время появления «Сохранено»;
   - редактирование уже выполненного подхода;
   - ширины 375, 390 и 430 px;
   - отсутствие скачков строк, перекрытий и случайного завершения соседнего подхода.

Бизнес-логика, серверные методы и структура тренировки не меняются.
