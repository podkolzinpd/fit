# YAFIT-672 — принятие нового основного документа

Владелец разрешил один PR по настройкам и документации, самостоятельные merge и
проверку результата. Общие правила действуют для всех экранов, ролей и режимов.
Код приложения, CI, флаги, данные и механики не меняются.

## Источник и решение

Основа — предоставленный владельцем документ «Правила работы ИИ-разработчика
в этом проекте», сохранённый экспорт AGENTS.md. SHA-256 источника: `9fb77f373fcc3f9ca156efef959807beafd025650dc65d6c29e866ebb7520434`.
Это идентификатор прочитанной версии, не требование скачивать внешний документ
перед каждой задачей. Новый текст применяется в корневом AGENTS.md.

Выбран новый документ, а не слой поверх старого процесса. Разбиение на четыре
PR и сохранение отдельного старого цикла выпуска отвергнуты как лишние для
этой задачи. Существующие workflow/CI не меняются этой правкой документации.
Пункты 1 и 6 адаптируются к существующему хранению, без нового DEVLOG.

  статусы не превращают синтетический UI в реальный OAuth/телефон.

- [Архив28.10](../archive/workflow-20261028/README.md): заменённые AGENTS и
  FIT_WORKFLOW побайтно. Архив27.10 с его manifest остаётся неизменным.

Не перенесены как параллельный процесс: прежний общий цикл работы, дубли общих
