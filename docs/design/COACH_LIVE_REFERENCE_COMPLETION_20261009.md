- Сохранить видимый отсчёт отдыха при прокрутке. Проверить обычный отдых, подготовку, завершение отсчёта и восстановление после возврата в приложение.

### PR 2. Карточки упражнений

- Перенести графитовый фон, скругления, разделитель и внутренние отступы.
- Добавить круглый номер упражнения.
- Центрировать название, предусмотреть длинные названия в несколько строк.
- Добавить сводку количества подходов, веса и повторений. Для неодинаковых подходов не показывать вводящую в заблуждение общую цифру.
- Сделать многоточие визуально компактным, сохранив удобную область нажатия.
- Убрать большую раскрытую технику из основного вида: оставить компактный вход, по нажатию раскрывать изображение и подробности.
- Оформить следующие и завершённые упражнения в той же айдентике, **сохранив существующие свёрнутые состояния**.

### PR 3. Поля и состояния подходов

- Сохранить нынешнюю высоту полей и галочки — **48 px**.
- Разделить вес, повторения и подтверждение видимыми зазорами.
- Перенести единицы измерения внутрь полей; убрать дублирующие заголовки там, где они больше не нужны.
- Аналогично оформить время, дистанцию и остальные используемые показатели.
- Развести состояния: текущий подход — акцентный; ожидающий — нейтральный; подтверждённый — явно отмечен выполненным.
- Не менять сохранение значений, черновики и порядок подтверждения.
- Добавить крестик удаления подхода через существующую безопасную логику. Для подхода с результатом исключить случайную потерю данных.

### PR 4. Действия, завершение и мобильная проверка

- Сделать «+ Подход» центрированным действием с лаймовым плюсом.
- Оформить «+ Упражнение» широкой графитовой кнопкой по референсу.
- Убрать большую дублирующую нижнюю панель завершения **после обеспечения постоянного доступа к компактной кнопке завершения**. Сохранить все подтверждения незавершённых подходов.
- Проверить перетягивание и свайпы после изменения карточек: прокрутку длинного списка, сохранение порядка и результатов.
- Исправить перекрытия содержимого, включая открытие клавиатуры и нижнюю безопасную область экрана.

### Проверка перед выкаткой

Каждый PR проверяем отдельно. В конце — сравнение с референсами и проверка полного сценария: ввод → подтверждение → отдых → следующий подход → завершение. Дополнительно — длинные названия, несколько упражнений, время/дистанция и обе пилотные учётки.

Результат: **композиция по референсу с сохранённой тренерской механикой**, а не очередная перекраска. Пока это только план.
