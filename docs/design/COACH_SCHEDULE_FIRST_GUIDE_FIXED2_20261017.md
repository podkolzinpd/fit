# Подсказка первого входа в расписание для двух тренеров

Разрешение владельца: «делай, выкатывай». Один обязательный PR по подтверждённой
ошибке. Изменения только для двух прежних разрешённых учёток reference-пилота;
контакты и UUID не публикуются. Состав пилота не расширяется.

## Подтверждённый план

### PR 1. Исправить подсказки первого входа

Что меняем:

- Вместо трёх одновременно открывающихся подсказок в расписании оставить одну короткую: где переключается календарь/список и находятся фильтры.
- Привязать её к видимому элементу управления, а не к скрытому текстовому якорю.
- Проверить положение: подсказка не выходит за экран, кнопка «Понятно» доступна.
- После закрытия не показывать повторно для этой учётки.
- Не переделывать общий онбординг и не добавлять пошаговый тур.

Что проверяем:

- Первый вход с чистой историей подсказок.
- Повторное открытие и перезагрузку после закрытия.
- Узкий экран, обычный телефон и desktop.
- Открытие фильтров, календаря и окна новой тренировки.
- Отсутствие изменений у пользователей вне двух учёток.
- Добавить проверку отсутствия наложения — прежние тесты этого не проверяли.

### Остальные пункты

Таймер. Пока оставить текущий вариант. Для точного совпадения нужен оригинальный
шрифт или полный набор цифр и разделителей от дизайнера. Не рисовать недостающие
символы приблизительно и не обещать точное соответствие.

Фото клиента. Инициалы оставить как согласованный вариант. Настоящее фото
потребует отдельной задачи на получение данных профиля; в этот косметический
PR её не включать.

Автозаполнение iPhone. Проверить на физическом устройстве вес, повторы, время
и дистанцию. Если панель остаётся — сначала установить причину. Не отключать
системное поведение глобально без проверки последствий. Физического устройства
для этой проверки сейчас нет; она не подменяется симулятором и не входит в
исправление подсказок.

### Выпуск и приёмка

После исправления — целевые тесты, визуальная проверка, обязательный CI,
выкатка и проверка опубликованной версии. Дополнительно коротко перепроверить
Live: ввод, отдых, суперсеты, свайпы и перетягивание.

Итого: сейчас 1 PR. Количество дальнейших PR определим только после получения
исходника таймера и проверки физического iPhone.
