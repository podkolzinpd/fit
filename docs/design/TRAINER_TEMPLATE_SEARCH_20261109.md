# Поиск шаблонов тренера — YAFIT-707

План согласован Антоном09.11.2026 вместе с Lime-макетом. Разрешены реализация,
полный выпуск и production-проверка. Канонический план/журнал — этот документ;
[тикет](https://st.yandex-team.ru/YAFIT-707) хранит статус и квитанции выпуска.

## Объём и приёмка

- S101: под заголовком библиотеки строка «Поиск по названию»; мгновенное
  совпадение части названия без учёта регистра, е/ё и крайних пробелов.
  Прежний порядок списка сохраняется; пробельный запрос равнозначен пустому.
- S102: то же поле/правило в окне добавления шаблона в план. Крестик очищает
  запрос, возвращает полный список и фокус; Tab/Shift+Tab остаются в окне.
- S103: запрос библиотеки хранится в q маршрута и сохраняется при возврате
  из редактора, включая успешное сохранение. Контекст клиента/даты/черновика,
  явный выход и существующие действия карточек сохраняются.
- S104: отсутствие совпадений отличается от пустой библиотеки и сбоя чтения.
  Существующие loading/error/retry не подменяются пустым результатом.
- S105: существующие общие search-иконки/поле/кнопки и Lime-токены, YS Geo,
  текущий акцент; проверка ширины320/390 и desktop1440. Без новых фильтров,
  сортировки, счётчиков, зависимостей и отдельной системы дизайна.
- S106: целевые проверки, положенный общий локальный check, CI актуального
  head, очередь GitHub, выпуск web/подписанного обновления и production-проверка.

API возвращает весь actor-scoped список без пагинации. Поиск работает над
полученными данными и не отправляет запрос на каждую букву. Не меняются API,
БД, права, сохранение шаблонов/планов, история, клиентские экраны и флаги.
Общая реализация поля/сопоставления нужна двум существующим потребителям;
клиентский поиск и его стили не рефакторятся.

## Итерация1 — 09.11.2026 — Codex / OpenAI

Задача: реализовать утверждённый простой поиск и полностью опубликовать.
База: bd2b8452, отдельная ветка feat/trainer-template-search-20261109.
Расхождения: поиск отсутствовал в обоих тренерских входах; новый input должен
войти в существующий focus trap. Возврат редактора без контекста терял бы q.
Сделано: зафиксированы план, границы и карта приёмки; YAFIT-707 создан/прочитан.
Решение: локальный фильтр по названию и q с replace без потери location.state;
передача только строки поиска в существующий возврат редактора.
Отвергнуто: серверный поиск, теги/фильтры, новый state-store и запись в БД —
не требуются для полного уже загруженного списка.
Проверка: актуальный main и чтение реализации list; интерактивный макет прошёл
поиск/очистку/пустой результат и геометрию320/390. Это не приёмка приложения.
Открыто: реализация, проверки, CI, очередь и выпуск впереди.
Дальше: общая строка поиска, оба потребителя, целевые проверки и приёмка.

## Итерация2 — 09.11.2026 — Codex / OpenAI

Сделано: общее поле/нормализация в shared/workout-template-search; библиотека
хранит q через replace с сохранением location.state; существующий возврат
редактора передаёт только строку запроса. Picker использует тот же фильтр,
включает input в детерминированный Tab-цикл. Общая геометрия search и иконки
переиспользованы из clients-search; Lime-адаптация ограничена новым полем.
Расхождения: первый запуск браузерного стенда был пропущен без его штатного
FIT_SCHEDULE_V2_VISUAL; не засчитывался. WebKit пропускал нативную кнопку
при Shift+Tab из нового input: существующий trap теперь переводит каждый
Tab/Shift+Tab по фактическим доступным контролам. Сохранение не затрагивалось.
Проверка: tsc passed; компонентные13/13, включая возврат запроса после save;
браузерный сценарий2/2 Chromium/WebKit после правки фокуса. Проверены е/ё,
регистр/пробелы/пустой результат/очистка, геометрия320/390/1440, неизменность
упражнений после save и отсутствие записи workout при поиске/выборе.
Первый lint выявил нетипизированный location.state; передаётся как unknown,
содержимое не преобразуется. Локальные зависимости скопированы отдельно,
чтобы Vite не запрещал шрифты за пределами корня symlink-зависимостей.
Открыто: общий check, существующие template-регрессии, CI и production.
Дальше: закончить проверки и выпуск; конкретные head/runs — в YAFIT-707.
