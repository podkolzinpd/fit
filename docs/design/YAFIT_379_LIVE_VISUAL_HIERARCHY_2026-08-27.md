# YAFIT-379: визуальная иерархия Live-тренировки

Дата: 27 августа 2026 г.  
Статус: готово

## Зафиксированный объём задачи

1. Статус тренировки показывается один раз — в общей шапке Live.
2. Упражнения не дублируют статус `Выполняется` / `Запланировано`.
3. Компактное действие `Ввести` становится единственным заполненным
   коралловым действием текущего подхода.
4. `＋ Подход` остаётся нейтральным вторичным действием.
5. Обычный таймер тренировки нейтрален; коралловый акцент и пульсация
   появляются только во время активного отдыха.

Данные тренировки, порядок, подтверждение подходов, RPC и расчёт времени не
меняются.

## Матрица приёмки

| Пункт | Видимый результат | Проверка | Статус |
|---|---|---|---|
| 1 | В Live один статус в общей шапке | Playwright, активная тренировка | Готово |
| 2 | В шапках упражнений нет дублирующих статусов | Playwright, текущее и следующее упражнение | Готово |
| 3 | `Ввести` — компактный primary с touch-target не меньше 44 px | Playwright, второй подход | Готово |
| 4 | `＋ Подход` не конкурирует с подтверждением | Вычисленные стили | Готово |
| 5 | Таймер меняет акцент только при старте отдыха | Playwright до/после подтверждения подхода | Готово |

## Проверка

- Целевой Playwright-сценарий Live прошёл полностью: один общий статус,
  нейтральный таймер до отдыха, коралловый акцент во время отдыха, primary
  `Ввести` высотой не меньше 44 px и нейтральный `＋ Подход`.
- Полный `npm run check` прошёл: lint, typecheck, 835 unit-тестов, coverage,
  57 infra-policy проверок, 206 API-тестов и production build.

Другие экраны и следующие пункты дизайн-аудита в YAFIT-379 не входят.
