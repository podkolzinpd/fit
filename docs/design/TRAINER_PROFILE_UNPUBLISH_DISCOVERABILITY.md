# Снятие анкеты тренера с публикации

Проверка актуального `main` показала: backend и действие снятия уже существуют,
но кнопка спрятана внутри свёрнутого блока «Публикация». Из-за этого тренер не
видит, как убрать анкету.

## План и acceptance

1. В опубликованной анкете кнопка «Снять с публикации» видна сразу, без
   раскрытия дополнительных настроек.
2. Перед действием Fit показывает короткое подтверждение с точным результатом:
   анкета исчезнет из каталога и по публичной ссылке, заполненные данные
   сохранятся.
3. Пока запрос выполняется, повторное нажатие заблокировано и виден статус
   «Снимаем с публикации…».
4. После успеха опубликованная версия и кнопка исчезают, а сохранённый черновик
   остаётся доступен для редактирования и повторной публикации.
5. Ошибка остаётся на текущем экране и показывается существующим `SaveStatus`.
6. Каталог, публичная анкета, чат, данные тренера и ИИ-сценарии не меняются.
