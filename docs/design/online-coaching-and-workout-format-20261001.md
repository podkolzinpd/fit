# Онлайн-сопровождение и формат тренировки — утверждённый план

Статус: утверждён владельцем продукта 1 октября 2026 года. Пункты ниже —
неизменяемый acceptance-чеклист двух последовательных PR.

## Что добавляем

### 1. Два типа абонемента

На существующем экране **«Новый абонемент»** тренер выбирает:

- **Пакет занятий**
- **Онлайн-сопровождение**

Для пакета занятий остаются текущие поля:

- количество занятий;
- стоимость;
- даты;
- оплаты.

Для онлайн-сопровождения:

- название;
- дата начала;
- дата окончания;
- стоимость;
- оплаты.

У онлайн-сопровождения нет количества занятий и остатка.

### 2. Формат тренировки

На существующем экране создания тренировки, сразу после даты и времени:

**Формат**

`Самостоятельно` | `С тренером`

Значение подставляется автоматически:

- есть только пакет занятий → `С тренером`;
- есть онлайн-сопровождение → `Самостоятельно`;
- есть и пакет, и сопровождение → `Самостоятельно`;
- тренировку создал спортсмен → всегда `Самостоятельно`.

Тренер может переключить формат перед сохранением. Отдельных настроек в
профиле не добавляем.

### 3. Простое правило списания

При завершении тренировки:

- `Самостоятельно` → ничего не списываем;
- `С тренером` + есть пакет занятий → списываем одно занятие;
- `С тренером` + пакета нет → тренировка сохраняется без списания;
- онлайн-сопровождение никогда не уменьшается от тренировок.

Повторное завершение не создаёт повторного списания.

### 4. Что показываем

В тренировке видна короткая метка:

- `Самостоятельно`;
- `С тренером`.

После завершения:

- `Самостоятельно · без списания`;
- `Занятие списано · осталось 4`;
- `Не списано · нет абонемента`.

Спортсмен видит формат, но не может его менять.

### 5. Исправление ошибки

Если тренер неправильно выбрал формат, он использует существующее действие
**«Изменить учёт»**:

- списать занятие;
- отменить списание;
- отметить бесплатным или пробным.

Новых экранов для исправлений не создаём.

### 6. Существующие данные

- все текущие абонементы остаются пакетами занятий;
- старые оплаты и списания не меняем;
- завершённые тренировки не пересчитываем;
- новые правила действуют только для новых и незавершённых тренировок.

## Разделение разработки

### PR 1 — онлайн-сопровождение

- новый тип абонемента;
- форма создания;
- карточка тренера;
- карточка клиента;
- оплаты и задолженность;
- отсутствие счётчика занятий.

### PR 2 — формат тренировки

- переключатель на форме;
- автоматическое значение;
- метки для тренера и спортсмена;
- новое правило списания;
- защита от повторного списания;
- проверки на 320, 390 и 430 px.

Никаких дополнительных настроек, автоматических исправлений старой истории,
переносов между абонементами и новых сложных экранов.
