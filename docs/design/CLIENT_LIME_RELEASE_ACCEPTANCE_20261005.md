# Клиентский Lime — приёмка визуального завершения

Дата локальной приёмки: 5 октября 2026 года. Основа — пилот клиентского
приложения только для `budoha1@yandex.ru`. Матрица относится к сериям PR1–10
из [принятого плана](CLIENT_LIME_VISUAL_COMPLETION_20261005.md); PR11 добавляет
сквозные проверки и фиксирует результаты. PR #1435–#1445 слиты после CI;
PR #1452 устранил лимит времени полного WebKit прогона.

## Проверено локально

| Маршрут / состояние | Проверка |
| --- | --- |
| Кабинет, список тренировок, календарь, план, длинные названия | Единая Lime-геометрия, отсутствие вложенных рамок и горизонтального переполнения. |
| Обычный Live, круг и суперсет | Основное действие, вторичные кнопки, прогресс круга, медиа и нижнее завершение остаются видимыми; порядок подходов не изменён. |
| Завершение и история | Полный, частичный и нулевой итог; пояснение калорий отдельно от сетки; последний блок после прокрутки выше навигации. |
| Создание / правка | Голосовой и текстовый вход, изолированные черновики, повторный разбор, исправление и сохранение. |
| Прогресс, цель, достижения | Одиночный период компактный; существующие карточки, прогресс ачивок и их окно без переполнения. |
| Профиль, настройки, финансы, тренеры | Единые поля и действия; работающие переключатели и возврат; одиночная настройка карты тела не занимает всю ширину. |
| Чат, ассистент, листы | Сообщения, меню, короткая высота под клавиатуру; стартовые действия ассистента и голосовая кнопка в Lime-геометрии. |
| Темы и граница пилота | Светлая, тёмная и системная тема; чужой клиент остаётся без `fit-client-lime`, тренерские маршруты не используют клиентский scope. |

Автоматические мобильные сценарии запускаются на 390 и 430 px в WebKit и
Chromium: 102 из 102 сценариев `Client Lime` прошли на итоговой ветке.
Полный `npm run check` прошёл на итоговой ветке: 283 набора и 2 377 тестов,
линтер, TypeScript, инфраструктурные проверки и production-сборка. Падения первой
параллельной проверки PR4 были вызваны таймаутом worker; её повтор с одним
worker и отдельные затронутые тесты прошли. В PR10 локальный ассистент
проверялся с явным development-флагом доступа; production использует свой
существующий флаг и серверные границы данных.

## Production-подтверждение

PR #1445 и #1452 слиты; CI итогового `main` 37376020377 прошёл полностью.
Следующий актуальный commit `7eb6c56fac47fe00b9cdc90f42e87c59026f3dea`
прошёл CI 37378543406 и deployment 37380030323. Deployment подтвердил
206 объектов, активацию шлюза, smoke клиентских маршрутов и ресурсов, а также
readback активной версии. Production-сборка включает
`VITE_CLIENT_LIME_ENABLED=true`; доступ по-прежнему требует серверного
назначения только для проверенного `budoha1@yandex.ru`. Другой клиент и
тренерский интерфейс проверены в автоматической приёмке, реальный вход
другого аккаунта в production вручную не выполнялся.

## Осталась проверка на устройстве

- Пройти на физическом iPhone обе темы, обычную и круговую тренировку,
  настоящую диктовку, системную клавиатуру и safe area. Browser WebKit и
  симулятор не заменяют эту проверку. Локальная попытка обнаружить устройство
  завершилась таймаутом CoreDeviceService, поэтому проверка не заявлена как
  выполненная.
