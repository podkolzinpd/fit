# Fit Lime: очередь незавершённых действий

Пункт 17 плана YAFIT-539, задача YAFIT-556. Колокольчик использует существующую рабочую очередь: вопросы тренеру, дискомфорт, прошлые планы и планирование. Число равно видимым пунктам; при неполной загрузке или ошибке вместо ложного нуля остаются `…` и `—`. Откладывание обновляет очередь и счётчик без дублирования.

Окно очереди на Fit Lime маркируется отдельным классом портала, потому что оно находится вне `.phone-frame`. Лайм используется только для доступного действия и фокуса; остальные строки графитовые. Для тренера без визуального флага портал не получает Fit Lime-класс. Источники рабочих действий и планирования теперь показывают собственные загрузку/ошибку/повтор: сбой одного не скрывает состояние другого, а повтор планирования обновляет все требуемые для него данные.

Открытие тренировки или её планирования из очереди передаёт исходный календарный URL через навигационное состояние. Это сохраняет дату и двухнедельный контекст при возврате, в том числе после перезагрузки вложенного экрана. Проверки охватывают две мокированные пилотные учётки, контроль без Fit Lime, вопрос, планирование, ошибку/повтор, фокус окна и мобильный WebKit. Реальный вход в личные аккаунты остаётся отдельной ручной приёмкой.
