# Fit — Gate 1, задача 2: Onest и компактная типографика

Статус: **принято 2026-08-29**.

Дата: 2026-08-29.

## Результат

Создан отдельный typography specimen:

- `docs/design/preview/monochrome-typography.html`;
- `docs/design/preview/monochrome-typography.css`.

Preview не импортирует `src/styles.css`, React-компоненты, theme tokens или
данные приложения. Палитра Fit не задаётся: light/dark используют системные
CSS-цвета `Canvas` и `CanvasText`, поэтому в этой задаче оценивается только
типографика.

## Шрифт

- Семейство: `Onest`.
- Подключённые веса: 400, 500 и 600.
- Источник preview: официальный Google Fonts CSS API.
- Upstream: `simpals/onest`.
- Лицензия: SIL Open Font License 1.1.
- Кириллица и variable weight 100–900 подтверждены upstream и метаданными
  Google Fonts.

В product bundle внешний CDN этой задачей не добавлялся. Перед применением в
приложении Onest должен быть self-hosted вместе с OFL-файлом, чтобы Capacitor и
offline-сценарии не зависели от сети. Это выполняется только в задаче, где
утверждённая типографика переносится в scoped identity foundation.

## Принятый для проверки набор ролей

| Роль | Размер | Вес | Назначение |
| --- | --- | --- | --- |
| Display | 24 px | 600 | заголовок страницы |
| Title | 18 px | 600 | главный заголовок карточки или шага |
| Section | 16 px | 600 | заголовок секции |
| Body | 14 px | 400 | основной текст |
| UI | 14 px | 500 | действия и controls |
| Caption | 12 px | 500 | метаинформация |
| Numeric | 18 px | 600 | обычное измеримое значение |
| Key number | 48 px | 600 | исключение для главного числа |
| Editable | 16 px | 400 | input/textarea без iOS zoom |

Правило веса:

- 600 — заголовки, иерархия и ключевые числовые данные;
- 500 — controls, active states и компактные labels;
- 400 — body и editable content;
- 600 не используется как универсальный вес интерфейса.

Вес 800 намеренно не используется. Иерархия строится размером, 400/500/600,
line-height и умеренным tracking. Body `14/400` не увеличивается на этом этапе:
его читаемость окончательно проверяется на реальном Client Home.

## Что проверено

Headless Chromium подтвердил:

- `document.fonts.check('16px Onest')` → `true`;
- Display → `24px / 600`;
- Title → `18px / 600`;
- Section → `16px / 600`;
- Body → `14px / 400`;
- Caption → `12px / 500`;
- editable input → `16px / 400`;
- горизонтального overflow нет;
- русский длинный заголовок переносится целыми словами;
- числа используют `font-variant-numeric: tabular-nums`;
- light/dark имеют одну геометрию и одну типографическую шкалу.

## Намеренно не изменено

- `src/` и product CSS;
- текущие light/dark/dark-pilot темы;
- коралловая и фиолетовая палитры;
- shared-компоненты;
- Client Home и другие продуктовые маршруты;
- feature flags и production bundle.

## Решение для приёмки

Нужно оценить только:

1. характер Onest на русской кириллице;
2. достаточность иерархии 24/18/16/14/12;
3. читаемость body 14 px;
4. уместность 600 вместо тяжёлого 700/800;
5. плотность переносов на 390/430 px;
6. различимость UI 14/500 и Caption 12/500;
7. внешний вид tabular numbers.

Палитра, поверхности, кнопки и экранная композиция не являются предметом этой
приёмки. После решения `принять` можно переходить только к Gate 1, задаче 3 —
светлой палитре в том же изолированном preview.
