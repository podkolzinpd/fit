# Исправление ответов анкеты и домашнего оборудования программы

Базовый `main`: `a6adfbce`. Поток: `assistant-ops`. Изменение не затрагивает
БД, UI-композицию, маршруты, роли или сохранение программы.

## Наблюдаемые дефекты

1. На вопрос о времени ответы `40–60`, `60` и `60 минут` обрабатывались
   по-разному; два первых могли возвращать повторное уточнение.
2. На вопрос о дате `завтра` распознавалось, а `сегодня` могло зациклить вопрос.
3. Ответ «дома, гиря 5 кг и резинки» не имел допустимых кодов оборудования в
   ограниченном каталоге программы. Модель могла подменить их гантелями.
4. Для цели снижения веса отсутствие аэробного блока не запускало обязательный
   содержательный пересмотр, если пользователь отдельно не написал слово
   «выносливость».

## Acceptance

- В контексте вопроса о длительности `60`, `60 минут` и диапазоны от 30 до 120
  минут распознаются детерминированно. Диапазон планируется по меньшей границе,
  чтобы каждое занятие гарантированно помещалось в доступное время.
- В контексте даты `сегодня` и `завтра` вычисляются от серверной календарной
  даты так же детерминированно, как «со следующего понедельника».
- `гиря/гири` и `резинка/резинки/эспандер` сохраняются отдельными кодами. В
  ограниченный каталог входят существующие активные упражнения Fit с гирей и
  резинкой; гантели без явного упоминания недоступны для генерации и замены.
- При цели `weight_loss` и отсутствии записанной другой активности программа
  проходит полную пересборку, если модель не добавила доступный аэробный блок.
- Силовая часть при снижении веса сохраняется. Ходьба остаётся валидной
  аэробной работой без оборудования; велотренажёр доступен только когда он
  указан. Гиревые и резиновые упражнения не переименовываются в «кардио».

## Проверка

- точечный проход реального chat-state для `60`, `40-60`, `Сегодня`, «гиря 5 кг
  и резинки»;
- parser/merge unit cases для времени, относительных дат и оборудования;
- source-contract общего каталога упражнений;
- выбор упражнений с гирей/резинкой без гантелей;
- quality signal для снижения веса без аэробной работы и его снятие после
  добавления ходьбы;
- полный API check и корневой `npm run check` перед выпуском.
