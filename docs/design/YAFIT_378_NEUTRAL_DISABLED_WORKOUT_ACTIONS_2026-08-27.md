# YAFIT-378: нейтральные недоступные действия создания тренировки

Дата: 27 августа 2026 г.  
Статус: готово к PR

## Зафиксированный объём задачи

1. На клиентском быстром вводе `Разобрать тренировку` не выглядит коралловым,
   пока поле пустое и действие недоступно.
2. В тренерской форме `Сохранить план` не выглядит ослабленным primary, пока в
   тренировке нет упражнений.
3. После заполнения обязательных данных существующий коралловый primary и
   продуктовая логика остаются без изменений.

## Матрица приёмки

| Пункт | Видимый результат | Проверка | Статус |
|---|---|---|---|
| 1 | Недоступное действие имеет neutral surface, muted-текст и полную непрозрачность | Playwright, быстрый ввод | Готово |
| 2 | Пустую тренировку по-прежнему нельзя сохранить | Playwright WebKit, 390 px | Готово |
| 3 | После ввода текста `Разобрать тренировку` становится доступным primary | Playwright, полный сценарий review | Готово |
| 4 | Правило ограничено экранами создания тренировки и не меняет остальные disabled-состояния | Проверка CSS scope и полный `npm run check` | Готово |

## Доказательства

- Клиентский/быстрый ввод: целевой Playwright-сценарий пройден.
- Тренерская пустая форма: целевой WebKit-сценарий на 390 px пройден.
- Цветовой контракт зафиксирован вычисленными стилями в e2e-тестах.
- Полный `npm run check`: 119 файлов / 832 теста приложения и 22 файла / 206
  тестов API пройдены; lint, typecheck и production build зелёные.

Другие пункты дизайн-аудита в YAFIT-378 не входят.
