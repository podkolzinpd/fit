## Утверждённый план

Итого предлагаю **3 продуктовых PR: два для планирования и один для Live**. Ранее один PR относился только к двум вариантам Live — его сохраняем цельным.

### PR 1. Планирование — исправить ввод и сохранение

Сначала устраняем ошибки, из-за которых можно сохранить неправильные значения.

- Исправить дробный вес: `22,5` и `22.5` должны давать одинаковый результат, не `225`.
- Сделать удобную замену заполненного числа по тапу.
- Enter/«Далее» переводит к следующему полю, а не сохраняет всю тренировку.
- Сохранять последнее введённое значение, даже если пользователь ещё не вышел из поля.
- Проверить вес, повторы, время, дистанцию и частоту гребков.
- Учитывать выбранный способ ввода времени — клавиатура или колесо.
- Защитить несохранённые изменения существующего плана при выходе и перезагрузке. Без скрытого автосохранения на сервер.
- При ошибке ввода выделять соответствующее поле, без дополнительных объясняющих экранов.

**Приёмка:** создание и редактирование → ввод → явное сохранение → повторное открытие. Все значения совпадают; ошибка сети не уничтожает введённое и не создаёт дубль.

### PR 2. Планирование — привести редактор к референсу

После исправления ввода доводим оформление.

- Упорядочить отступы карточек и строк подходов, убрать конфликтующие стили.
- Сохранить высоту полей **48 px**.
- Отцентрировать цифры, сделать единицы измерения небольшими и второстепенными.
- Привести RPE к общей айдентике, убрать системный вид и лишнюю громоздкость.
- Проверить название, клиента, дату, начало и окончание, заметки, настройки и добавление упражнений.
- Проверить открытие окон, возврат фокуса и доступность полей при клавиатуре.

Обязательно сохраняем:

- суперсеты, объединение со следующим, разделение и круги;
- перетягивание блоков;
- свайпы с существующими ограничениями и подтверждениями;
- комментарии, заметки, шаблоны и прошлые результаты.

**Приёмка:** изменение структуры плана не теряет значения. Отдельной настройки «компактный/оригинальный» для планирования пока не добавляем — она согласована для Live.

### PR 3. Live — оригинальный и компактный виды

Один экран с общей механикой, а не две независимые реализации.

**Оформление и настройка**

- «Оригинальный» — по сохранённым размерам и композиции SVG.
- «Компактный» — меньше воздуха и компактнее вторичные блоки.
- В обоих видах поля и галочки остаются **48 px**.
- Переключатель в настройках тренировок; по умолчанию — оригинальный.
- Выбор запоминается для пользователя на устройстве.
- Используем существующие шрифт, цвета и оригинальные иконки.

**Механика**

- Сохраняем суперсеты, круги, перенос, свайпы, заметки, RPE, время и дистанцию.
- Не добавляем новые кнопки «Начать», «Техника» или дополнительные этапы тренировки.
- Смена вида не сбрасывает ввод, подтверждения и таймер.
- Автосохранение не закрывает клавиатуру и не вызывает скачки страницы.
- Исправление выполненного подхода не запускает отдых повторно.
- После окончания отдыха большой таймер возвращается к общему времени, а кнопка отдыха продолжает отрицательный отсчёт.
- Закреплённые элементы не перекрывают поля.

**Приёмка:** оба вида проходят одинаковые сценарии ввода, суперсетов, жестов, отдыха и завершения; клиентский Live не меняется.

### Порядок выпуска

**PR 1 → PR 2 → PR 3.** Проверки входят в каждый PR, отдельный «PR с тестами потом» не нужен.

Новое оформление и выбор вида — только для согласованного тренерского пилота, без расширения списка учёток. После каждого выпуска проверяем опубликованный результат; при регрессии механики следующий выпуск останавливаем.

Сейчас это только общий план — реализацию и выкатку не начинаю.
