## PR 1. Свёрнутая шапка: кнопки и отсчёт отдыха

- Устранить перекрытие кнопок отдыха и завершения.
- Сохранить удобные области нажатия.
- Сделать видимым время отдыха, включая отрицательный отсчёт после окончания.
- Сохранить согласованную логику: отдых закончился → основной таймер показывает общее время тренировки; кнопка отдыха продолжает считать в минус.

Проверка: оба режима, узкие экраны, прокрутка вверх-вниз, активный и завершившийся отдых.

## PR 2. Плавные переходы таймера

- Перенести масштабирование цифр из дизайнерского исходника.
- Убрать скачок размера при включении отдыха.

- Проверить обратный переход и прокрутку во время анимации.

Расчёт времени и существующий механизм отдыха не меняем. Новые кнопки и этапы тренировки не добавляем.

## PR 3. Сворачивание карточек по референсу

- Добавить переход фона свёрнутой карточки.

- Согласовать движение оболочки и содержимого.
- Сохранить введённые значения, фокус и заметки при сворачивании.

Проверка: обычные упражнения, суперсеты, длинные названия, оба режима. Свайпы и перетягивание не должны конфликтовать со сворачиванием.

## PR 4. Закрытие каталога жестом и итоговая проверка

- Добавить перетягивание окна вниз за заголовок по исходнику.
- Разделить жест закрытия и прокрутку списка.
- Исключить случайное выделение заголовка при перетягивании.
- Сохранить закрытие кнопкой, фильтры, поиск и создание упражнения.
- Проверить, что закрытие не вызывает повторного добавления.

После этого — полный повтор регрессионных проверок, визуальное сравнение с handoff и отдельная проверка жестов на телефоне.

Во всех PR сохраняем механику, изоляцию двух учёток и клиентские доработки соседнего чата.

## Приёмка и неподвижные границы

- Переиспользуем CoachLiveV79Timer, LiveRestTimer, WorkoutExerciseHeader,
  ExercisePicker/FitLimeSheetHeader, WorkoutGestures, текущие --lime-* токены,
  YS Geo/Doto и оригинальные экспорты v79. Не создаём второй timer owner.
- Основное действие Live — подтверждение подхода; редкие действия и жесты
  не получают competing primary. Каталог сохраняет существующий single-add.
- Доступ/allowlist не расширяются. Client, planner и посторонний trainer не
  наследуют этот вариант; общие компоненты меняются только через явный prop.
- Сохраняются сохранение/версии/ошибки/retry, заметки, все метрики, суперсеты,
  отмена удаления и перенос. Не переносим демо-Start/Pause/3-2-1/лимит5/reset.
- Полные макеты и исходный коммерческий пакет шрифтов не публикуются.
- Физический телефон проверяется только при доступном устройстве/инструменте;
  отсутствие доступа отмечается явно и не подменяется браузерной эмуляцией.
- Каждый PR: fresh main/открытые PR → baseline → точечные тесты → полный check
  по scope → браузерная/визуальная проверка → зелёный CI → штатный merge.
  Более ранние активные PR выпускаются первыми; клиентские изменения сохраняем.
