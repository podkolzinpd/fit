## Приёмка и неподвижные границы

- Переиспользуем CoachLiveV79Timer, LiveRestTimer, WorkoutExerciseHeader,
  ExercisePicker/FitLimeSheetHeader, WorkoutGestures, текущие --lime-* токены,
  YS Geo/Doto и оригинальные экспорты v79. Не создаём второй timer owner.
- Основное действие Live — подтверждение подхода; редкие действия и жесты
  не получают competing primary. Каталог сохраняет существующий single-add.
- Доступ/allowlist не расширяются. Client, planner и посторонний trainer не
  наследуют этот вариант; общие компоненты меняются только через явный prop.
- Сохраняются сохранение/версии/ошибки/retry, заметки, все метрики, суперсеты,
  отмена удаления и перенос. Не переносим демо-Start/Pause/3-2-1/лимит5/reset.
- Полные макеты и исходный коммерческий пакет шрифтов не публикуются.
- Физический телефон проверяется только при доступном устройстве/инструменте;
  отсутствие доступа отмечается явно и не подменяется браузерной эмуляцией.
- Каждый PR: fresh main/открытые PR → baseline → точечные тесты → полный check
  по scope → браузерная/визуальная проверка → зелёный CI → штатный merge.
  Более ранние активные PR выпускаются первыми; клиентские изменения сохраняем.
