# Компактные итоги тренировки

## Цель

Сделать завершённую тренировку компактной и нейтральной: быстро показать факт тренировки и сохранить самочувствие независимо от того, занимается пользователь с тренером или самостоятельно.

## Зафиксированный результат

1. В шапке завершённой клиентской тренировки показываются статус, фокус тренировки, дата и время — без упоминания автора или получателя итогов.
2. Основные показатели собраны в одну компактную строку: длительность, тоннаж и выполненные подходы. Ниже остаются группы мышц; личный рекорд показывается только при фактическом рекорде.
3. Форма содержит три обязательных ответа: нагрузка RPE 1–10, самочувствие после тренировки, боль или дискомфорт.
4. При боли обязательно уточняются место и интенсивность. При RPE 9–10 обязательно уточняется причина высокой нагрузки.
5. В остальных случаях пользователь может добавить необязательную заметку.
6. Основное действие называется «Сохранить итоги». Тексты про отзыв и отправку тренеру исключены.
7. Сохранённые итоги доступны для изменения и остаются нейтральными для клиента и тренера.
8. Заметка сохраняется независимо от ответа о дискомфорте; существующий API-контракт остаётся совместимым.

## Проверка

- Unit: RPE, нейтральное подтверждение и условная валидация.
- DB: заметка без дискомфорта сохраняется; боль без пояснения по-прежнему отклоняется.
- E2E: клиент сохраняет и редактирует итоги, тренер видит сохранённые данные.
- Visual: 390/430 px, светлая/тёмная тема, длинный русский текст, без наложений и горизонтального скролла.
- Regression: `npm run check`, Supabase reset/tests, очередь PR и production smoke после merge.
