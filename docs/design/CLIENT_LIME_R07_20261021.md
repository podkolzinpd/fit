преждевременный переход420→844 между pointerdown и click. Общий provider

нажатия на фон. Не проверено: физический iPhone/реальная клавиатура.

## Реализация

- Геометрия клавиатуры сохраняется, пока visual viewport остаётся уменьшенным;
  переход фокуса на кнопку сам по себе не разворачивает оболочку.
- Восстановление застрявшей геометрии WebKit с обеими уменьшенными высотами
  сохранено, но не выполняется посреди pointer-жеста.
- Каталог и дата закрываются по намеренно начатому на фоне жесту, а не по
  итоговому click, сместившемуся с кнопки на фон.
- API, autosave/confirm/append, флаги, числовой ввод, DOM-ключи полей,
  управление таймером и механика переноса не меняются.
