## Проверки и выпуск

Перед каждым PR: fresh main, diff, действующие источники и готовое покрытие;
уже реализованное переиспользовать. Проверять светлую/тёмную тему,390/430px,
WebKit и Chromium. Функциональные сценарии не размножать без причины.
Обязательны CI текущего head и опубликованная версия; не выдавать локальный
тест/симулятор за физический iPhone.

Общие потребители: проверка Live select-all, клавиатуры, сохранения галочки при
редактировании, переноса веса, свайпов/DnD и таймера, если меняется общий
компонент. CSS этой серии не меняет их область. Проверить исключённого клиента
и тренера отдельно. Каждый PR содержит законченное видимое изменение.

Неактивный более ранний PR можно обойти после проверки. Активный — дождаться.
