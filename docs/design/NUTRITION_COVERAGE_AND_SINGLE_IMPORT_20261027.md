## Приёмка

1. Огурец, перец, яблоко и мандарин доступны на первой странице даже при
   отсутствии КБЖУ у магазина или недоступности внешнего API. Используется
   полный выбранный raw fruit/vegetable срез официального FNDDS2021-2023 (релиз2024-10-31),
   с FDC ID, исходным описанием и nutrient IDs. Пустые retail-поля не заполняются
   данными от другого продукта: справочные продукты — отдельные карточки.
2. Сохраняются сорта/бренды и предыдущие йогурт/оливье/сыр. Конкретные вкусы,
   способы приготовления и неоднозначные рецептуры не заменяются базовым
   продуктом. Составное название сохраняется в форме своего блюда;
   калории пользователь подтверждает в существующей форме.
3. Ровно одна видимая кнопка «Сканировать штрихкод» сразу открывает системный
   выбор изображения. Android с Camera-плагином использует native Prompt со
   съёмкой/фото; web/iOS — стандартный file chooser без capture. Native-contract изменился,
   нужен новый APK; несовместимый OTA на старую сборку не допускается. Собственного
   import-dialog с «Камера»/«Галерея» нет.
4. Изображение декодируется локально. Synthetic EAN13 в обычном и повёрнутом
   положении распознаётся; API получает код один раз. Отмена не меняет форму,
   pending блокирует повтор; повтор того же файла возможен. После нераспознанного
   изображения доступен прежний ручной ввод кода. На чужую роль/gate-off не
   переносится новый вход.
5. Реальный native-route WebKit: light390/dark430, клавиатура/focus, overflow,
   запрос/выбор/порция/сохранение, invalid/retry/cancel/pending/success сканирования.
   Системный chooser в CI подтверждается filechooser event и свойствами input;
   физическое меню iOS/Android получает отдельный статус.
6. Targeted tests, полный check, exact-head CI, очередь ранних PR, штатный merge,
   production catalog/readback и затронутые mobile bundles. Ничего не объявляется
   выпущенным по одним локальным тестам.

Визуальный референс — текущая NutritionPage: кнопка secondary wide, существующие
палитра/YS Geo/48px, без нового sheet или контролов. Primary в выдаче — выбор
продукта, в порции — сохранение. Доступы, пилоты, БД, LLM/SpeechKit прежние.
Baseline: WebKit light390/dark4302/2, оба варианта import-dialog воспроизведены
и просмотрены. Снимки диагностические, не объявляются visual golden.
