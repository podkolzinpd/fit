# Client Progress: период, анализ и стабильная навигация

Статус: согласовано владельцем продукта 2026-09-09. Реализация ведётся одним
изменением экрана `/me/progress`.

## Пользовательский результат

Клиент выбирает период и сразу видит короткий вывод ИИ за этот же интервал.
Любое действие внутри карты, результатов и фильтров сохраняет текущую позицию
экрана. Ошибка одного источника данных не закрывает остальные разделы.

## Acceptance-чеклист

1. Выбор мышцы, стороны тела, режима карты и возврат к карте периода не
   прокручивают Progress наверх.
2. Раскрытие всех результатов и изменение их фильтров сохраняют позицию экрана.
3. Период, его даты, превью ИИ, свежесть и действие «Открыть анализ» находятся
   в одном верхнем блоке; отдельного нижнего блока и промежуточной прокрутки нет.
4. Точный анализ подписан выбранным периодом. Предыдущий сохранённый анализ
   показывает собственные даты, а новые тренировки и обновление обозначены
   явно. Loading, empty и recoverable error остаются понятными.
5. Порядок клиента: период и анализ → текущая неделя → цель → лучшие результаты
   периода → замеры → карта тела → нагрузка по неделям → регулярность →
   сравнение периодов → бег.
6. Результаты подписаны «Лучшие результаты за период». При изменении периода
   пригодные фильтры сохраняются, недоступные сбрасываются после загрузки
   данных. Возврат из источника открывает прежний раздел и сохраняет параметры.
7. Бег использует общий выбранный период. При наличии беговой истории блок не
   исчезает во время загрузки, ошибки или пустого выбранного интервала.
8. Ошибка замеров локальна для замеров и не закрывает весь экран Progress.
9. Проверены реальные состояния client 390/430, узкий WebKit, light/dark,
   длинный текст, отсутствие overflow, сохранение прокрутки и возвраты.

## Границы

- Переиспользуются текущие Fit period controls, cards, disclosures и summary
  sheet, без новой палитры и компонентной системы.
- Источники данных, расчёты прогресса и prompt ИИ не меняются.
- Trainer Progress сохраняет текущую композицию.
