# Fit Lime: послерелизный аудит этапа 4

Дата: 28 сентября 2026 года. Область: тренерский интерфейс под серверным флагом Fit Lime для двух утверждённых учётных записей. Это аудит выпущенного этапа 4, а не начало этапов 5–6.

## Проверено

- Production-выпуск этапа 4: GitHub Actions `36353301584`, commit `22651941`, успешные сборка, публикация и smoke; главная страница `fit-training.ru` отвечает HTTP 200.
- Локальный визуальный и функциональный прогон на серверно-мокированном pilot/non-pilot контракте: 89 мобильных сценариев, в том числе календарь, задачи, вопросы и сообщения, клиенты, цели, прогресс, профиль, каталог упражнений, создание, карточка и live тренировки, история и ассистент.
- Отдельный обзор 19 тренерских маршрутов при ширине 320 px. Проверяются горизонтальный размер документа и реальные границы элементов управления; для ключевых экранов снимаются скриншоты.
- Линтер, проверка типов, production-сборка и 2057 модульных тестов.

## Найдено и исправлено

1. На ширине 320 px форма тренировки скрывала справа выбор клиента, переключатель типа тренировки и поле времени: родитель обрезал дочерние элементы, поэтому проверка только ширины документа не находила ошибку. Секция получила сжимаемую сетку, а дата и время на узком экране размещаются вертикально.
2. Нижняя панель с четырьмя вкладками на 320 px задавала минимальную ширину каждой ячейки, из-за чего подписи теснились и перекрывались. Ячейки стали сжимаемыми; размеры подписей и пиктограмм адаптированы только для узких экранов Fit Lime.
3. Заголовок недели обрезал год на 320 px. Полный период теперь виден.
4. Подсказка в поле ввода ассистента занимала две строки, но нижняя строка обрезалась. Высота поля увеличена на узком экране.
5. Один сценарный тест безусловно ожидал уже прочитанную подсказку «Понятно». Тест теперь закрывает её только при появлении; редактирование тренировки проверено повторно.

## Граница доказательства

Автоматические тесты подтверждают назначение флага и сохранение старого вида вне пилота на тестовом серверном контракте. Вход в настоящие сессии двух тренеров, их личные данные и iOS-среда владельцев этим прогоном не проверялись. Пункты 5–6 плана не выполнялись.
