# YAFIT-488 — юридические документы и регистрация

## Цель

Опубликовать в Fit понятные условия использования и политику конфиденциальности, сохранять версию принятой редакции, дать пользователю путь запроса удаления аккаунта и убрать Google из интерфейса входа и регистрации без удаления существующих Google-аккаунтов.

## Реализация

1. Публичные маршруты `/legal/terms`, `/legal/privacy` и `/legal/delete-account` доступны без таббара и без обязательного входа для чтения.
2. Нажатие «Создать аккаунт» означает принятие показанных рядом документов. Версии и время сохраняются в отдельной RLS-таблице. Действующий пользователь принимает новую редакцию один раз.
3. В профилях тренера и спортсмена добавлены ссылки на оба документа и удаление аккаунта.
4. Страница удаления создаёт отменяемую заявку. Она ничего не удаляет автоматически, поэтому релиз и тесты не могут удалить аккаунт пользователя.
5. Кнопка Google не показывается ни во входе, ни в регистрации. OAuth-провайдер, callback и существующие Google-аккаунты не удаляются.
6. Политика описывает реальные данные тренировок, замеры, уведомления, аналитику и передачу контекста в Yandex Cloud для функций с ИИ.

## Границы

- Auth-хуки запрещены правилами проекта, поэтому Google убран из интерфейса, а серверный провайдер сохраняется без удаления существующих аккаунтов.
- Yandex ID pilot не блокируется Supabase-согласием: его отдельная сессия пока включается только для ограниченного перенесённого профиля.
- В исходных документах не указаны официальное имя оператора и публичный email. В приложении используется обозначение «Администратор сервиса Fit» и действующий канал обращений из профиля; перед публикацией в сторах реквизиты следует дополнить после их утверждения владельцем продукта.

## Проверка

- SQL/RLS: собственные согласия, изоляция чужих записей, создание и отмена заявки, запрет анонимного доступа.
- UI: Google отсутствует во входе и регистрации, документы доступны в регистрации и профиле, публичное чтение, одноразовый gate, signed-out deletion flow.
- Регрессия: полный `npm run check`, ключевые web/iOS/Android сценарии, неизменность AI-контрактов и сборка production/mobile.
