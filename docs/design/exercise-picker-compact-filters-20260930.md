# Компактные фильтры в выборе упражнений — 30.09.2026

Тикет: YAFIT-469. Последнее решение пользователя уточняет его пункт о поведении панели: после выбора одного условия она закрывается автоматически.

## Подтверждённый вариант 1

> Оставить поиск сверху, а категории и оборудование убрать под кнопку «Фильтры». Рядом показывать выбранные фильтры короткими плашками, например «Спина ×». После выбора фильтра панель закрывается — на экране помещается больше упражнений.

## Границы

Общий picker клиента и тренера в создании, редактировании, копировании, замене и Live. Поиск, фасеты, порядок карточек, техника, выбор нескольких упражнений, создание своего упражнения и API не меняются. Панель фильтров находится внутри существующего окна, без второго модального слоя. Нижнее действие «Добавить N» остаётся доступным.
