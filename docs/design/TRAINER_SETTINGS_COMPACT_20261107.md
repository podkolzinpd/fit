AppLayout для section данного маршрута и адресные переходы существующих тестов.

  unavailable/unknown не маскируются под off. CSS scoped только trainer settings.

### PR3 — установка, уведомления, формы и помощь

- SET104: существующие push loading/permission/denied/restore/working/error/
  unsupported/install/native, только поддерживаемые категории. Известное cached
  значение остаётся при ошибке; unknown не изображается выключенным. Транспорт,
  opt-out и механизм тестовой отправки не меняются, доставка не обещается.
- SET106: контекст установки по платформе; installed/native без повторного CTA;
  установка и разрешение push разделены, инструкция доступна через помощь.
- SET108-FORM: имя/фамилия/timezone с кнопкой сохранения, feedback и документы,
  прежние delete request/cancel и logout. Pending без дублей, ошибка без потери
  текста, отмена возвращает прежние значения. Без новых обязательных подтверждений.
- SET111: итоговые опубликованные assets/API/совместимый OTA и экраны; отдельный
  PR только ради приёмки не создаётся. Проверка физического телефона отдельно
  от Chromium/WebKit и не объявляется пройденной по эмуляции.

После каждого PR — применимые проверки и обязательный exact-head CI.
