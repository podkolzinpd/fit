# Компактные настройки тренера — 07.11.2026

Владелец разрешил весь пакет из трёх PR: реализацию, самостоятельные слияния,
выпуск и проверку опубликованной версии. Источник — просмотренное видео и
согласованные эскизы настроек. Главная компактная; переключатели сохраняются
внутри разделов и обязательно видны выключенными. Клиентские экраны прежние.
Фото/описания упражнений остаются отдельным бэклогом и этим пакетом не чинятся.

## Границы и архитектура

Поток: product. База: main98d2a0904506675ea9e03c56c95cb536f4e5dd6d.
Пользовательский результат: найти нужную настройку на коротком главном экране,
открыть один раздел и изменить прежнее значение без потери выбора/механики.
Таблицы/API/repository/transport/migrations/rollout/defaults не меняются.
Существующий маршрут /profile/settings; выбранный раздел — query section,
сохранение через прежние hooks/components. Права trainer/corporate capability,
платформенные возможности push, личные/device ключи и серверная плотность прежние.
Не затрагиваем Live/таймеры/факты/54–48, клиентский редизайн/общие настройки
спортсмена, backend, каталог и права. Shared файлы: только scoped scroll-dependency
AppLayout для section данного маршрута и адресные переходы существующих тестов.
Зависимостей нет; применяется актуальный main с сохранением параллельных правок.

## Согласованный план

### PR1 — структура и переходы

- SET101: короткий обзор «Тренировки», «Расписание», «Уведомления», «Оформление»;
  текущая сводка там, где значение уже известно, без выдуманного push-success.
- SET107: прежние упражнения/код подключения и capability-gated администрирование.
- SET108-NAV: аккаунт/помощь отдельно, прежний выход снизу.
- SET109: внутренний раздел сразу рабочий, back/swipe/system-back и прямой URL;
  новый раздел открывается сверху без влияния на календарь/клиентские маршруты.

### PR2 — параметры и видимые off-switches

- SET102: Original/Compact, анимация, ввод времени колёсиком, отдых в плане, RPE;
  все прежние getters/setters, исходные defaults и ключи. «Отдых в плане» не
  управляет таймером Live; изменение подписи не меняет механику.
- SET103: плотность календарной сетки, прежние pending/error/retry/rollback.
- SET105: тема с фактической областью действия, карта тела; без текста про пилот.
- SET110: off заметен на поверхности: трек/контур и светлый бегунок слева,
  label не тускнеет; on акцент#D1FD2D. Тап-target>=44, клавиатура/focus прежние;
  unavailable/unknown не маскируются под off. CSS scoped только trainer settings.

### PR3 — установка, уведомления, формы и помощь

- SET104: существующие push loading/permission/denied/restore/working/error/
  unsupported/install/native, только поддерживаемые категории. Известное cached
  значение остаётся при ошибке; unknown не изображается выключенным. Транспорт,
  opt-out и механизм тестовой отправки не меняются, доставка не обещается.
- SET106: контекст установки по платформе; installed/native без повторного CTA;
  установка и разрешение push разделены, инструкция доступна через помощь.
- SET108-FORM: имя/фамилия/timezone с кнопкой сохранения, feedback и документы,
  прежние delete request/cancel и logout. Pending без дублей, ошибка без потери
  текста, отмена возвращает прежние значения. Без новых обязательных подтверждений.
- SET111: итоговые опубликованные assets/API/совместимый OTA и экраны; отдельный
  PR только ради приёмки не создаётся. Проверка физического телефона отдельно
  от Chromium/WebKit и не объявляется пройденной по эмуляции.

После каждого PR — применимые проверки и обязательный exact-head CI.
Порядок production сериализуется с текущим владельцем окна. Чужая незавершённая
публикация/readback не прерывается. Старый CI не выдаётся за проверку нового head.
