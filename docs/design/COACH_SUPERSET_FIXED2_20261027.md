# Coach Live: суперсеты, исходные fixed2 / 4 PR

Согласовано владельцем 27.10.2026: реализовать, проверить, слить и выпустить
все четыре PR самостоятельно. Только исходные две тренерские учётки через
существующий `isCoachLiveV79Enabled(actor)`. Allowlist не расширяется.
Клиентский интерфейс и остальные тренеры сохраняют прежний путь.

## Проверка существующего

Baseline: main `57423a94350f237fa99e974781d5baca31c4349e`.
Маршрут `/workouts/:workoutId/live`, trainer, coach-v79 fixed2.
В опубликованном интерфейсе на синтетических данных проверены начало,
середина и завершение в original/compact, WebKit390×844. API аккаунтов
изолированы. Отдельный точный SVG суперсета не обнаружен: компоновка
адаптирует утверждённые Fit-компоненты, не объявляется новым макетом дизайнера.

Уже работает: объединение/разделение, атомарные круги, подтверждение,
отдых, перенос группы, локальные черновики и сохранение фактов.
Переиспользуем: `WorkoutExerciseHeader`, `WorkoutFoldBody`, `OverflowMenu`,
существующие жесты и поля, `--lime-*`, YS Geo и согласованные размеры.
Меняем: представление группы, расположение управления, доступность заметок
и действий между кругами, плавность сворачивания и финальный итог.
Не проверено: реальный OAuth и физический iPhone; WebKit не заменяет устройство.

## PR 1. Постоянная компоновка

- Постоянная шапка группы и правые места меню/переноса во всех состояниях.
- Названия участников остаются читаемыми; добавление круга после содержимого.
- Подпись параметров относится к текущему кругу; будущие круги спокойнее.
- Оригинальные поля54px, компактные48px; без новых цветов и основного CTA.

## PR 2. Постоянные действия и заметки

- Действия упражнения доступны во всех кругах через существующие обработчики.
- Заголовок сворачивает содержание, инструкция открывается отдельным действием.
- Заметка доступна в любом раскрытом круге, общий draft и сохранение по exerciseId.
- Сохраняются ограничения объединения/удаления, перенос всей группы и таймер.

## PR 3. Переходы и завершение

- Плавное сворачивание с сохранёнными формами, черновиками и фокусом.
- Завершённый круг уступает место следующему без принудительного закрытия ввода.
- Итог группы: завершённые/все круги, названия и раскрытие результатов.
- Добавить круг после завершения можно внутри раскрытой группы.

## PR 4. Приёмка и выпуск

- Начало, частичное выполнение, следующий круг, отдых и завершение в обоих видах.
- Заметки, редактирование результата, reload, добавление круга после завершения.
- Свайпы/подтверждение удаления, перенос, объединение и разделение, ошибки/retry.
- Узкий WebKit, клавиатура, safe area, длинные названия, reduced motion, overflow.
- Gate-on двух тренеров и gate-off другого тренера; сохранность клиента.
- Зелёные обязательные CI, штатный merge, проверка официального public bundle;
  финальная подписанная OTA и свежая сборка/установка/запуск iOS simulator.

## Неподвижные границы

Не меняются API, БД, порядок выполнения, расчёт времени, запуск/минус отдыха,
подтверждение и сохранение фактов, правила допустимого удаления и возможности
группировки. Настройка original/compact остаётся прежней. Каждый PR содержит
свои целевые проверки; четвёртый проверяет полный цикл. Перед каждым следующим
PR — сверка с новым main и очередью параллельных изменений.
