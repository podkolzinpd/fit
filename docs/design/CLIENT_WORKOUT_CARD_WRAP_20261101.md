# Карточка истории спортсмена: перенос заголовка — 01.11.2026

Задача: по скриншоту владельца устранить разрыв «Тренировка» рядом с
«Личный рекорд», статусом и копированием в истории спортсмена.
Область: существующая клиентская Lime-карточка `/me/workouts`, без изменения
данных, расчётов, навигации, флагов и общего тренерского оформления.
Это отдельное исправление вёрстки, не следующий этап очистки MC1–MC8.

## Критерии

- CW1: обычное «Тренировка» и дата не сжимаются бейджами на390px.
- CW2: рекорд/статус остаются видимыми, копирование доступно с областью44px;
  заголовок, дата, бейджи и кнопка не перекрываются, переход копирования прежний.
- CW3: длинное валидное название120символов не выходит за карточку;
  Chromium/WebKit, светлая/тёмная темы и360/390/430px проверяются по геометрии.
