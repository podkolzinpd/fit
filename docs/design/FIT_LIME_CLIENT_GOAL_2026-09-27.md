# Fit Lime: цель и этапы клиента

Пункт 23 плана YAFIT-539, задача YAFIT-562. Пилотная тёмно-лаймовая айдентика добавлена только на тренерский `/clients/:clientId/goal` при двух серверных флагах; клиентская цель, карточка и дальнейшие разделы остаются в своих границах.

Используются существующие цель, критерии, этапы, даты, версии, подтверждения удаления/архива и формы. Текущий этап читается по текстовому статусу и контуру, завершённый не исчезает. Пустая цель остаётся создаваемой без ИИ-критериев, ошибка загрузки показывает повтор. Цвет ошибки или опасного действия не заменяется лаймом.

Проверены два серверно-мокированных пилотных профиля, непилотный тренер, прямой вход и возврат, текущий/пустой этап, создание, ошибка/повтор, мобильный Chromium и iPhone WebKit. Полный `npm run check` выполняется перед PR. Реальный вход в обе учётные записи отдельно после публикации.
