# Client Lime — выпуск персонального пилота

## Граница выпуска

Только клиентское приложение, только существующий auth profile пользователя
budoha1@yandex.ru. Светлая, тёмная и системная темы доступны в настройках.
Тренерские флаги, данные, маршруты и бизнес-операции не меняются.

## До включения

1. Получить разрешение автоматической проверки на публикацию в существующий
   remote podkolzinpd/fit. Общая команда владельца на реализацию и выпуск есть;
   автоматическая проверка отдельно запросила подтверждение конкретного remote.
2. Разрешить указанную учётку в её существующий auth profile UUID через доверенный
   серверный источник. Не использовать ID карточки спортсмена, догадку, email из
   localStorage или тестовый UUID. Если достоверное сопоставление недоступно,
   оставить флаг выключенным и зафиксировать блокировку.
3. В первых четырёх выпусках VITE_CLIENT_LIME_ENABLED остаётся false.
4. После общей приёмки задать ровно один проверенный UUID в repository variable
   VITE_CLIENT_LIME_PILOT_USER_IDS, включить VITE_CLIENT_LIME_ENABLED=true и
   выполнить штатную сборку/выкладку Yandex frontend с зелёного текущего main.
   Изменение переменных само по себе сайт не обновляет.
5. Проверить deployment SHA и артефакты. На опубликованной версии проверить
   budoha1: темы, перезагрузку, основные разделы, завершение тренировки, выход и
   повторный вход. Отдельно проверить другой клиентский аккаунт и тренера.
   Browser production-проверка пока блокируется административной политикой CUA;
   локальные mock-сценарии её не заменяют и блокировка не обходится.

## Откат

Установить VITE_CLIENT_LIME_ENABLED=false и штатно перевыпустить проверенный main.
Single-ID gate перестанет назначать класс и переключатель Lime. Данные тренировок
и учётки не затрагиваются; прежняя тема приложения применяется автоматически.
Локально сохранённый выбор Lime останется per-actor для возможного возврата.
При проблеме самого релиза использовать существующий проверенный rollback
frontend артефакта, а не ручное редактирование production файлов.
