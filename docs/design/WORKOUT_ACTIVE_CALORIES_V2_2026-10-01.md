# Оценка активных калорий FIT — утверждённый план

Итоговый план — **4 PR в строгом порядке**. Сначала делаем достоверными минуты и источник данных; только потом меняем коэффициенты. Цель — обоснованная оценка **активных** калорий, а не совпадение с цифрой часов.

### PR 1. Достоверность факта и времени

- Для времени, дистанции и RPE различать: человек внёс фактическое значение или FIT скопировал план при подтверждении подхода. Все пути записи — Live, быстрое завершение, редактирование истории и тренерская запись — должны соблюдать одно правило. Старым записям, где источник восстановить нельзя, присвоить статус «неизвестно», а не «измерено».
- Привести длительность к одному значению в секундах: не складывать минуты и секунды, если они представляют одно время.
- Проверять согласованность времени подходов с общей длительностью, переход через полночь и тренировки дольше трёх часов. Вместо безусловного ограничения 180 минут — проверка неправдоподобных значений.
- Для веса брать известное значение на дату тренировки, не подменяя его более поздним измерением. **Текущие опубликованные калории этот PR не меняет.**

Критерий готовности: тестами покрыты фактическое и унаследованное время, дистанция и RPE; пропущенные и противоречивые данные; все способы завершить тренировку.

### PR 2. Новая формула — сначала скрытый расчёт

Версию 2 считать рядом с нынешней, **не показывая пользователю и не перезаписывая результат версии 1**.

- Считать выполненные упражнения отдельно и складывать результат. Не распространять нагрузку одного интервального блока или тяжёлого упражнения на всю тренировку.
- Для продолжительного кардио использовать подтверждённое время работы. Остаток общего времени не объявлять автоматически кардио: это могут быть отдых, настройка тренажёра или пауза.
- Использовать дистанцию **по назначению**: для бега и ходьбы вместе со временем вычислять правдоподобный темп и выбирать диапазон нагрузки; для гребли учитывать темп только при понятном типе измерения. Дистанцию велотренажёра хранить для результата и проверки данных, но не переводить напрямую в калории — без сопротивления это невозможно.
- Задать проверенные группы нагрузки для известных кардиоупражнений, силовой работы и восстановления. Для пользовательских и неоднозначных упражнений — консервативное правило без догадки по одному лишь полю «повторы/секунды/км».
- Плановый RPE не считать фактической интенсивностью; фактический RPE использовать лишь как грубую поправку. Сохранять правило активных калорий — без энергии покоя.

Критерий готовности: воспроизводимые расчёты для велосипеда, бега разного темпа, ходьбы, гребли, интервалов с паузами, смешанной силовой и растяжки. Формула не должна ни автоматически удваивать всё кардио, ни завышать лёгкую работу.

### PR 3. Минимальные изменения ввода и объяснение результата

- Если для кардио указана дистанция, но нет подтверждённого времени, при завершении предложить внести длительность. Если человек пропускает — **не показывать выдуманное число калорий**.
- Ясно подписать результат: «Оценка активных калорий FIT» и коротко указать основу — например, «по времени и темпу» либо «приблизительно, без данных об интенсивности».
- Не добавлять сейчас обязательные ватты, наклон дорожки или подключение часов. Это отдельные улучшения после проверки, что базовый ввод и формула работают.

Критерий готовности: человеку понятно, почему число показано или отсутствует; сохранение тренировки не блокируется из-за отсутствия данных для калорий.

### PR 4. Проверка на данных и выпуск

- Сравнить старую и новую версии на обезличенных тренировках по видам нагрузки; вручную разобрать крупные расхождения и подозрительно высокие значения.
- Для нескольких тренировок с часами сверить одинаковые интервалы и **активные**, а не общие калории. Часы использовать как сигнал для расследования, не как абсолютный эталон.
- Выпускать новую версию управляемо, с возможностью быстро вернуть прежний расчёт. После выпуска контролировать пропуски оценки и выбросы по видам упражнений.
- **Исторические калории не пересчитывать автоматически.** Когда станет ясно, сколько старых тренировок имеют достоверные данные, отдельно предложить политику пересчёта.

Поля мощности, наклона и данные часов — возможный следующий этап, но не условие этих четырёх PR. Самая важная проверка перед выпуском: для каждой показанной оценки мы можем ответить, **какие минуты были реально выполнены, какая нагрузка применена и откуда взялись исходные данные**.
