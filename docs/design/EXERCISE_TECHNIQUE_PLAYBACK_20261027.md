# Видео техники: автозапуск, запуск вручную и повтор

Согласовано владельцем 27.10.2026. YAFIT-663. Поток: product. База: main57423a94.
Одна задача, ветка и PR. Исходная причина на физическом iPhone не установлена:
настройка пользователя неизвестна; подтверждён отдельный воспроизводимый дефект
при асинхронной выдаче ссылки и prefers-reduced-motion.

## Неизменяемый план

1. При открытии техники сразу запускаем видео независимо от «Уменьшения движения».
2. Пока воспроизведение не началось, показываем кнопку ▶: iPhone всё равно может ограничить автозапуск.
3. При ошибке загрузки показываем «Повторить».

Довести до выпуска и проверки production. Без лишних доработок.

## Дизайн и границы

Референс: действующее окно «Техника», исходные записи и каталог упражнений.
Единственное primary внутри медиа — запуск либо повтор в состоянии ошибки.
Существующая оболочка/геометрия/темы окна сохраняются. Play использует общий
SVG и текущий размер52 с ограничением размером медиа; ошибка — короткая подпись
и существующее secondary. В маленьком Live media44/48/72 используется иконка
повтора с доступным названием; текстовая плашка туда не переносится.
Это approved-adaptation состояния существующего проигрывателя, не новый экран.
Карта состояний: разрешение ссылки → загрузка → playing; блокировка автозапуска
→ ручной запуск; ошибка выдачи/файла/таймаут → ограниченный auto retry → явный
ручной повтор. Закрытие/возврат и смена упражнения остаются прежними.

Системное reduced-motion сохраняется для интерфейсных эффектов; исключение
касается обучающего видео. Предпочтение «Анимация в Live», пилоты и плотность
не меняются. Не менять API, IAM/ACL, bucket, файлы медиа, БД, историю,
сохранение тренировок, таймеры, SpeechKit, маршруты и главные страницы.
