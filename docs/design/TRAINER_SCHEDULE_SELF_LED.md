# Самостоятельное выполнение назначения в расписании тренера

Статус: реализовано и локально принято 2026-09-18; готово к production rollout.

## Зафиксированный план

1. Сохранять автора начала и завершения тренировки.
2. Считать тренировку самостоятельной, только если её назначил тренер, а начал и завершил спортсмен.
3. Старые тренировки без этих данных не перекрашивать — ничего не угадывать.
4. Передать признак одинаково через Supabase и Yandex.
5. Для самостоятельного выполнения использовать спокойный холодный серо-голубой оттенок: лёгкий фон, чуть более заметная граница и подпись «Самостоятельно» тем же тоном; в тёмной теме — глубокий графитово-синий фон.
6. Не смешивать происхождение со статусом: зелёный остаётся завершением, янтарный — текущим или частичным выполнением, серый — отменой; при частичном самостоятельном выполнении предупреждающий статус сохраняется, а «Самостоятельно» показывается текстом.
7. Старые и новые записи, обе темы, мобильный WebKit и desktop проверяются до PR; после полного зелёного CI изменение самостоятельно сливается и проверяется в production.

## Границы задачи

- Поток: `product`.
- Пользовательский результат: тренер сразу отличает в подробном расписании дня своё проведённое занятие от назначения, которое спортсмен выполнил самостоятельно.
- Базовый `main`: `ee67239d` (#1035).
- Зависит от PR: нет.
- Затрагиваемые таблицы/API: `public.workouts`, workout list/detail и Live start/finish обоих backend.
- Общий repository-контракт: nullable `startedBy` и `completedBy`; отсутствие значения означает, что происхождение выполнения неизвестно.
- Supabase implementation: additive migration, actor-aware start/finish, list/detail mapping.
- Yandex implementation: numbered additive migration, actor-aware Live start/finish, training-data mapping и tenant migration profile closure.
- Feature flag: не нужен; старые строки безопасно остаются без нового оттенка.
- Запрещено: выводить догадки по `updated_by`, перекрашивать недельный обзор или менять lifecycle тренировки.

## Матрица приёмки

| Состояние | Видимый результат | Проверка |
| --- | --- | --- |
| Назначил тренер, начал и завершил клиент | Серо-голубая карточка с текстом «Самостоятельно» | Supabase/Yandex contract + component/e2e |
| Назначил и провёл тренер | Прежняя карточка и статус | Supabase/Yandex contract + component |
| Самостоятельную тренировку создал клиент | Не выдаётся за назначение тренера | Domain/component |
| Выполнение частичное | Самостоятельность видна текстом, предупреждающая семантика не теряется | Component + visual |
| Старые `null`-поля | Прежнее оформление без догадки | Migration/domain |
| Loading / empty / error | Экран дня сохраняет существующее поведение | Component/e2e |
| 390 / 430 / 1440 px, light/dark | Нет переполнения, наложений и разъезда текста | Visual baselines |
