# Окно победителю конкурса — 2026-09-28

Контекст: конкурс среди коллег «до 25.09.2026 среди всех, кто пройдёт хотя бы
одну тренировку — разыграем персональную тренировку с Иваном, бренд-тренером».
Yandex ID не передаёт Fit почту, в профилях у большинства только имя, поэтому
связаться с победителем можно только через само приложение.

## Решение

Одноразовое модальное окно вместо чата: полноценный support-чат требует схемы,
API на двух backend и записи в production БД. Окно — только frontend, ответ
идёт через существующую обратную связь, где автор сообщения известен.

## Acceptance

1. Окно видно только при `VITE_CONTEST_WINNER_ENABLED=true` и UUID текущего
   пользователя в `VITE_CONTEST_WINNER_PILOT_USER_IDS` — unit-тесты флага,
   `AppLayout.test.tsx`.
2. Обе роли, любой рабочий экран; не показывается в Live, форме тренировки и
   чате — `AppLayout.test.tsx`.
3. Контакт отправляется одной записью обратной связи; повторная отправка
   заблокирована pending-состоянием — component test, локальная БД.
4. Ошибка сохраняет введённый контакт и даёт «Повторить» — component test,
   скриншот ошибки.
5. «Позже»/Escape скрывают до следующего запуска; после отправки окно больше
   не появляется для этого пользователя на устройстве — component test,
   Playwright reload.
6. После 13.10.2026 00:00 МСК окно не показывается — component test.
7. Визуально: WebKit 390 light/dark, 430, trainer 1440; поле 16 px, actions
   48 px, без горизонтального overflow.

## Вне scope

Чат поддержки, push-уведомление победителю, серверное хранение отметки
«прочитано», iOS-сборка (TestFlight не раздаётся).
