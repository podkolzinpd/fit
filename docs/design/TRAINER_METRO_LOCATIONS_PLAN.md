# Станции метро в анкетах тренеров

## Результат

Тренер сохраняет несколько станций московского метро и несколько мест,
введённых вручную. Спортсмен видит их в каталоге и публичной анкете и может
отфильтровать тренеров по станции.

## Границы

- Существующее поле `city` не меняется.
- Метро и ручные места необязательны и не влияют на публикацию.
- Старые draft/published JSON читаются с пустыми списками без записи в БД.
- Публикация и `listed_in_catalog` существующих анкет не меняются миграцией.
- Карта, геолокация, рейтинг, отзывы и ИИ-подбор не входят в задачу.

## Выпуск

- Добавить `metroStationIds` и `customLocations` в совместимый контракт анкеты.
- Добавить версионируемый справочник действующих станций метро Москвы.
- Добавить фильтр каталога по одной или нескольким станциям с логикой OR.
- Реализовать одинаковый контракт Supabase и Yandex.
- Проверить старую заполненную анкету без новых полей, сохранение новых полей,
  повторную публикацию и пагинацию каталога.

### PR 2. Интерфейс

- Добавить поиск и множественный выбор станций в редактирование анкеты.
- Добавить ручной список клуба, района или адреса.
- Показывать места компактно в каталоге и полностью в публичной анкете.
- Добавить фильтр каталога по метро с сохранением состояния и возврата.
- Проверить мобильную вёрстку, светлую/тёмную темы, каталог, чат и ИИ-регрессии.

## Критерий совместимости

Существующая заполненная и опубликованная анкета до добавления метро выглядит,
открывается, находится в каталоге, редактируется и публикуется повторно без
изменения прежних полей и видимости.
