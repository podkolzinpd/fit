# Голосовой ввод: стабильный резервный канал

Статус: реализовано и локально проверено, 2026-09-14.

## Подтверждённая причина

Основной потоковый SpeechKit relay не устанавливает соединение. После его ошибки интерфейс корректно переключается на локальный Whisper, но браузерная загрузка закреплённой модели с Hugging Face блокируется CORS на промежуточном redirect. Из-за последовательного отказа обоих каналов голос не доходит до существующего разбора тренировки.

Отдельно глобальный цвет `strong` перекрывает цвет ошибки внутри тёмной голосовой карточки, поэтому сообщение почти не читается.

## Изменение

1. SpeechKit остаётся первым каналом; запись, transcript и разбор тренировки не меняются.
2. Резервная модель `ggml-base-q5_1` раздаётся из отдельного публичного Supabase Storage bucket по неизменяемому пути. В bucket лежит только публичная upstream-модель; пользовательское аудио туда не отправляется.
3. Ручной production workflow сверяет размер и SHA-256 модели до загрузки и после чтения с публичного URL, а также проверяет CORS для production origin.
4. Ошибка на Client Home и Trainer Today получает читаемый цвет, не меняя композицию voice-first карточки. Повтор запускается той же основной кнопкой.

## Не меняется

- parser, сопоставление упражнений и сохранение тренировок;
- основной экран и порядок действий;
- старый unmanaged relay и другие backend-маршруты.

## Проверка

- unit/component: стабильный URL, cache key, fallback и retry;
- WebKit: контраст и отсутствие горизонтального переполнения на 390/430 px;
- полный repository check;
- production: размер, hash и CORS модели, затем Vercel и свежая iOS Release-сборка из merged `main`.
