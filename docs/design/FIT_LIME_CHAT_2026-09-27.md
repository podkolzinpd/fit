# Fit Lime: переписка тренера

Пункт 19 плана YAFIT-539, задача YAFIT-558. Новый стиль `/chat/:conversationId` доступен только тренеру с серверными флагами Fit Lime и Schedule V2. Для остальных переписка остаётся прежней. Никаких изменений прав, API или способа хранения сообщений нет.

Экран использует чёрный фон, графитовый заголовок и входящие сообщения, оливковую поверхность собственных сообщений, лайм для отправки, новых сообщений и фокуса. Сохранены поиск, вложение и просмотр фото, ответ, редактирование, удаление, блокировка, приглашение, черновик, непрочитанная граница, догрузка истории и офлайн-повтор отправки с тем же идентификатором. При ошибке догрузки истории есть адресный повтор, уже показанные сообщения не исчезают. Нижняя строка и лист действий учитывают safe area; текстовое поле имеет 16 px на iPhone.

Возврат из диалога ведёт к списку, а затем к исходной дате календаря. Прямая ссылка без внутренней истории возвращает внутрь приложения. Проверки: два серверно-мокированных пилотных профиля, контроль без Fit Lime, неудачная отправка и повтор без дубля, мобильный Chromium и iPhone WebKit. Личный вход в реальные учётные записи остаётся отдельной проверкой.
