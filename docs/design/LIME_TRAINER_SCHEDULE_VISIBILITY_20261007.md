# Расписание тренера Lime: автор и формат тренировки

Утверждено владельцем 7 октября 2026 года. База: c465ca9f.
Тикет: https://github.com/podkolzinpd/fit/issues/1506.

## Утверждённый план (без сокращений)

План доработки расписания тренера в Lime.

### 1. Разделить тренировки по автору и формату

| Тренировка | Отображение в расписании тренера |
|---|---|
| Создана спортсменом | Не показываем |
| Создана тренером, «С тренером» | Показываем всегда |
| Создана тренером, «Самостоятельно» | Только при включённой настройке |

Автор определяется по тому, кто создал тренировку, а не кто позже редактировал или завершил её.

### 2. Добавить настройку отображения

В существующем блоке фильтров расписания добавить галочку **«Показывать самостоятельные тренировки»**.

- По умолчанию выключена.
- Выбор сохраняется отдельно для каждого тренера.
- Применяется совместно с фильтрами по спортсмену и статусу.
- Новых экранов и дополнительных подписей не добавляем.

### 3. Применить единое правило во всём расписании

Обновить неделю, две недели, список и подробный день, включая вход через «Сегодня».

Карточки, отметки на датах и счётчики должны учитывать только отображаемые тренировки. Если остались только скрытые тренировки — показываем обычное пустое состояние.

Включённые самостоятельные планы видны для контроля, но не считаются занятостью тренера.

### 4. Сохранить остальные механики

Не меняем:

- тренировки и историю в карточке спортсмена;
- приложение спортсмена и его календарь;
- прогресс, результаты и финансовый учёт;
- создание, быстрый старт, Live и завершение;
- права доступа к тренировкам.

Фильтрацию ограничиваем расписанием, не общим источником данных.

### 5. Проверить старые записи

Проверить тренировки без заполненного автора или формата. Использовать существующие правила совместимости, чтобы не скрыть реальные занятия тренера и не принять клиентские записи за его собственные.

### 6. Проверить перед выпуском

Проверить все три категории тренировок, разные статусы, записи с временем и без него, смешанный день и день только со скрытыми тренировками. Отдельно — сохранение галочки, переключение видов, фильтры, обновление данных и независимость настроек разных тренеров.

Критерий готовности: по умолчанию тренер видит только созданные им занятия «С тренером»; галочка добавляет его самостоятельные планы, но никогда — тренировки, созданные спортсменом.

## Прямое ограничение выпуска

«фиксируй, делай, но выкатывай самым последним после выкатки нового лаймового дизайна на тренера и клиента».

Реализация и проверки разрешены сейчас. Merge/deployment этой задачи запрещены до подтверждённого выпуска Lime для ОБЕИХ ролей. Зависимости: PR1500 (клиент), PR1501 (тренер) и их фактическая активация/проверка, а не только merge подготовительных workflows. Этот PR не включает Lime, не расширяет пилот и не обходит отдельное согласование all. Перед выпуском: актуальный main, повторные проверки/зелёный CI и последняя позиция в согласованной очереди.

## Preflight и технические границы

- Референс: существующие `/schedule` и `/today` Lime; календарь, список, Page, AsyncView, Coachmark и native inputs сохраняются. Primary — прежнее планирование/быстрый старт; галочка не становится primary.
- Стиль: существующие lime-text, lime-text-secondary, lime-divider и lime-accent; 44px touch target, обе темы, 390/430/1440px, без нового экрана или палитры.
- Предпочтение: localStorage, ключ с actor.userId, в текущем браузере; перенос между устройствами не обещается. При недоступном storage переключатель остаётся рабочим, невозможность сохранения видима.
- createdBy определяет автора. Legacy null/пустой автор принадлежит тренеру только при trainerId=current actor, по действующему ownership-контракту. startedBy/completedBy/origin не определяют автора.
- Отсутствующий формат следует действующему fallback `self`; не выводим формат из времени, веса или статуса и не переписываем старые данные. Такие собственные записи доступны с галочкой и в карточке спортсмена.
- Видимый самостоятельный план имеет текст «Самостоятельно», не блокирует время занятия тренера. Автопрокрутка рабочего дня ориентируется на занятия с тренером. Финансовые/Live-ограничения не изменяются.
- Нет DB/API/repository/RLS изменений. Вне Lime сохраняется прежнее расписание.
