# YAFIT-528 — каталог доступных тренеров

Статус: реализуется отдельным PR после выпуска YAFIT-527.

## Что меняется

- Каталог клиента всегда запрашивает только тренеров, которые берут новых клиентов.
- Яндекс API применяет это условие по умолчанию, даже если старый клиент не передал фильтр.
- Из фильтров каталога убирается выбор «Сейчас не берёт».
- Сохранённое в браузере старое значение фильтра больше не возвращает недоступные анкеты.
- Опубликованная анкета остаётся доступна по прямой ссылке и показывает актуальный статус.

## Что не меняется

- Существующие связи клиента и тренера, история тренировок и чат.
- Публикация, снятие с публикации и ручное включение анкеты в каталог.
- Ассистент и его данные.

## Проверка

- Первый запрос и пагинация каталога используют `acceptingClients=true`.
- Старое сохранённое состояние каталога безопасно обновляется.
- В интерфейсе отсутствует фильтр недоступных тренеров.
- Яндекс API без параметра `accepting` передаёт в запрос базы `acceptingClients=true`.
- Прямая публичная анкета со статусом «не берёт клиентов» продолжает открываться.
- Проверяются мобильные размеры 390 и 430, WebKit, светлая и тёмная темы.
