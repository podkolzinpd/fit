# Coach Live — простые исправления, 10.10.2026

## Утверждённый scope (неизменяемый)

Только две разрешённые тренерские учётки: `knyaz187@mail.ru` и
`mr.vidishev@yandex.ru`. Используется существующий fixed2-флаг
coach-workout-reference. Третья тренерская учётка, остальные тренеры,
клиентское приложение и Mono не получают эти изменения. Allowlist не расширяется.

Пользователь разрешил реализацию, самостоятельное слияние зелёных PR и
официальную production-публикацию всех пяти пунктов. Новые сценарии не вводятся.

### PR 1. Только понятное переключение таймера

- Во время отдыха большой таймер показывает оставшееся время отдыха, верх янтарный.
- При нуле большой таймер возвращается к общему времени тренировки, верх зелёный/Live.
- Кнопка отдыха остаётся янтарной и продолжает считать в минус: «Отдых −0:15».
- Сигнал окончания отдыха сохраняется. Удаление будущего/постороннего упражнения
  не сбрасывает текущий отдых.
- Не добавляем кнопку «Начать», новые фазы или автоматическое подтверждение;
  остальные существующие механики таймера сохраняются.

### PR 2. Чистые поля и правильные галочки

- Оригинальные SVG-галочки референса во всех состояниях подхода вместо Unicode.
- Высота полей и галочки остаётся 48 px, цифры центрированы по обеим осям.
- Подписи кг/повторов меньше и спокойнее (10–11 px); ввод остаётся 16 px.
- Убираем лишние пересекающиеся рамки; ошибочное поле подсвечивается красным.
- Не показываем постоянные «Сохраняем / Сохранено» в пилоте.
- Существующая краткая ошибка сети/повтор сохраняется; её нельзя выдавать за
  ошибку заполнения поля. Новых панелей или постоянных статусов не добавляем.

### PR 3. Простые свайпы и перетягивание

- Убираем крестики удаления подходов; свайп строки открывает удаление подхода.
- Свайп карточки открывает удаление упражнения; существующая замена сохраняется.
- Перетягивание за существующую ручку меняет порядок упражнений.
- Поля не запускают жесты; вертикальная прокрутка сохраняется.
- Свайп только открывает действие, а не удаляет сразу. Защита выполненного
  и последнего подхода сохраняется.
- Не добавляем кнопки вверх/вниз, новый режим сортировки или другие жесты.

### PR 4. Суперсет — только со следующим

- Меню: «Объединить со следующим в суперсет» для допустимых соседних упражнений.
- Существующие круги, отдых и разъединение сохраняются.
- Без выбора произвольного упражнения, объединения частично выполненных
  хвостов, переписывания подтверждённых фактов или серверной семантики.

### PR 5. Только конкретные косметические недочёты

- Плавающий плюс каталога не перекрывает карточки упражнений.
- Окна времени/фильтров помещаются в экран; действия достижимы, прокрутка работает.
- Исправляем воспроизводимые обрезания и перекрытия, не перестраиваем логику
  каталога, фильтров и времени.

PR 6 исключён: без объяснений старых сессий, переделки восстановления
длительности или нового сценария завершения.

## Приёмка

Ввод → подтверждение → отдых → следующий подход; свайпы, перетягивание,
суперсеты и обе разрешённые учётки. Отдельный отрицательный контроль третьего
тренера/клиента/Mono. Mobile 375/390/430, desktop 1440, Chromium и WebKit;
проверка снимков, полный check, зелёный CI, штатная выкладка и readback.
Физический телефон и реальная авторизованная сессия не подменяются fixtures.
