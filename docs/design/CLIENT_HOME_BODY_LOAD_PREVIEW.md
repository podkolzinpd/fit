# Карта нагрузки за период на Client Home

Статус: скорректировано пользователем 24 сентября 2026 года после первого выпуска.

## Пользовательский результат

На главном экране спортсмен видит только карту нагрузки по телу за текущий
месячный период. Выбор зоны показывает её процент. Рейтинга мышц, распределения
подходов, списка упражнений и отдельного режима конкретной тренировки нет.

«Открыть в прогрессе» раскрывает ту же карту за период и сразу включает режим
«Нагрузка». В Progress остаётся соседний режим «Прогресс», но Home не создаёт
для карты собственный срез или детализацию.

## Утверждённая композиция

- Заголовок на Home: «Нагрузка по телу» без дополнительной подписи.
- Home и Progress используют один `loadBodyMap` и один период: по умолчанию
  последний месяц до текущей даты.
- На фигуре одновременно видны все рассчитанные зоны; выбранная зона показывает
  название и целый процент нагрузки.
- Переключатель «Спереди / Сзади» появляется только при данных на обеих сторонах.
- На Home нет общего счётчика, рейтинга зон, списка мышц или упражнений,
  количества подходов и действия «Показать все группы».
- В load-режиме Progress также нет абсолютных количеств и раскрывающейся
  детализации упражнений: только карта, зона и процент за выбранный период.
- Переход с Home содержит только `view=pro` и `mapMode=load`; параметры
  конкретной тренировки, дат одной записи и зоны не используются.
- Смена периода в Progress сохраняет режим «Нагрузка» и пересчитывает карту для
  нового периода.
- Если данных для мышечных зон нет, большая пустая фигура на Home не выводится;
  остаётся короткое фактическое empty-state без выдуманного процента.

## Границы

- Расчёт нагрузки, модели данных, backend и БД не меняются.
- Личный результат последней тренировки, блок недели, быстрый ввод и порядок
  основных действий Client Home не меняются.
- Карта не делает физиологических выводов о восстановлении или росте мышц.
