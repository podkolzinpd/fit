## Как применяем после сверки
Каталоги авто-генерируются (`scripts/import-exercises.mjs`), правка руками в
`*.generated.ts` перезатрётся. Поэтому корректировки вносим как **override-слой
в скрипте импорта** (карта `ref → { muscleGroup, primaryMuscleDetail }`),
затем `node scripts/import-exercises.mjs` → перегенерация → `npm run check`.
Так правки переживут повторный импорт из Free Exercise DB.
