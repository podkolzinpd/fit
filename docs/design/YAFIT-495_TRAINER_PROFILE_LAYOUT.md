# YAFIT-495 — анкета внутри профиля тренера

## Результат

1. Основные данные и профессиональная анкета находятся на одной вкладке
   «Профиль» тренера.
2. Отдельный пункт «Анкета тренера» удалён. Старый адрес `/profile/trainer`
   перенаправляет в основной профиль.
3. Кнопки «Сохранить», «Предпросмотр» и «Опубликовать» находятся в конце
   последнего блока формы и прокручиваются вместе с ним.
4. Публичная страница, закрытый черновик и опубликованный снимок работают как
   раньше.

## Проверка состояний

- loading и error анкеты отображаются внутри основной страницы;
- пустая анкета заполняется в основной вкладке;
- опубликованная анкета сохраняет ссылку и снятие с публикации;
- мобильная панель действий не использует sticky-положение и не перекрывает
  нижнее меню.
