# YAFIT-386 — понятный результат подключения

## Граница задачи

Меняется только представление результата уже существующей атомарной привязки.
RPC, перенос данных, отключение и смена тренера в эту задачу не входят.

## Критерии приёмки

| Роль и состояние | Что видит пользователь | Следующее действие |
|---|---|---|
| Клиент, привязка успешна | «Тренер подключён», самостоятельные тренировки сохранены | «Открыть кабинет» |
| Тренер, привязка успешна | «Клиент подключён», карточка и доступная история готовы | «Открыть карточку» |
| Клиент, уже есть другой основной тренер | Понятное объяснение без технического кода ошибки | Сначала завершить текущую связь |
| Повтор того же использованного приглашения | Тот же успешный результат без дублей | Перейти в кабинет/карточку |

## Проверки

- unit: перевод `trainer_switch_required` в пользовательский текст;
- Chromium 390 px: клиент принимает приглашение, видит результат и открывает кабинет;
- WebKit 390 px: тренер создаёт карточку, клиент принимает приглашение и продолжает сценарий назначения;
- нет горизонтального переполнения и автоматического перехода до явного CTA;
- полный `npm run check` перед PR.
