# Ввод времени с клавиатуры по умолчанию

Тикет: YAFIT не создан из этого окружения (нет авторизованного Tracker); выпуск в одном PR. Подтверждено владельцем 30.09.2026. Scope — клиент и тренер, составление плана, ручной факт, review и Live. Источник данных остаётся прежним: `durationSec` и `distanceKm`; БД, API, каталог упражнений и разбор речи не меняются.

1. Во всех формах ввода времени подхода по умолчанию показывать два числовых поля «мин» и «сек» с системной цифровой клавиатурой. Минуты допускают значения больше 59, секунды — 00–59. Пустое время остаётся пустым, старые `durationMin` и точные `durationSec` читаются без потери. При фокусе нулевое значение удобно заменяется вводом. Неверные значения не должны попадать в сохранение.
2. Для подходов с дистанцией разместить минуты, секунды и расстояние на одной строке на мобильном экране, сохранив выбор м/км, необязательность дистанции там, где она была, и отдельную частоту гребков. RPE не должен скрывать или переносить дистанцию под время. Для упражнений только со временем дистанцию не добавлять.
3. В настройках «Тренировки» клиента и тренера добавить переключатель «Ввод времени колёсиком», выключенный по умолчанию на устройстве. При включении во всех тех же формах остаётся существующий выбор двумя колёсами. Переключение способа ввода не меняет сохранённые значения и не меняет основной сценарий сохранения тренировки.
4. Проверить план, ручной факт, review, Live и оба профиля: минуты >59, секунды 00/59, пустое/очистка, время + дистанция, м/км, опциональная дистанция, RPE, старые записи, заблокированный подход, автосохранение и подтверждение. Проверить состояния загрузки/ошибки/повтора существующих экранов, не добавляя новые экраны и действия.
5. Выполнить целевые тесты и реальную визуальную/WebKit-проверку клиента на 390/430 px, тренера на 1440 px и узкий мобильный shell; проверить клавиатуру, focus, safe area, горизонтальный overflow, светлую/тёмную тему. Затем `npm run check`, зелёный CI, один PR/merge и production smoke на `fit-training.ru`.

Единственное primary-действие на формах — прежнее «Сохранить тренировку» или «Подтвердить подход»; выбор способа ввода — настройка, не второе primary. Переиспользуются `WorkoutDurationField`, `TimeWheel`, `RunMetricsFields`, `WorkoutSetTable`, `Switch`, Fit-поля и существующие семантические токены. Вне scope: новый формат данных, изменение Voice/LLM, прогресса, каталога и главных экранов.
