# Семь клипов: проверка точных разновидностей

## План и приёмка

1. Отключить пять подтверждённых неверных привязок и две неподтверждённые.
2. Сохранить девять совместимых карточек с видео, все refs и историю.
3. Согласовать оборудование узкого EZ-сгибания с его инструкцией.
4. Проверить общий каталог и реальные карточки 390/430/1440, затем полный check.
5. Дождаться зелёного CI, соблюсти очередь PR, проверить production после merge.

Используются существующие текстовые состояния ExercisePicker/ExerciseTechnique
и каталога. Primary-действие — выбрать упражнение. Новых компонентов, стилей,
токенов, API или изменений S3 нет. Проверяются отсутствие чужих poster/video,
открытие и закрытие деталей, инструкции и отсутствие горизонтального overflow.

## Доказательство

SHA-256 исходного архива совпал с sourceArchiveSha256 каталога:
99cf4a28b8a68cd8a317ce7f389de5e3a0cfb7db9c1923cf3257cdbad531b33e.
Семь исходных sourceFile повторно обработаны точными параметрами существующего
импорта; каждый полученный MP4 совпал SHA-256 с media manifest выпуска.
Просмотрены 12 последовательных кадров каждого полного клипа, дополнительные
увеличенные фазы для наклонной скамьи. Это сверка карточки и движения, не
сертификация техники и не полный аудит 670 Pro-роликов.

| Клип | Результат |
|---|---|
| EX-016 | Одновременный молоток; не подходит fedb-alternate-hammer-curl |
| EX-009 | Обычный хват; не подходит fedb-close-grip-standing-barbell-curl |
| EX-019 | Одновременное сгибание на наклонной; не подходит fedb-alternate-incline-dumbbell-curl; fedb-flexor-incline-dumbbell-curls и fedb-incline-inner-biceps-curl не подтверждены |

| EX-004 | Прямые ноги поднимаются к перекладине; соответствует текущим двум названиям |

Итог: 5 доказанных несовпадений + 2 неподтверждённых варианта отключены;
9 карточек сохранены. Общий карантин 47 refs. Все 1040 выбираемых упражнений
сохранены. Нет подбора нового ролика по одной лишь мышце/оборудованию.

747 шаблонных инструкций остаются отдельной содержательной задачей.
Нельзя объявлять все анимации каталога проверенными по этой выборке.

Локальная приёмка: полный npm run check прошёл; 37 целевых тестов и три
WebKit-сценария (все семь новых карточек на 390/430/1440) прошли. Скриншоты
просмотрены: чужого видео и overflow нет, оборудование EZ-гриф отображается.
CI и подтверждённая публикация остаются гейтами выпуска.
