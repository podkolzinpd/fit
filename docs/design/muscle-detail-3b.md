## Часть B — разбивка на пучки (ручная разметка через RECLASSIFY)
Источник не различает пучки — размечаем вручную по прайм-муверу. Override
`primaryMuscleDetail` для каждого ref.

### Плечи → пучки дельт (~30 упр., группа shoulders)
- **Передняя дельта:** жимы над головой (армейский, Смит, гантели, блок,
  Брэдфорд, антигравитационный), подъёмы гантелей вперёд, жим-маятник.
- **Средняя дельта:** разводки в стороны, тяга к подбородку (upright row).
- **Задняя дельта:** разводки/тяги на заднюю дельту, тяга каната на заднюю дельту.
- **Трапеции:** шраги — остаются (уже отдельная деталь).
- Спорные (вертикальные тяги к шее и т.п.) — по прайм-муверу, отмечу в PR.

### Грудь → верх/середина/низ (~28 упр., группа chest)
- **Грудь (верх):** жимы/разводки на положительном наклоне (incline).
- **Грудь (низ):** жимы/разводки на отрицательном наклоне (decline).
- **Грудь (середина):** горизонтальные жимы/разводки/отжимания/сведение.

### Спина — оставляем как есть (Середина спины / Широчайшие / Поясница)
Разбивать глубже не просили; при желании — отдельно.

## Часть C — показ вторичных мышц в карточке
`secondaryMuscles` уже хранятся (напр. hip-thrust → «Икры, Бицепс бедра»), но не
показываются. В карточке упражнения (таб «Техника»/шапка):
```
Основная: Ягодицы · Также: Бицепс бедра, Икроножные
```
- Если secondary пусто — только «Основная: …».
- Народные термины применяются и к вторичным (тот же MUSCLE_LABEL).

## Где показываем детали (UI)
- **Пикер:** второй ряд чипов-подкатегорий по `primaryMuscleDetail` (уже
  работает — при выборе группы всплывают детали). После разбивки в «Плечи»
  появятся «Передняя/Средняя/Задняя дельта», в «Грудь» — «Верх/Середина/Низ».
- **Карточка упражнения:** основная деталь + вторичные (Часть C).
