# Клиентский Live: применение тренерского v79 в существующем пилоте

Согласовано 26.10.2026, YAFIT-657. План и статусы:
[CLIENT_LIVE_V79_REUSE_20261026](CLIENT_LIVE_V79_REUSE_20261026.md).
Этот документ задаёт клиентские варианты существующих компонентов, не включает
флаги и не расширяет прежний allowlist из четырёх тестовых аккаунтов.

## Источники и приоритет

1. Подтверждённый план и сохраняемые механики клиента.
2. Текущий код тренерского v79, [интеграция](COACH_LIVE_V79_INTEGRATION_20261025.md)
   и [последующая полировка](COACH_LIVE_V79_POLISH_20261025.md).
3. Общий [Lime-контракт](FIT_LIME_DESIGN_CODE.md), включая §8.1 для вложенных состояний.

Для этого клиентского пилота числовая роль часов — уже используемый Doto700,
а не исторический REM из общего документа. Новый handoff v79 содержит полный
шрифт и ресурсы. Это не восстановление гарнитуры по контурам прежних SVG.
Текст и формы — существующий YS Geo400/500, без загрузки новых гарнитур.

## Карта повторного использования

| Представление | Существующий компонент / источник | Клиентский контракт |
| --- | --- | --- |
| Метрики | LiveSetFields, RunMetricsFields, WorkoutSetRow | Два обычных поля без повторных «Вес/Повторы»; 3/4 метрики сохраняют подписи и сетку |
| Ввод | LiveSetInput, WorkoutDurationField | Стабильный DOM, select-all, 54/48px, текст/колёсико согласно сохранённой настройке #1818 |
| Заголовок | WorkoutExerciseHeader, исходные v79-ресурсы | Анимация слева, название слева, меню⋯ справа; без тренерского номера вместо медиа |
| Сворачивание | Существующие формы и v79 motion | Формы не уничтожаются ради анимации, ввод/фокус/сохранение не сбрасываются |
| Время | LiveRestTimer → CoachLiveV79Timer | Один источник времени; клиентская пауза; большой→малый при прокрутке |
| Окна | FitLimeSheetHeader, ExercisePicker и текущие dialogs | Наследование темы; клиентский multi-add, поиск/фильтры/черновик сохраняются |
| Жесты | WorkoutGestures | Перенос всей карточки, раздельные свайпы подхода/упражнения, pending/conflict/undo |

## Правила для следующих доработок

- Проверять реальный gate `client-workout-reference`, а не подключать клиенту
  `coach-live-v79` или вручную подставлять root-классы.
- Применять `--lime-*`, общие поля radius16 и карточки radius32. Оригинальный
  ввод54px, компактный48px, ввод текста>=16px и hit targets>=44px.
- Проверять обе темы на одной разметке. Не копировать dark-only цвета из демо,
  глобальные reset/hover/typography и тренерские права/сохранение.
- Анимации по умолчанию ON; OFF убирает медиа и занимаемое место. «Моя заметка»
  и «+Подход» на одной линии. Контент тренера и собственная заметка различаются.
- После нуля большие часы показывают общее время/Live, малый отдых — минус.
  Правка подтверждённого не снимает галочку и не начинает отдых заново.
- Для каждого PR проверять свежий main, вложенные окна/уведомления и конечные
  состояния, обе плотности, клавиатуру/нажатия/жесты. Документ не заменяет UI QA.
- Не удалять общую Identity/Monochrome основу и fallback Onest без отдельной
  карты действующих потребителей. За пределами клиентского пилота ничего не мигрировать.
