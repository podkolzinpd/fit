# Client Progress — лучшие результаты за период

Статус: утверждено к реализации 2026-09-10.

## Пользовательский результат

Блок на клиентском Progress показывает несколько понятных достижений выбранного
периода, а не смешивает рекорды с обычной историей. Пользователь сразу видит,
что именно улучшилось, относительно какого прежнего максимума и в какой
тренировке это произошло.

## Контракт

- Источник — подтверждённые подходы завершённых тренировок и вся предыдущая
  история того же `exercise_id`/типа ввода.
- В коротком списке показываются до трёх разных упражнений, только со статусом
  реального личного рекорда в выбранном периоде.
- Если у упражнения в периоде несколько рекордов, показывается самый свежий;
  при нескольких рекордных метриках в одной тренировке приоритет: вес,
  повторы при фиксированном весе, повторы, объём.
- Силовой результат показывает выполненный подход: вес и число повторов.
- Изменение рекорда сравнивается с прежним историческим максимумом той же
  метрики, а не просто с предыдущей тренировкой.
- Одна строка содержит одну ссылку «Открыть тренировку». Предыдущая тренировка
  не выдаётся за самостоятельное сравнение.
- Остальные достижения периода раскрываются внутри блока; полная история,
  включая первые, стабильные и снизившиеся результаты, остаётся в
  «Все результаты».
- Если рекордов нет, показывается честное пустое состояние без искусственной
  похвалы и без подмены последним снижением.

## UI и состояния

- Переиспользуются текущая карточка Progress, семантические токены, тихие
  разделители, `ProgressDetailsSummary` и существующая ссылка тренировки.
- Единственное действие строки — «Открыть тренировку»; общим подробным
  действием остаётся «Все результаты».
- Проверяются loading, error с retry, empty, 1–3 достижения, больше трёх,
  длинные русские названия, 390/430 px, light/dark и WebKit.

## Вне scope

- Полная история и её сравнение с предыдущей тренировкой не меняются.
- Формулы ИИ-анализа, БД, API, идентичность упражнений и тренерский Progress не
  меняются.
