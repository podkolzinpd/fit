# Vital Gym Pro — план и контракт интеграции

Статус: реализовано в feature-ветке, production rollout — после обязательных CI.

## Решение

- Исходный купленный ZIP и открытые медиафайлы остаются вне публичного Git.
- В Git хранится только AES-256-GCM authenticated bundle. Vercel получает ключ
  `VITAL_MEDIA_KEY` из закрытого environment и раскрывает bundle только во время
  сборки; в production ролики публикуются как часть приложения.
- Из архива проверено 317 animation family; после схлопывания пяти уже известных
  true duplicate основной выбор содержит 312 самостоятельных карточек.
- 16 публичных кандидатов исключены: безопасного файла в купленном архиве нет.
- Старые упражнения, `exercise_id`, планы, факты, веса, повторы, PR и история не
  мигрируются и не удаляются.
- Алиасы и старые названия индексируют новый каталог, при этом прежние карточки
  остаются доступны в расширенном поиске и истории.

## Медиа

Воспроизводимый импорт создаёт для каждой карточки:

- MP4/H.264, 540 × 540, 30 fps, muted-compatible, fast start;
- статичную обложку JPG;
- второй JPG-кадр для fallback;
- запись каталога и словарь алиасов.

Кадр вписывается целиком через `contain`; обрезание фигуры запрещено. Суммарный
вес 317 оптимизированных роликов — около 41 МБ, но браузер не загружает их все:
в списке видео-элемент создаётся только для явно нажатой карточки.

`scripts/package-vital-gym-pro-media.mjs` создаёт зашифрованный bundle из
проверенных файлов, а `scripts/prepare-vital-media.mjs` перед production build
проверяет ключ, GCM-тег и SHA-256 каждого из 951 файлов. Без ключа Vercel build
завершается ошибкой; локальные и CI-проверки используют только manifest.

## Поведение picker

1. При открытии все карточки статичны.
2. Тап по карточке с видео запускает её inline без звука и по кругу.
3. Тап по другой карточке уничтожает предыдущее видео и запускает новое.
4. Повторный тап по активной карточке открывает крупную технику.
5. `+ / ✓` выбирает упражнение независимо от просмотра.
6. Поиск, фильтры и смена режима останавливают текущее inline-видео.
7. При `prefers-reduced-motion` autoplay не включается.

## Границы

В эту поставку не входят анимация Live-тренировки, миграция старых записей,
удаление legacy-каталога, изменение БД и публикация исходного архива.

## Проверка

- валидность и уникальность 317 соответствий;
- наличие 951 сгенерированного файла;
- декодирование всех MP4, H.264/30 fps/без аудио и размер 540 × 540;
- успешная упаковка и обратная authenticated-расшифровка с проверкой manifest;
- ровно одно inline-видео после последовательных тапов;
- сохранение отдельного действия выбора и полной техники;
- поиск по новым названиям, алиасам и прежним FIT-названиям;
- unit/component, build и релевантный mobile smoke.
