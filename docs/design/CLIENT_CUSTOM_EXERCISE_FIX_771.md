# Создание своего упражнения клиентом — #771

Задача: https://github.com/podkolzinpd/fit/issues/771
PR: https://github.com/podkolzinpd/fit/pull/772

## Требования
- создание работает у тренера;
- создание работает у клиента с привязанным тренером;
- создание работает у самостоятельного клиента;
- клиент не видит упражнения другого клиента;
- тренер сохраняет доступ к своим упражнениям и может работать с упражнениями клиентов в своём разделе;
- существующие ID, упражнения тренеров и история тренировок не меняются и не удаляются;
- собственное упражнение можно сохранить внутри тренировки;
- вместо ложного сообщения о недоступной записи показывается корректная ошибка.

## Реализация
1. Отделить автора custom exercise от раздела данных тренера.
2. Безопасно мигрировать существующие строки с сохранением ID и внешних ссылок.
3. Обновить RLS для тренера, связанного и самостоятельного клиента без доступа между клиентами.
4. Передавать корректного владельца раздела из SessionActor.
5. Добавить unit, database и e2e-регрессию.
6. После зелёного CI выполнить squash merge и проверить production.

Форма, Fit-компоненты и primary «Сохранить упражнение» не меняются. Loading,
pending, валидация, повтор после ошибки и пустая выдача используют существующий
общий picker. Тренерские упражнения не объединяются с системными. Каталог,
словарь, matching, видео и другие экраны вне scope.
