# YAFIT-493 — анкеты тренеров для спортсмена

## Размещение

- вход находится в блоке «Тренеры» внутри профиля спортсмена;
- на главном экране нет рекламного блока;
- ссылка остаётся доступной и спортсмену без тренера, и спортсмену с уже
  подключённым тренером;
- каталог открывается отдельным экраном «Тренеры» с возвратом в профиль.

## Каталог

- поиск по имени;
- дополнительные фильтры по направлению, городу, формату занятий и набору
  новых клиентов;
- компактные карточки с фото, направлениями, форматом, городом и опытом;
- полная опубликованная анкета открывается по кнопке «Посмотреть анкету»;
- подключение и чат из каталога не запускаются: это следующие самостоятельные
  сценарии.

## Публикация и приватность

- тренер сначала публикует готовую анкету;
- отдельным переключателем тренер разрешает показывать её в каталоге;
- каталог читает только опубликованный снимок, изменения черновика не видны;
- снятие анкеты с публикации автоматически убирает её из каталога;
- неопубликованные и не добавленные тренером анкеты никогда не попадают в
  выдачу.

## Критерии приёмки

1. Спортсмен открывает каталог из профиля максимум за одно нажатие.
2. Каталог не занимает место на главной и не навязывает работу с тренером.
3. Поиск и фильтры одинаково работают через Supabase и основной Yandex API.
4. Карточка открывает полную публичную анкету и позволяет вернуться к списку.
5. Экран помещается по ширине на мобильном устройстве и не перекрывается
   нижней навигацией.
