# YAFIT-524 — авторизованные пользователи в Яндекс Метрике

Цель: начать собирать в Яндекс Метрике точное количество авторизованных
пользователей Fit по ролям без новой таблицы активности в Supabase.

## Итоговый план

1. После авторизации берём уже существующие `userId` и роль пользователя.
2. Передаём в Метрику:
   - `setUserID` — внутренний ID аккаунта;
   - событие `authenticated_open`;
   - роль: `trainer` или `client`.
3. Отправка работает фоном и никак не влияет на работу приложения.
4. Счётчик загружается только на каноническом production-домене
   `fit-drab.vercel.app` и в упакованном Capacitor-приложении: localhost,
   Vercel Preview и автоматические браузерные проверки не попадают в
   продуктовую статистику.
5. Проверяем на одном тренере и одном клиенте.
6. В Метрике строим недельный график уникальных пользователей отдельно по
   ролям.

## Ограничения

- Новую таблицу в Supabase не создаём.
- Не передаём имя, email, телефон, тренировочные или медицинские данные.
- История начинает собираться только с момента выкладки.
- Данные до production-only фильтра содержат preview/test-трафик и не подходят
  для расчёта активной аудитории.
- Недоступность Метрики не должна влиять на авторизацию и работу Fit.

## Acceptance-чеклист

1. `userId` и роль берутся только из уже восстановленного `SessionActor` —
   реализовано, проверяется typecheck.
2. `setUserID`, `authenticated_open` и текущая роль отправляются в указанном
   порядке — реализовано, unit-тест для обеих ролей.
3. Отсутствующая или падающая Метрика не выбрасывает ошибку в приложение —
   реализовано, unit-тесты.
4. Тренер и клиент покрыты отдельными параметризованными test cases —
   реализовано локально; production-события появятся после выкладки.
5. Метрика инициализируется только на `fit-drab.vercel.app` и при протоколе
   `capacitor:` — реализовано в `index.html`; локальный и preview-трафик не
   создают `window.ym`.
6. Недельный отчёт строится только по данным после выкладки production-only
   фильтра; прежнюю историю нельзя считать точной активной аудиторией.
