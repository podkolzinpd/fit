# Редактор избранного: не терять черновик при загрузке актуальной версии

План подтверждён владельцем22.10.2026. Разрешены реализация и полный выпуск
с проверкой production. Только подтверждённая ошибка с ранним удалением
черновика. Ограничения и улучшения из повторного аудита не входят в задачу.
Исходный main:0a81a5f7dc325d696520c24ab40c53da5907ec4d.
Тикет:YAFIT-645.

## Итоговый план исправления — неизменяемый acceptance

1. **Сначала загрузить актуальную версию**, не удаляя текущие поля и локальный черновик.
2. **Только после успешного чтения применить замену**, подтвердить новую версию редактора и убрать старый черновик. Полную перезагрузку страницы заменить обновлением существующей формы.
3. При ошибке сети или отсутствии шаблона оставить введённые данные нетронутыми, показать понятную ошибку и возможность повторить чтение. Ничего автоматически не сохранять.
4. Проверить успешную замену, отказ сети, удалённый источник, отмену и повторные нажатия. Затем повторить основной цикл сохранения, редактирования, удаления и планирования.
5. После реализации — обязательные проверки, CI и приёмка production.

**Границы:** без изменений БД, новых экранов, редизайна и переписывания рабочего сохранения. Всё остаётся на существующих Lime-компонентах.
