# План: восстановить анимации Gym Pro в списке упражнений

Статус: выполнено и выложено в production через PR #818.

Пользовательский результат: в основном каталоге Fit первый тап по каждой
карточке Gym Pro запускает именно её анимацию. Экран техники открывается только
повторным тапом по уже активной карточке.

## Acceptance-чеклист

1. Сохранить `techniqueVideoUrl`, уже заданный у новой системной карточки Gym
   Pro, если для неё нет отдельной legacy-привязки медиа.
2. Подтвердить, что все 317 отобранных Gym Pro movement family сохраняют
   корректный MP4-путь в итоговом системном каталоге.
3. Проверить сценарий списка: первый тап запускает один ролик, запуск следующего
   останавливает предыдущий, повторный тап открывает крупную технику, а `+ / ✓`
   по-прежнему независимо меняет выбор.
4. Сохранить ожидаемое поведение расширенного каталога: упражнение без
   подходящей анимации открывает существующую карточку техники и не получает
   выдуманный ролик.
5. Пройти целевые тесты, полный `npm run check`, обязательные CI checks и
   мобильный smoke на 390/430 px для клиентского и тренерского путей.
6. При свободной очереди смержить PR без обхода checks, дождаться production
   deployment и проверить основной сценарий на production.

## Границы

- Не менять состав каталога, поиск, фильтры, названия, aliases и идентификаторы.
- Не менять тренировочную историю, статистику, планы и БД.
- Не добавлять новый UI, токены, плеер или autoplay без явного тапа.
- Не назначать приблизительные Vital-анимации упражнениям без безопасного
  соответствия.
