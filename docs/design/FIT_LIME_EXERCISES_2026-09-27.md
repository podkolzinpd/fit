# Fit Lime: каталог упражнений тренера

Пункт 26 плана YAFIT-539, задача YAFIT-565. Lime включается на `/exercises` только для тренера с обоими серверными флагами. Системная библиотека, поиск по названию/мышце/оборудованию, техника и медиа, каталог собственных упражнений и переход назад сохраняют существующие источники данных и права. Workout picker, тренировка и клиентский каталог не входят в этот пункт.

Библиотека и свой каталог используют Lime-карточки и токены, подробности открываются в графитовом нижнем листе. Пустой поиск и пустой собственный каталог остаются разными состояниями. Новые API, медиа и удаление не добавлялись: продукт поддерживает только архивирование и восстановление собственного упражнения. Для пилота перенос в архив требует подтверждения; серверная ошибка архива теперь видна рядом со списком. В общей форме исправлена потеря набранного названия при ошибке: поля очищаются только после успешного сохранения. Непилотный стиль и мгновенное архивирование не меняются.

Приёмка: два пилотных профиля и непилотный контроль, поиск/сброс, подробности/медиа, собственные записи, создание и повтор после ошибки без потери текста, редактирование, отмена архива, ошибка/повтор и восстановление, ошибка загрузки списка, возврат в профиль, мобильный Chromium и iPhone WebKit, desktop 1440, полный `npm run check`. Живой вход в обе учётки — после публикации; до неё это локальные проверки с серверным мокированием.
