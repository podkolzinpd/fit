## Согласованный объём

- S101: проведённая тренировка всегда «Проведена», с одинаковым оформлением
  и галочкой, независимо от упражнений и числа подтверждённых подходов.
  План/незавершённая остаются без галочки; «Не состоялась» — с крестиком.
- S102: незаписанный результат упражнения/подхода у тренера отображается «—»;
  отсутствие записи не объявляется невыполнением и не показывает план как факт.
  Подтверждённые значения и существующие примечания плана сохраняются.
- S103: одно обозначение в карточке, истории, дне/неделе/списке расписания,
  включая записи без времени и существующий просмотр источника из истории.
- S104: оба режима Original54/Compact48, клиентский Live/подписи, факт/план,
  финансы, права, завершение и параллельные клиентские изменения сохраняются.

Новых видимых блоков/кнопок/пояснений нет. Структура истории, выборки дат,
пауза, фильтры, финансовые правила и серверные команды не меняются.
Остальные находки аудита не превращаются в обязательную часть этого PR.
Частичный результат у спортсмена сохраняет прежнее представление. Формат
«Самостоятельно» остаётся форматом; кто нажал завершение, не заменяет
обозначение проведённого занятия в тренерском календаре.

## Проверки и выпуск

Правила: пустое проведение, ноль/часть/все подтверждённые подходы; план,
Live со всеми отметками без завершения и отмена. UI: совпадение цвета/аватара/
галочек в календаре, статус карточки/истории/списка, «—» в раскрытых результатах.
Существующие клиентские проверки сохраняются. Новые browser-cases покрывают
две уникальные регрессии: CSS статуса и передачу тренерского контекста в
карточку/историю/результаты. Они выполняются в Chromium/WebKit, без размножения
каждого случая на все размеры/темы; обе плотности проходят существующий Live.

После current-headCI — merge, полный mainCI и штатный веб/API/подписанныйOTA.
Публичная приёмка проверяет release/готовность API, файлы веба и реальные
опубликованные ресурсы с синтетическими API-данными, без изменения тренировок
или списаний пользователей. Физический телефон/OAuth проверкой браузера не
считаются. Итоговый статус — [YAFIT-700](https://st.yandex-team.ru/YAFIT-700)/PR.
Отдельный PR только для приёмки не создаётся.
