# Расписание тренера: визуальная и продуктовая иерархия

Дата: 26 августа 2026 г.  
Статус: информационная архитектура реализована; color-specific решения заменены
в `monochrome_preview` контрактом UI Identity v1 задачи 21.

## Зафиксированный объём задачи

Нумерация и смысл пунктов не меняются до завершения задачи.

1. Пересобрать верхнюю панель:
   - `Расписание`;
   - строка `Август 2026` с компактной кнопкой `Сегодня` и контурной иконкой календаря справа;
   - единая полоса недели;
   - ниже `Среда, 26 августа` и `2 тренировки`;
   - нейтральная кнопка `Запланировать`;
   - убрать отдельную тяжёлую коралловую кнопку `+`.
2. Убрать ложную эмодзи-дату `📅 17` и заменить её контурной SVG-иконкой календаря.
3. Упростить выбор недели:
   - одна общая нейтральная подложка;
   - семь равных зон без отдельных рамок;
   - выбранная дата — компактное primary-состояние (в UI Identity v1 графит в
     light и молочный в dark);
   - сегодняшний день — маленькая точка, если выбрана другая дата;
   - стрелки — контурные иконки без кнопок-коробок;
   - неделя начинается в понедельник.
4. Сделать карточку тренировки компактной и двухстрочной:
   - первая строка: `07:10–08:00  Антоха`;
   - вторая строка: `Велотренажёр, жим ногами`;
   - при большем числе упражнений: `· ещё 2`;
   - не выводить упражнения отдельными строками;
   - минимальная высота гарантирует две читаемые строки.
5. Зафиксировать статусы:
   - запланирована — нейтральное состояние;
   - идёт сейчас — коралловое/янтарное;
   - завершена — зелёное состояние и текст `Готово`;
   - пропущена — нейтрально-серое состояние и текст `Пропущена`;
   - цвет не является единственным обозначением статуса.
6. Сократить воздух перед шкалой времени до 20–24 px и правильно выбирать фокус:
   - ближайшая тренировка;
   - первая тренировка, если все уже закончились;
   - текущее время, если тренировок нет.
7. Сделать счётчик однозначным:
   - для выбранной даты: `Среда, 26 августа` и `2 тренировки`;
   - недельный счётчик, если появится, должен называться `2 тренировки на неделе`.
