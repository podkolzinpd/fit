# Ассистент: склонённые имена клиентов

Дата: 2026-08-27

## Проблема

В естественной русской команде тренер пишет «запиши Анне Смирновой» или
«покажи прогресс Анны Смирновой», а в карточке хранится «Анна Смирнова».
Буквальное сравнение не находило клиента и заставляло повторно уточнять имя.

## Решение

- Для слов имени строятся консервативные ключи распространённых русских
  падежных форм без общего fuzzy-поиска.
- Один контракт используется записью тренировки, сводкой прогресса и
  подготовкой программы.
- После выбора клиента его склонённое имя удаляется из исходной диктовки, а
  упражнения и значения остаются без изменений.
- Если подходят несколько клиентов, ассистент показывает явный выбор и не
  принимает решение сам.

## Границы

Модель, provider, temperature, системные инструкции и конфигурация LLM не
меняются. Функция не исправляет опечатки и не угадывает похожие фамилии.

## Приёмка

- «Запиши Анне Смирновой тренировку: …» сразу выбирает Анну Смирнову и
  сохраняет только текст упражнений.
- «Покажи прогресс Анны Смирновой за последние 30 дней» выбирает нужную
  карточку и период.
- «Составь программу Анне Смирновой» переходит к сбору brief.
- При двух клиентах с именем Анна команда «Запиши Анне …» открывает выбор.
