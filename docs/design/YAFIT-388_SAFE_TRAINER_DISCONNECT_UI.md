# YAFIT-388 — безопасное отключение тренера в профиле клиента

## Граница задачи

Только интерфейс уже готовой серверной операции `disconnect_client_trainer`.
Повторная привязка и смена тренера в эту задачу не входят.

## Сценарий

1. Клиент видит текущего тренера в профиле и выбирает «Отключить».
2. Подтверждение прямо говорит, что тренер потеряет доступ, а аккаунт клиента,
   тренировки, замеры и цели сохранятся.
3. Во время запроса действие заблокировано и показывает состояние выполнения.
4. После успеха список перечитывается, профиль показывает самостоятельный
   режим и отдельное подтверждение сохранности данных.
5. Повторный запрос `already_disconnected` считается успешным.
6. Конфликт старой карточки не маскируется под потерю данных: пользователь
   получает спокойное сообщение, а текущая связь остаётся видимой.

## Визуальный контракт

- «Отключить» — destructive-ссылка, не заполненная коралловая primary-кнопка.
- Подтверждение — единственный модальный слой и явное destructive-действие.
- Успех — текстовый success-статус без лишней карточки.
- Ошибка — рядом с блоком связи; остальной профиль остаётся доступным.
