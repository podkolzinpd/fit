# Nutrition catalog input foundation — 19.10.2026

## Поток и границы

Поток: `product`.

Пользовательский результат: клиент может вставить обычную запись вида
`куриная грудка 300гр., рис отварной 100гр`, поочерёдно выбрать реальные
продукты из каталога и получить подставленный вес. Ничего не сохраняется и
КБЖУ не угадываются до явного выбора и сохранения.

Эта поставка не меняет таблицы, API, права тренера, пилотный cohort, источники
КБЖУ или production flags. LLM и ручная модерация в ней не используются.

## Уже есть → используем → меняем

- Уже есть: серверный `VkusvillNutritionCatalog`, безопасный публичный DTO без
  цены/ссылок/изображений, immutable snapshot записи и ручная еда.
- Используем: существующий поиск и экран добавления еды; поисковый адаптер
  остаётся единственным местом сетевого доступа к источнику.
- Меняем: добавляем детерминированный разбор списка с явно указанными граммами
  в UI, не изменяя контракт сохранения.

## Контракт разбора

- Разделители: запятая, точка с запятой или новая строка.
- Поддерживаются только явные единицы `г`, `гр`, `грамм`, `грамма`, `граммов`;
  запятая в дробном значении веса допускается.
- Максимум 12 позиций и 20 000 г на позицию. Неоднозначный либо чрезмерный
  ввод не разбирается как структурированные данные.
- Выбранная позиция становится обычным поисковым запросом; вес передаётся в
  форму только после выбора конкретного продукта. Результат поиска, сохранение
  и история не меняют другие позиции строки автоматически.

## Источники и последующие PR

Основной текущий источник — read-only публичный MCP ВкусВилла. Его условия
перепубликации и лимиты ещё не подтверждены, поэтому он не является
«источником истины» и не даёт права на bulk-import.

Следующий отдельный PR: контракт `barcode -> normalized code -> server lookup
-> provenance`, без камеры в первой итерации. Кандидаты проверяются отдельно:

- Open Food Facts: <https://openfoodfacts.github.io/openfoodfacts-server/api/>;
- USDA FoodData Central: <https://fdc.nal.usda.gov/api-guide/>.

До юридически и технически подтверждённого контракта новый внешний источник не
включается в production и не кэшируется как общий каталог. Для пользовательских
продуктов последующей задачей будет алгоритмическая дедупликация по
нормализованному названию и КБЖУ; автообъединение записей дневника запрещено.

## Проверка

- unit: разбор примера с `300гр.`, позиции без веса, ограничения ввода;
- UI: выбор разобранной позиции вызывает существующий поиск, переносит граммы
  и не создаёт запись сам;
- typecheck и targeted lint.
