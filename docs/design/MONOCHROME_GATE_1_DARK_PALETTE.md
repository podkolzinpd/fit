# Fit — Gate 1, задача 4: тёмная палитра

Статус: **принято 2026-08-29**.

Дата: 2026-08-29.

## Результат

Тёмная neutral foundation применена только в
`docs/design/preview/monochrome-typography.html`. Preview не импортирует
product CSS и не меняет реальные экраны.

Утверждённые решения заблокированы без изменений:

- типографика задачи 2: `24/600`, `18/600`, `16/600`, `14/400`, `14/500`,
  `12/500`, editable `16/400` и принятая семантика весов;
- светлая палитра задачи 3, включая контекстные роли `secondary` и
  `secondary-strong`.

## Тёмные роли

| Роль | Значение | Назначение |
| --- | --- | --- |
| App background | `#111214` | основной глубокий фон без чистого чёрного |
| Main milk | `#F1EDE6` | основной текст и будущий primary |
| On milk | `#171719` | контент на молочном inverse |
| Grouped surface | `#1D1E21` | карточки и сгруппированные блоки |
| Raised | `#26272B` | sheets и активный вложенный уровень |
| Sunken / field | `#191A1D` | поля и утопленный уровень |
| Divider | `#303136` | границы и разделители |
| Secondary | `#999A9F` | вторичный текст на фоне и тёмных поверхностях |

Coral, purple, градиенты, glow и семантические success/warning/danger в задачу
не добавлялись.

## Контраст

| Сочетание | Контраст | Решение |
| --- | --- | --- |
| `#F1EDE6` / `#111214` | 16.06:1 | основной текст на фоне |
| `#171719` / `#F1EDE6` | 15.34:1 | inverse-контент |
| `#999A9F` / `#111214` | 6.67:1 | secondary на background |
| `#999A9F` / `#1D1E21` | 5.93:1 | secondary на grouped surface |
| `#999A9F` / `#26272B` | 5.31:1 | минимальная пара: secondary на raised |
| `#999A9F` / `#191A1D` | 6.20:1 | secondary на field |

`#999A9F` проходит WCAG AA для обычного текста на каждом предусмотренном
тёмном уровне. Поэтому отдельный `secondary-strong` для тёмной темы не введён:
новый оттенок не решал бы реальную проблему и усложнил бы семантику.

## Проверка браузером

Chromium на 390, 430 и 1020 px подтвердил:

- точные computed colors всех применённых тёмных ролей;
- неизменность типографических значений задачи 2 и светлых ролей задачи 3;
- загрузку Onest;
- отсутствие горизонтального overflow;
- различимость background, grouped, raised и sunken без glow и градиентов.

## Намеренно не изменено

- `src/`, product CSS и production bundle;
- Client Home и другие маршруты;
- shared-компоненты и feature flags;
- утверждённая типографическая шкала и светлая палитра;
- success, warning, danger и data-series colors.

## Решение

Задача 4 принята. `#999A9F` утверждён как единый secondary-текст dark theme;
отдельный `secondary-strong` не создаётся. Dark theme не считается
автоматической инверсией light theme: surfaces, cards, controls и active states
должны проходить самостоятельную визуальную проверку, даже если формально
соответствуют WCAG. Дополнительные оттенки, glow, coral и purple возможны только
после отдельного решения.

Следующий допустимый шаг — только задача 5: действия и формы в изолированной
component matrix. Продуктовые экраны всё ещё не меняются.
