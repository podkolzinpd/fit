# YAFIT-520 — завершение отдыха и история тренировок

Статус: реализовано и локально проверено 2026-09-16.

## Пользовательский результат

После окончания отдыха спортсмен явно видит, что можно начинать следующий
подход. В списке истории завершённую тренировку можно скопировать одним
отдельным действием, а на самой карточке видны основные проработанные группы
мышц.

## Утверждённый план

1. Индикация окончания отдыха
   - После завершения отсчёта кнопка таймера переходит в состояние
     `Отдых завершён`.
   - Добавляется заметная цветовая индикация на самой кнопке.
   - Звуковой сигнал сохраняется.
   - Состояние снимается после завершения следующего подхода или запуска нового
     отдыха.
   - Корректно обрабатывается окончание таймера при свёрнутом приложении.

2. Копирование из списка истории
   - На карточке завершённой тренировки непосредственно в списке истории
     добавить значок копирования.
   - Нажатие на карточку продолжает открывать тренировку.
   - Нажатие на значок сразу открывает новую редактируемую копию.
   - Используется существующий механизм: выполненные веса и повторы становятся
     значениями нового плана и могут быть изменены.
   - Для значка сделать самостоятельную удобную область нажатия, чтобы действия
     не путались на мобильном.

3. Группы мышц в списке истории
   - На этой же карточке завершённой тренировки в списке истории показывать
     основные проработанные группы мышц.
   - Рассчитывать их по упражнениям и фактически выполненным подходам.
   - Показывать до трёх групп компактной строкой, например:
     `Грудь · Плечи · Трицепс`.
   - При большем количестве показывать `+N`.
   - Если достоверных данных нет — строку не выводить.
   - Экран самой тренировки и карточки запланированных тренировок не менять.

4. Проверка
   - Таймер: окончание отдыха, работа после сворачивания, повторный запуск.
   - История: отдельные нажатия на карточку и копирование.
   - Копия: правильные упражнения, веса, повторы и возможность редактирования.
   - Группы мышц: одна, несколько и большое количество групп.
   - Мобильная проверка, чтобы текст и кнопка копирования не перекрывали друг
     друга.

## Состояния и роли

- Live: `idle`, `resting`, `finished`; loading/error страницы сохраняются.
- История с данными: новые элементы показываются только у завершённых
  тренировок в режиме списка.
- Пустая история, loading, error/retry, календарный режим, ближайшие и ранее
  запланированные тренировки не меняются.
- Карточка списка проверяется отдельно для спортсмена и тренера.

## Переиспользуемый UI

- `LiveRestTimer` и существующая toolbar Live;
- `WorkoutChronicleCard` и существующий `copyWorkout` route;
- общий `CopyIcon` из `src/shared/icons.tsx`;
- существующие Foundation tokens: янтарный для активного отдыха, success для
  подтверждённого завершения, нейтральные поверхности карточек.

Главное действие экранов не меняется. Новая кнопка копирования — компактное
вторичное действие 44 × 44 px с доступным названием.

## Границы

- Повторяющиеся тренировки остаются в бэклоге и в эту работу не входят.
- Новые экраны, таблицы, API и серверная логика не добавляются.
- LLM, SpeechKit, matching, сохранение тренировки и остановленная задача
  Yandex ID не меняются.
