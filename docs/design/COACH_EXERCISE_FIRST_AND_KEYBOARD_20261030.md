# Упражнения первыми и стабильная клавиатура

30.10.2026. [YAFIT-696](https://st.yandex-team.ru/YAFIT-696).
Владелец согласовал шесть PR и самостоятельные слияние/публикацию всего пакета.
Канонический план и журнал — этот файл; фактический статус выпуска — в задаче.

## Принятый контракт

- Тренерская карточка: название → дата → отзыв тренера → упражнения.
  Имя клиента остаётся видимым контекстом. Название32px, дата15px, подписи13px —
  согласованный эскиз этой задачи, не восстановленные из контуров SVG размеры.
- Общие тоннаж/подходы/длительность/мышцы/калории находятся ниже упражнений
  в закрытой сводке. Вес/повторы/время/дистанция каждого подхода остаются доступны.
- Пустой отзыв в подробной карточке — компактное добавление; заполненный читаем.
  В списках пустых плашек отзыва нет. Вопрос клиента и дискомфорт не прячутся.
- Клиентский отчёт/аналитика не получают тренерскую композицию. Общие исправления
  клавиатуры применяются обеим ролям, сохраняя действующий клиентский дизайн.
- Название/дата/отзыв/состав согласованы во всех поверхностях выбора тренировки.
  В расписании время и клиент главнее: длинный текст не растягивает временной слот.
- Календарь истории тренера сохраняет полный состав выбранной даты и факты.
  Обычный список сохраняет три названия и «ещёN».
- Общий исторический отзыв не копируется в новую тренировку; комментарии
  к упражнениям и преобразование факт→план сохраняют действующую механику.
- Rollout — всем тренерам. Независимые клиентские/пищевые пилоты не расширяются.
  Сохраняются Original54/Compact48, таймеры/пауза, жесты/суперсеты, заметки,
  сохранение и права. API/БД/voice/parsing/расчёты не меняются.
- Шрифт/палитра/иконки — действующий Lime; полного макета этого экрана в SVG нет.
  Не публикуем исходный коммерческий пакет шрифтов, полные макеты и частные снимки.

## Проверки и публикация

В каждом PR сохраняются уникальные проверки и обязательный CI. Новые browser
случаи — только для конкретной регрессии; существующие расширяются assertions,
без ослабления таймаутов/retries/inventory. Снимки просматриваются.
Обычные слияния сохраняют свежий main и параллельные клиентские PR.
После всего пакета — зелёный CI точного current-main, штатные API/web/подписанный
Android OTA, public version/assets/health и браузерная приёмка опубликованной версии.
Физическая клавиатура/телефон отмечаются отдельно от моделирования viewport.
Прежняя очередь выпусков не отменяется этим планом; подготовка продолжается
во время ожидания, задача не завершается до полной опубликованной приёмки.

## Итерация2 — 30.10.2026 — Codex / OpenAI

Задача: K101–K104, первое исправление клавиатуры.
Расхождения: закрытие расширяло viewport до возврата нормального padding React,
из-за чего браузер ограничивал scroll; окно тренера не учитывало visual viewport.
Сделано: общая геометрия rename, preventScroll при входе/возврате фокуса;
снимок внутренней прокрутки при закрытии восстанавливается до отрисовки,
после согласования высоты и классов оболочки. Pointer/blur guards сохранены.
Решения: восстановление только при переходе открытая→закрытая клавиатура,
без вмешательства в обычный scroll и без таймера центрирования.
Отвергнуто: переписывать Live, отключать padding или навигацию всех экранов.
Проверка: полный npm run check прошёл (2932 frontend unit;1543 API tests,
218 существующих skips). Расширен существующий rename case — Chromium/WebKit.
8 локальных probes +4 с включённым клиентским Lime: поле выше420/490px,
отмена сохраняет scroll641→641 при той же высоте/контенте. Снимки просмотрены.
Первый sandbox-прогон остановился на EPERM локального сервера; повтор с разрешённым
локальным сервером прошёл полностью. Модель viewport не физическая клавиатура.
Открыто: CI PR и опубликованная приёмка; PR2–PR6.
Дальше: Enter и видимость ответа тренера.
