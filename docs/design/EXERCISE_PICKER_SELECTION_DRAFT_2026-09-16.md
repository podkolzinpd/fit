# Черновик выбора упражнений в каталоге

Дата: 2026-09-16

## Проблема

В режиме множественного выбора каталог хранит отмеченные упражнения внутри модального окна. Закрытие по крестику или фону размонтирует окно и безвозвратно сбрасывает выбор, хотя пользователь ещё находится в той же форме тренировки.

## Решение

1. Поднять черновик выбора в экран текущей тренировки: отдельно для быстрого создания и полной формы.
2. Крестик и нажатие на фон только закрывают каталог. При следующем открытии отмеченные упражнения, счётчик и кнопка добавления восстанавливаются.
3. Добавить рядом со счётчиком явное действие «Очистить». Оно снимает весь текущий выбор, не меняя фильтры.
4. «Добавить N» остаётся единственным действием, которое переносит выбранные упражнения в тренировку. После успешного добавления черновик очищается.
5. Сброс поиска и фильтров не влияет на выбранные упражнения.
6. Черновик живёт только пока открыта текущая форма: он не переносится в другую тренировку и не сохраняется после перезагрузки страницы.

## Границы изменения

- Одиночный выбор, замена упражнения, выбор упражнения для распознанного текста и live-тренировка остаются без изменений.
- Закрытие каталога не добавляет упражнения автоматически.
- Уже добавленные в тренировку упражнения не удаляются действием «Очистить».

## Проверка

- Выбрать несколько упражнений, закрыть каталог крестиком и по фону, открыть снова — выбор сохранён.
- Очистить выбор — отметки и счётчик исчезли.
- Сменить и сбросить фильтры — выбор сохранён.
- Нажать «Добавить N» — упражнения добавлены один раз, при повторном открытии черновик пуст.
- Проверить быстрый экран создания тренировки и полную форму, светлую/тёмную темы и мобильную ширину 390/430 px.
