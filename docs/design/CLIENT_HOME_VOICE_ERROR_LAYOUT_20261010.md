## Подтверждённый план — без изменений

Уточню: **ошибка раскладки подтверждена**, но точную последовательность действий спортсмена я пока не воспроизвела целиком. Поэтому исправление должно быть узким.

План — один небольшой PR:

1. **Добавить воспроизводящий тест.** На настоящем экране приложения задать ответ разбора, где одно упражнение требует уточнения, затем закрыть редактор. Проверить появление сообщения и расположение карточек.

2. **Исправить область действия стиля.** Назначение `grid-area: error` оставить только сообщению внутри голосовой карточки. Сообщение на главной должно занимать отдельную полноширинную строку, не превращая карточки в два столбца.

3. **Сохранить существующее поведение.** Не скрывать предупреждение ради устранения поломки. Оставить «Редактировать текст», автоматическое сохранение черновика и текущие `VoiceInputButton`, `WorkoutComposer`, `QuickStartWorkout`. Не менять шрифты, размеры кнопок, цвета и основное действие экрана.

4. **Проверить регрессии.** Светлая/тёмная тема, Lime/монохром, ширины 390/430 и узкий экран; без черновиков, с одним и несколькими; успешная диктовка, уточнение, ошибка обработки, продолжение черновика и перезагрузка. WebKit и Chromium, затем полный набор проверок проекта.

Критерий готовности: сообщение остаётся читаемым, карточки сохраняют нормальную ширину, кнопки не перекрывают текст, черновик можно продолжить.

Распознавание, сервер и хранение данных в этот PR не включаем. Пока ничего не меняю.
