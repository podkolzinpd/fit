# Архивирование клиента свайпом в списке тренера

Статус: реализовано и локально принято 2026-09-18; готово к production rollout.

## Зафиксированный план

1. Действие доступно только основному тренеру карточки; дополнительный тренер не видит ни свайп, ни кнопку действий.
2. Свайп влево только открывает явную кнопку «В архив» и сам ничего не изменяет.
3. Для архивной карточки то же место содержит «Восстановить».
4. Горизонтальный жест распознаётся только после отделения от вертикального; прокрутка списка остаётся нативной.
5. Одновременно открыта не более одной строки. Нажатие вне неё и `Escape` закрывают действие.
6. Кнопка `⋯` открывает то же действие для клавиатуры, скринридера и пользователей, которым неудобен свайп.
7. После архивации показывается подтверждение с «Вернуть»; это восстановление использует актуальную версию карточки.
8. Ошибка или version conflict не скрываются и не считаются успехом; список перечитывается штатным query lifecycle.
9. Supabase и Yandex возвращают один признак права `canArchive`; серверные ограничения остаются окончательной границей доступа.
10. Перед релизом проверяются component/API/SQL, Chromium, iOS WebKit, светлая и тёмная темы и ширины 390/430/1440 px.

## Границы задачи

- Поток: `product`.
- Базовый `main`: `759eee63` (#1038).
- Удаления клиента нет: действие обратимое и использует существующую архивацию.
- Страница клиента и её прежняя кнопка архивации сохраняются.
- Общий доменный контракт получает только признак права; membership и персональные данные не раскрываются дополнительно.
- Supabase: additive RPC migration и существующая RLS-protected mutation.
- Yandex: numbered overview migration и существующая root-only API mutation.
- Настройка «Показывать архив клиентов» получает эквивалентную загрузку активных и архивных карточек в Yandex-контуре.

## Матрица приёмки

| Сценарий | Ожидаемый результат |
| --- | --- |
| Root trainer, активный клиент | Свайп/`⋯` открывают «В архив»; изменение только после нажатия |
| Root trainer, архивный клиент | Открывается «Восстановить» |
| Connected trainer | Карточка открывается как раньше, управляющих действий нет |
| Вертикальная прокрутка | Строка не сдвигается, список прокручивается |
| Две строки | Открытие второй закрывает первую |
| Открытая строка и нажатие по карточке | Первый тап закрывает действие и не уводит со страницы |
| Успешная архивация | Активный список обновляется, доступно «Вернуть» |
| Conflict/ошибка сети | Видимая ошибка, ложного подтверждения нет |
| Keyboard/screen reader | `⋯`, кнопка действия, `aria-expanded`, status/alert доступны без жеста |
| 390/430/1440, light/dark | Нет горизонтального overflow, наложений и изменения высоты карточек |
