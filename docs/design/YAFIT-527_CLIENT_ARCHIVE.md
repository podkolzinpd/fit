# YAFIT-527 — отдельный архив клиентов

Статус: реализовано по подтверждённому плану, ожидает PR и production-проверку.

## Пользовательский результат

Основной список тренера содержит только активных клиентов. Архив открывается
отдельной последней строкой списка.

## Подтверждённый план

1. Всегда показывать строку «Архив» последней в списке клиентов.
2. Открывать отдельный экран только с архивными клиентами.
3. Сохранить просмотр карточки, истории, существующего чата и восстановление.
4. Не показывать архивных клиентов в выборе для новых тренировок.
5. Удалить настройку «Показывать архив клиентов» и зависимость от localStorage.
6. Проверить loading, empty, error, поиск, возврат и мобильный экран.

## Реализация

- `/clients` запрашивает активный список и дополнительно отсекает архивные
  карточки на границе экрана.
- `/clients/archive` запрашивает список с архивом и показывает только карточки
  с `archivedAt`.
- Оба экрана используют существующие `Page`, `AsyncView`, карточку клиента,
  поиск, чат и действие свайпа. Единственное изменяющее данные действие архива —
  «Восстановить».
- Строка «Архив» использует существующую нейтральную поверхность и
  `ChevronRightIcon`; отдельный набор компонентов и токенов не добавляется.
- Выбор клиента для тренировки продолжает использовать `list(false)`.
