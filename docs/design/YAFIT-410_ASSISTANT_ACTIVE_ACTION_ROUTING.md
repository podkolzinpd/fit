# YAFIT-410 — активные сценарии ассистента в живом контексте

## Зафиксированный план

1. `/assistant` находит последнее активное действие текущей беседы для всех поддержанных инструментов: `create_client_draft`, `record_workout`, `create_program_draft`, `schedule_program`, `summarize_progress`.
2. Выполненное, отменённое или завершившееся ошибкой действие не показывается как текущий контекст и не возвращает более старый сценарий.
3. В архивной беседе текущая изменяемая карточка не показывается.
4. Локальный черновик тренировки остаётся только у `record_workout`; другие сценарии не создают и не используют ключ черновика тренировки.
5. Модель, provider, temperature, prompts и другая конфигурация LLM не меняются; визуальный редизайн в задачу не входит.
6. Живой маршрут проверяется на ширине 390 и 430 px для карточек клиента, тренировки, программы и сводки, а также для выполненного/отменённого действия и архивной беседы.
