# План: полностью удалить старые фотографии упражнений

Статус: реализация завершена локально; rollout проходит через PR/CI.

Пользовательский результат: красные фотографии старого каталога больше не
появляются ни на одном экране. Если для упражнения нет новой Vital-анимации,
интерфейс показывает только название и данные упражнения без медиаблока.

Этот контракт заменяет исключение пункта 4 в
`VITAL_MEDIA_LOADING_FLASH_PLAN.md`, которое ранее разрешало старые локальные
кадры упражнениям без Gym Pro.

## Acceptance-чеклист

1. Сохранить исторические `ref`, варианты, поиск, тренировки и статистику без
   миграции или удаления пользовательских данных.
2. Использовать в итоговом каталоге только медиа из `vital/` и `vital-pro/`.
3. Совместимому историческому дублю отдавать точную современную анимацию его
   канонической карточки; не подбирать движение приблизительно.
4. Не рендерить медиаблок, если новой анимации нет.
5. Запретить `base-*` и `fedb-*` URL непосредственно в общем компоненте медиа,
   чтобы старые метаданные не могли вернуть фотографию.
6. Удалить из public-поставки все 1 240 старых JPG; приватные и публичные
   Vital-файлы сохранить.
7. Проверить каталог, picker, технику и историю упражнения, затем пройти полный
   `npm run check`, CI, merge и production smoke.

## Матрица проверки

| Пункт | Видимый результат | Проверка | Статус |
| --- | --- | --- | --- |
| 1 | История и поиск продолжают находить прежние `ref` | catalog/unit tests | Выполнено |
| 2–3 | Старый дубль показывает только точное Vital-медиа | catalog regression test | Выполнено |
| 4–5 | Непокрытая карточка текстовая, stale legacy URL не создаёт `<img>` | component tests | Выполнено |
| 6 | В `public/exercises` нет top-level `base-*`/`fedb-*` JPG | repository audit | Выполнено |
| 7 | Реальные роли и production не регрессируют | local UI, CI, production smoke | Выполняется |

## Границы

- Не менять LLM matching, сохранение, БД, названия или соответствие Vital-видео.
- Не заменять отсутствующую анимацию похожим движением.
- Не запускать видео без явного тапа в списке и не добавлять новые controls.
