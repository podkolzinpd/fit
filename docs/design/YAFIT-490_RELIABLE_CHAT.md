# YAFIT-490 — надёжный личный чат

## Продуктовый результат

- У спортсмена есть отдельный диалог с каждым подключённым тренером.
- У тренера есть отдельный диалог с каждым спортсменом с аккаунтом.
- Точка входа — иконка сообщений справа в шапке «Кабинета» и «Сегодня»; рядом показывается общее число непрочитанных.
- Контекстная кнопка «Написать» есть в карточке тренера спортсмена и в карточке спортсмена тренера.
- Нижняя навигация остаётся свободной для будущей ленты событий.
- Первый выпуск поддерживает только текст.
- История, непрочитанные и черновик сохраняются.
- Сообщение имеет состояния «отправляется», «отправлено», «ошибка»; повтор использует тот же ID и не создаёт дубль.
- После возвращения приложения из фона диалог обновляется.
- Push открывает нужный диалог.
- После отключения тренера история и отправка сообщений остаются доступны обеим сторонам. Доступ тренера к тренировкам, прогрессу и замерам не восстанавливается.
- Переписка не передаётся ИИ автоматически и не используется как контекст ассистента.

## Этапы реализации

1. Добавить таблицы диалогов и сообщений, права участников, постраничную выдачу, отметку прочитанного и идемпотентную отправку.
2. Повторить контракт в Yandex-контуре и добавить HTTP API.
3. Добавить репозиторий приложения и единые типы для обоих контуров.
4. Собрать список диалогов, экран переписки, черновик и состояния отправки.
5. Добавить точки входа, счётчики и возврат после push.
6. Добавить категорию уведомлений «Новые сообщения» и постановку push в существующую очередь по всем устройствам получателя.
7. Проверить роли, отключённую связь, фон, плохую сеть, повтор, длинную историю, 390/430 px, desktop 1440 px и WebKit.
