## Реализация и границы

- Один PR #1464: точные системные refs, не эвристики по названию.
- Существующие WorkoutExercise/WorkoutSetTable/WorkoutSetRow,
  WorkoutDurationField и RunMetricsFields; прежние Fit-токены/размеры.
- План тренера, запись постфактум, review, Live, история и копирование
  сохраняют вес. Кг и дистанция принимают дробные значения.
- ВиПР переключается в существующих настройках между повторами и временем.
  Смена режима не удаляет ранее введённые значения; старые timed snapshots
  остаются timed, новые карточки по умолчанию с повторами.
- Проходки: вес + дистанция в основной строке, время во второй
  подписанной строке; без бегового темпа. Удержания: вес + время.
- Схему метрик и API не расширяем: все величины уже поддерживаются.
  Numbered Yandex migration исправляет только шесть refs выпадов/зашагиваний
  в planned/in_progress, повышая версию каждого workout один раз.
  Завершённая история и строки подходов не изменяются.
- Карточка моста r289-1625 в приобретённом источнике называется
  single leg glute raise holds & single arm dumbbell и уже имеет duration.
  Добавляем вес, не переводим её в динамический формат без просмотра видео.
  Исходные динамические мосты вне этого точного ref не меняем.
- Единственное primary-действие остаётся существующее сохранение/подтверждение.
  Loading/error/retry и авторизация не меняются; новых наград/калорий/графиков нет.
