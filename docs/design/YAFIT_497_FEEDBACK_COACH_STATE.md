# YAFIT-497 — сообщение об отзыве и активная связь с тренером

## Результат

Экран завершённой тренировки больше не обещает самостоятельному клиенту, что
его отзыв увидит тренер. Источником истины служит текущий список активных
`client-trainers`, а не роль пользователя, автор тренировки или историческая
связь.

- При активной связи подтверждение говорит: «Спасибо, тренер увидит ваш отзыв».
- Без активной связи и при неизвестном состоянии связи подтверждение нейтрально:
  «Спасибо, данные о самочувствии сохранены».
- Действие «Задать вопрос тренеру» показывается только при активной связи.
- После отключения тренера новые отзывы сохраняются, но бывший тренер не может
  прочитать тренировку; существующая история не удаляется.

## Границы

Состав формы, сохранение feedback, optimistic version и схема БД не меняются.
Загрузка или ошибка списка тренеров трактуется консервативно: интерфейс не
обещает передачу данных и не предлагает действие, которое может оказаться
недоступным.

## Приёмка

- Unit: обе формулировки зависят только от признака активной связи.
- WebKit: standalone → active trainer → disconnect, reload после каждого
  состояния, viewport 390/430 px без горизонтального переполнения.
- Access: после disconnect бывший тренер получает пустой результат прямого
  запроса к тренировке.
- Regression: существующий сценарий отзыва тренера остаётся зелёным.
