# Клиентский Lime: добавление тренировки из списка

## Утверждённый план

1. Сохранить переход кнопки на компактную форму. Исправить лаймовую инициализацию черновика: сейчас она сбрасывает открытие формы и оставляет пользователя на главной.
2. Включить микрофон внутри этой же формы, рядом с текстовым вводом. Диктовка должна добавлять текст в то же поле; уже набранное нельзя затирать. Проверить отмену записи и отказ в доступе к микрофону.
3. Проверить вход как нажатием из списка, так и по прямой ссылке, а также закрытие формы и восстановление черновика. Главная страница не должна появляться вместо формы.
4. Добавить лаймовый тест полного пути: одна кнопка → компактная форма → видимый микрофон → текст или диктовка → разбор → сохранение. Проверить мобильный WebKit на 390/430 px и обе темы.

Границы: путь `/me?entry=workout` сохраняется; `/workouts/new`, тренерский и непилотный клиентский сценарии не меняются.

## Матрица приёмки

| Пункт | Видимый результат | Проверка | Статус |
| --- | --- | --- | --- |
| 1 | Кнопка из пустого/заполненного списка открывает компактную форму | Browser E2E, 390/430 px, light/dark; 8/8 пройдено, скриншоты осмотрены | Готово локально |
| 2 | Микрофон в той же форме дополняет текст; отказ и отмена не теряют ввод | Browser E2E с локальным SpeechKit mock; 2/2 пройдено | Готово локально |
| 3 | Прямая ссылка, обновление, скрытие и возврат сохраняют корректную форму/черновик | Browser E2E; 8/8 + прямой вход пройдены | Готово локально |
| 4 | Разбор и сохранение завершают путь из списка | Browser E2E пройден; полный `npm run check` на актуальном main пройден; CI и production readback после PR | Выпуск ожидается |

Тестовые состояния: пустой и заполненный список проверены; состояния загрузки и ошибки списка, включая повтор, не менялись и остаются под действующими проверками списка. Клиентский Lime включается только серверным признаком; тренер и непилотный клиент сохраняют прежние маршруты и действия. Визуальная приёмка — локальный WebKit без фирменных шрифтов; production-сборка подставляет проверенные файлы при выпуске.
