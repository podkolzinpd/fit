# YAFIT-747 — полный бесплатный пак Vital Animations

Статус: реализовано локально, ожидает CI и production smoke.

## Результат для пользователя

Все 50 упражнений бесплатного пака Vital Animations доступны в системном каталоге FIT с локальным видео техники. Четыре пилотных ролика сохраняются, остальные 46 добавляются в этом этапе.

## План

1. Зафиксировать полный состав Free50 (ID 0051–0100) и лицензионный источник.
2. Для каждого ролика использовать только точное соответствие движению; если точного упражнения в каталоге нет — добавить отдельную системную запись с понятным русским названием, оборудованием, мышечной группой и инструкцией.
3. Оптимизировать и хранить ролики локально, без обращения приложения к Vital Animations.
4. Для нового упражнения добавить статичную обложку, чтобы карточка работала при выключенной анимации и ошибке видео.
5. Добавить русские поисковые формулировки для новых тренажёров и движений, включая «лестница», «степмилл», «аэробайк» и «эллипс».
6. Не создавать смысловые дубликаты уже существующих упражнений.
7. Проверить карточку каталога, подробную технику и fallback на 390, 430 и 1440 px, Chromium и iPhone WebKit.
8. Обновить продуктовую и лицензионную документацию.

## Границы

- Платные паки не используются.
- Приблизительные совпадения движений не используются.
- Общее расширение каталога за пределами Free50 выполняется следующим отдельным PR.
