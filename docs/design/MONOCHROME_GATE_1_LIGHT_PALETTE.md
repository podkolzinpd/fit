# Fit — Gate 1, задача 3: светлая палитра

Статус: **принято 2026-08-29**.

Дата: 2026-08-29.

## Результат

Светлая neutral foundation применена только в
`docs/design/preview/monochrome-typography.html`. Preview не импортирует
product CSS и не меняет реальные экраны.

Утверждённая задача 2 заблокирована без изменений:

- Display `24/600`;
- Title `18/600`;
- Section `16/600`;
- Body `14/400`;
- UI `14/500`;
- Caption `12/500`;
- Editable `16/400`.

Dark specimen оставлен системным control и не является предложением задачи 3.

## Светлые роли

| Роль | Значение | Назначение |
| --- | --- | --- |
| App background | `#FBFAF7` | основной тёплый фон |
| Main graphite | `#242426` | основной текст и будущий primary |
| On graphite | `#F6F2EA` | контент на графитовом inverse |
| Raised | `#F7F5F1` | приподнятая поверхность |
| Grouped surface | `#EFEDE8` | сгруппированный блок |
| Sunken / field | `#E5E2DC` | поле и утопленный уровень |
| Divider | `#DEDBD4` | границы и разделители |
| Secondary on background | `#74736F` | вторичный текст только на базовом фоне |
| Secondary strong | `#666560` | мелкий текст на tinted surfaces, карточках и полях, когда `#74736F` не обеспечивает WCAG AA |

Coral, purple, градиенты, glow и семантические success/warning/danger в задачу
не добавлялись.

## Контраст

| Сочетание | Контраст | Решение |
| --- | --- | --- |
| `#242426` / `#FBFAF7` | 14.84:1 | основной текст |
| `#F6F2EA` / `#242426` | 13.88:1 | inverse-контент |
| `#74736F` / `#FBFAF7` | 4.55:1 | проходит AA для обычного текста только на background |
| `#74736F` / `#F7F5F1` | 4.36:1 | не использовать для мелкого текста |
| `#74736F` / `#EFEDE8` | 4.06:1 | не использовать для мелкого текста |
| `#74736F` / `#E5E2DC` | 3.67:1 | не использовать для мелкого текста |
| `#666560` / `#EFEDE8` | 4.99:1 | проходит AA на grouped surface |
| `#666560` / `#E5E2DC` | 4.52:1 | минимальная прошедшая пара для field |

`#666560` принят как отдельный `secondary-strong`, а не скрытая замена
утверждённого `#74736F`. Без него Caption `12/500` на surface/field не достигает
4.5:1. `secondary` используется на основном фоне; `secondary-strong` — только
на tinted surfaces, карточках и полях, где это требуется для WCAG AA. Новые
промежуточные оттенки текста без реальной необходимости не добавляются.

## Проверка браузером

Chromium на 390, 430 и 1020 px подтвердил:

- точные computed colors всех применённых ролей;
- неизменность типографических значений задачи 2;
- загрузку Onest;
- отсутствие горизонтального overflow;
- одинаковую геометрию typography specimen до и после светлой палитры.

## Намеренно не изменено

- `src/`, product CSS и production bundle;
- Client Home и другие маршруты;
- shared-компоненты и feature flags;
- тёмная палитра;
- success, warning, danger и data-series colors;
- типографическая шкала и правила веса.

## Решение

Задача 3 принята. Значения палитры и контекстная семантика `secondary` /
`secondary-strong` заблокированы для задачи 4 и служат контрольным светлым
specimen. Следующий допустимый шаг — только Gate 1, задача 4: тёмная палитра в
том же изолированном preview.
