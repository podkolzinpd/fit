## Acceptance и доказательства

Исходные пункты выше не сокращаются. Для каждого PR перед merge добавляется матрица «пункт → видимый результат → тест/скриншот → статус».
Для data surfaces: данные, empty, loading, error/retry; для mutations дополнительно pending, disabled, success. Темы: light/dark/system; роли: пилотный клиент, другой клиент, тренер. Размеры: 390/430 px; shared regression 1440 px. Голосовой ввод остаётся primary на главной, текстовый — secondary. Существующие Fit Button/Card/Field, theme preference и Lime typography/icon tokens переиспользуются после проверки реальных маршрутов.
