# Недельное расписание тренера

Статус: согласовано к реализации 2026-09-18.

## Зафиксированный план

1. На входе в расписание показываем недельную сетку: `Пн/Вт`, `Ср/Чт`, `Пт/Сб`, `Вс` на всю ширину.
2. В каждом дне показываем все тренировки компактными строками «время + имя», без «ещё N» и без внутреннего скролла.
3. Минимальная высота карточек `Пн–Сб` соответствует пяти строкам; карточки внутри пары всегда одинаковые и растут по более заполненному дню. Воскресенье имеет отдельный компактный минимум.
4. Нажатие на день открывает существующее подробное расписание дня; возврат сохраняет выбранную неделю.
5. Добавляю проверки для плотных, пустых и неравномерно заполненных дней, затем прохожу всю очередь PR, сливаю и выкатываю фронтенд самостоятельно. Эскиз остаётся зафиксированным как согласованный ориентир.

Карточки `Пн–Сб` имеют минимум 148 px, достаточный для пяти компактных строк. Две карточки в одной строке используют общую высоту CSS Grid и поэтому остаются симметричными. При шестой и следующих тренировках строка растёт по более заполненному дню; данные не скрываются и отдельный скролл внутри карточки не появляется. Воскресенье занимает обе колонки с минимумом 76 px и также растёт по содержимому.

## Поведение

- `/schedule` открывает текущую неделю; `?week=YYYY-MM-DD` — выбранную неделю.
- `?date=YYYY-MM-DD` сохраняет прежний подробный экран дня и обратную совместимость внешних переходов.
- Стрелки меняют неделю, «Сегодня» возвращает текущую, календарь сразу открывает выбранный день.
- Тренировки внутри дня сортируются по времени; записи без времени идут после них с обозначением `—`.
- Длинное имя сокращается только визуально в недельной строке. Полное имя остаётся в доступном названии и видно после открытия дня.
- Неделя загружается полностью одним запросом, поэтому пагинация не может скрыть поздние тренировки.

## Проверка приёмки

- пустая неделя и отдельный пустой день;
- 1–4 тренировки — минимальная симметричная высота;
- 5 тренировок — базовая вместимость карточки;
- 6–10 тренировок — рост пары без обрезания и внутреннего скролла;
- разная плотность двух соседних дней — одинаковая высота карточек пары;
- тренировки без времени, длинные имена, все статусы;
- переход неделя → день → неделя, предыдущая/следующая неделя и «Сегодня»;
- компактный экран телефона и desktop shell без горизонтального переполнения;
- светлая и тёмная темы, loading/error/retry и одноразовая подсказка нового входа.
