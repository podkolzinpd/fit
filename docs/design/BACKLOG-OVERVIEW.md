# Сводный бэклог Яндекс ФИТ — приоритизация

Единая картина всех незакрытых доработок из фидбэка тренеров, спек и роадмапа.
Оценка по двум осям: **Ценность** (нужность тренеру) × **Лёгкость** (трудозатраты + риск).
Размер: S (день) / M (2-4 дня) / L (неделя+) / XL (крупный проект).

Обновлено после аудита клиентского приложения (YAFIT-230).

## 📋 Рекомендованный порядок (мой)

**Ближайшие 3 (высокая отдача):**
1. **2а. Состав тела** (M) — прямой запрос, ложится на замеры.
2. **3b. Детализация мышц** (M) — тренеры просили; согласовать термины → override.
3. Женский цикл (ручной ввод) — важный дифференциатор без интеграций.

**Затем (ценное среднее):**
4. Женский цикл (ручной ввод) — важно, дифференциатор.
5. 2б/2в. Вложения + напоминания к замерам.
6. Аналитика по запросу / шаблоны.

**Крупные проекты (планировать отдельно, каждый = веха):**
- Редактирование in_progress (ядро, риск).
- Быстрое создание из текста/голоса.
- Периодизация (главный дифференциатор рынка).
- Форматы на время (Этап B).
