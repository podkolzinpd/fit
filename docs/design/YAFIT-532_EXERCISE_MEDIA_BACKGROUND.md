# YAFIT-532: цельный фон анимаций упражнений

## Пользовательский результат

Все системные анимации упражнений выглядят цельно во всех местах показа:
белые боковые поля заменены продолжением нейтрального фона, а фигура и
движение остаются исходного масштаба и пропорций.

## Acceptance cases

1. Правило применяется ко всей библиотеке аналогичных анимаций, а не к одному
   упражнению.
2. Фигура, оборудование и траектория не растягиваются, не обрезаются и не
   перерисовываются.
3. Белые поля убраны в миниатюрах плана, Live, результата, истории, каталога и
   в крупном блоке «Техника».
4. Для разных пропорций исходника используется безопасная область самого
   медиа; при отсутствии точной метаинформации сохраняется полный кадр.
5. Проверены светлая и тёмная темы, клиентские 390/430 px и тренерский desktop.
6. Обновлены автоматические и визуальные проверки общего `ExerciseImage`.

## Реализация

- Существующий `ExerciseImage` остаётся единственным медиакомпонентом.
- Для каждого проверенного системного ролика сборка фиксирует только пустые
  однотонные поля и нейтральный цвет края кадра.
- Пустые поля становятся прозрачными поверх адаптивного фонового canvas.
  Исходный кадр сохраняет размер, положение и пропорции.
- Пользовательские фотографии и медиа без проверенной метаинформации не
  обрезаются.
- Новых действий, текстов, состояний и навигации нет.
