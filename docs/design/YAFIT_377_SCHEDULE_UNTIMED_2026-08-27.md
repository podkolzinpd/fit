# YAFIT-377: тренировки без времени в расписании

Дата: 27 августа 2026 г.  
Статус: готово к PR

## Зафиксированный объём задачи

1. Показать тренировки без времени отдельным компактным блоком `Без времени` над часовой сеткой.
2. Не менять утверждённую структуру верхней панели, недельной навигации и часовой сетки.
3. Автоматический фокус часовой сетки не должен скрывать тренировки без времени.

## Матрица приёмки

| Пункт | Видимый результат | Проверка | Статус |
|---|---|---|---|
| 1 | Над часовой сеткой виден блок `Без времени` со всеми тренировками без начала | Визуальная приёмка Playwright, 390 и 430 px | Готово |
| 2 | Счётчик дня равен сумме тренировок с временем и без времени | Визуальная приёмка Playwright | Готово |
| 3 | Часовая сетка сохраняет фокус на ближайшей тренировке, блок без времени остаётся виден | Целевой Playwright e2e-тест | Готово |
| 4 | Существующая навигация по дням и неделям работает без изменений | Целевой e2e-тест расписания и полный `npm run check` | Готово |

## Доказательства

- Целевой сценарий расписания: 1 тест пройден.
- Визуальная приёмка: iPhone 390 × 844 и 430 × 932 px.
- Полный контроль: 828 frontend-тестов и 206 API-тестов пройдены; lint,
  typecheck, инфраструктурные политики и production build зелёные.

Другие пункты дизайн-аудита в YAFIT-377 не входят.
