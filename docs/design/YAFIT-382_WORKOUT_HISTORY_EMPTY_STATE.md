# YAFIT-382 — пустая история тренировок

## Цель

Пустая история должна объяснять следующий шаг без акцента на отсутствии
тренировок и без дублирования действий.

## Контракт

### Клиент

- Заголовок: «Новая тренировка».
- Пояснение: «Добавьте упражнения голосом, текстом или из каталога.»
- Единственное действие: «Добавить тренировку».
- Действие нейтральное, не конкурирует с глобальной навигацией коралловой
  заливкой.

### Тренер

- Заголовок: «Тренировка для клиента».
- Пояснение: «Составьте план или сразу запишите готовый результат.»
- Единственное действие: «Запланировать тренировку».
- Действие нейтральное; дублирующее действие в шапке при пустой истории не
  появляется.

## Не меняем

- Создание, сохранение и список тренировок.
- Состояния истории, в которой уже есть планы или результаты.
- Навигацию и права ролей.

## Приёмка

- Пустые состояния клиента и тренера проверены через Playwright.
- На каждом экране виден один и только один целевой переход.
- Компоновка проверена на ширине 390 и 430 px; тренерский экран также на
  desktop-профиле.
- Светлая и тёмная темы не теряют текст, рамки и действие.

## Матрица проверки

| Сценарий | Результат |
| --- | --- |
| Клиент, пустая история, 390 px | PASS — точные тексты и одно действие |
| Клиент, пустая история, 430 px | PASS — точные тексты и одно действие |
| Тренер, новый клиент без тренировок | PASS — точные тексты, одно действие, без дубля в шапке |
| Тренер, desktop-профиль | PASS — ручная визуальная проверка Playwright |
| Клиент, тёмная тема | PASS — текст, рамка и neutral CTA читаются |
