# Ассистент тренера — план исправления чата

План зафиксирован как неизменяемый чеклист. Каждый пункт выполняется отдельным PR: реализация, минимальная проверка, Playwright, CI, merge, production smoke-test — и только затем следующий пункт.

Настройки LLM, модель, provider, temperature, системные настройки и конфигурация LLM не меняются.

## Последовательность

1. **P0 — выравнивание сообщений по ролям.** Обычные сообщения пользователя находятся справа, ответы ассистента — слева, сервисные действия и результаты занимают доступную ширину.
2. **P0 — полоса ввода.** Один стабильный компактный блок, выровненные элементы управления, отступы 16 px, корректное положение над нижней навигацией и клавиатурой на 390 и 430 px.
3. **P0 — убрать декоративное коралловое свечение.** В чате и около полосы ввода не должно быть цветной утечки, не связанной с состоянием или действием.
4. **P1 — облегчить сообщения пользователя.** Ширина по содержимому с ограничением около 75%, более спокойный коралловый фон, без тяжёлой тени.
5. **P1 — собрать фрагменты диктовки.** Вместо повторяющихся карточек одна компактная строка «Диктовка · N фрагментов» с раскрываемыми подробностями.
6. **P1 — иерархия типов сообщений.** Пользователь, ассистент, действие/результат и ошибка должны читаться как разные состояния.
7. **P1 — вертикальный ритм.** Вопрос пользователя и ответ ассистента образуют близкую пару, между отдельными диалоговыми ходами больше воздуха.
8. **P1 — состояние ошибки.** Компактное красное сообщение об ошибке и расположенное рядом действие повтора.

## Итоговая приёмка

- обычное сообщение пользователя справа, ассистента слева, действие/результат на доступной ширине;
- полоса ввода полностью помещается в отступы 16 px, touch-targets не меньше 44 px, нет обрезания и цветной утечки, положение стабильно при открытой клавиатуре;
- повторяющиеся карточки фрагментов диктовки отсутствуют;
- проверены 390 и 430 px, светлая и тёмная темы, пустой диалог, обычная переписка, действие, ошибка, диктовка и открытая клавиатура;
- настройки LLM не изменены.
