# Cloud.ru frontend transfer integrity — 15.10.2026

## Пользовательский результат

Fit загружается через публичный Cloud.ru ingress без обрыва больших JS/CSS
ответов. Ошибка публикации не может пройти проверку только за счёт HTTP 200.

## Acceptance

1. Public web Nginx не пишет frontend-ответы во временный proxy buffer.
2. API ingress и loopback-only границы не меняются.
3. После установки web ingress текущие JS/CSS скачиваются через HTTPS целиком.
4. Неполная передача останавливает workflow и восстанавливает прежний site.
5. Yandex, DNS, сертификаты, БД, media и пользовательские данные не меняются.

## Доказательство исходной ошибки

До исправления `index.html` на Cloud.ru ссылался на JS размером 3 699 392 байта,
но HTTPS-соединение закрывалось примерно после 65 KiB. Range 0–65535 проходил,
range 0–131071 воспроизводимо завершался curl error 18. Recovery-экран был
следствием повреждённого основного модуля, а не auth/API ошибки.
